# MCP 与技能扩展支持

> @author ixxxxoooo
> 依据:Claude Code 官方文档(MCP、Skills、Hooks、Plugins、Memory)

## 1. MCP

### 1.1 传输类型

| 类型 | 添加方式 | 备注 |
| --- | --- | --- |
| HTTP | `claude mcp add --transport http <name> <url>` | 推荐,支持 headers 与 OAuth |
| SSE | `--transport sse` | 已被 MCP 规范弃用,GUI 标注警告 |
| stdio | `claude mcp add <name> -- <command> [args]` | 本地进程,不自动重连 |
| WebSocket | `--transport ws` | 首次连接失败不重试 |

### 1.2 作用域与优先级

| 作用域 | 存储位置 | 共享 |
| --- | --- | --- |
| local(默认) | `~/.claude.json` 内该项目条目 | 否 |
| project | 项目根 `.mcp.json` | 是(版本控制) |
| user | `~/.claude.json` 顶层 | 否 |
| plugin | 插件提供 | 随插件 |
| claude.ai 连接器 | 账号级 | 账号 |
| managed | 托管设置 `managedMcpServers` | 组织 |

优先级:managed > local > project > user > plugin > connector。同名按名称去重,按整条覆盖不合并字段;插件与连接器按端点去重。GUI 在列表里显示"被谁覆盖"。

### 1.3 GUI 功能清单

- **列表**:名称、传输、作用域、状态(connected / pending / failed / needs-auth / disabled)、工具数。
- **操作**:添加(表单与 JSON 两种)、编辑、删除、启用/禁用、重连、`reconnect all`、OAuth 认证。
- **表单字段**:transport、url、command、args、env、headers、timeout(毫秒,≥1000 生效)、scope。
- **校验**:`${VAR}` 与 `${VAR:-default}` 展开提示;提示 `ANTHROPIC_API_KEY` 等凭据变量在远程 `url/headers` 中读为空的规则。
- **导入**:`add-json`、从 Claude Desktop 导入。
- **详情页**:工具列表(含描述与输入 schema)、资源、prompts;`list_changed` 动态刷新;最近错误。
- **项目审批**:首次遇到 `.mcp.json` 服务器时弹出审批,可记住或拒绝(`disabledMcpjsonServers`)。
- **运行参数**:`MCP_TIMEOUT`、`MCP_TOOL_TIMEOUT`、`MAX_MCP_OUTPUT_TOKENS`、`CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS`、`CLAUDE_CODE_MCP_TOOL_IDLE_TIMEOUT` 在"高级"页集中配置。
- **Channels**:展示 `claude/channel` 声明与 `--channels` 开关状态。
- **输出提示**:超过 10,000 token 警告、默认上限 25,000 token 的说明。

### 1.4 MCP 与 ACP 的衔接

- 用户 MCP 由 `claude` 自身加载,GUI 的增删改写入对应配置文件(通道 B)或调用 CLI(通道 C),随后通过适配器的 `/mcp reconnect|enable|disable` 刷新。
- `session/new` 的 `mcpServers` 只放两类:OhMyAgent Bridge、用户在"Agent 扩展"中勾选的额外服务器。避免与用户配置重复。
- MCP prompts 映射为 `/mcp__<server>__<prompt>` 斜杠命令。MCP resources 出现在 `@` 补全里。

## 2. Skills

### 2.1 位置与作用域

| 作用域 | 路径 |
| --- | --- |
| 企业 | 托管设置目录 `.claude/skills/<name>/SKILL.md` |
| 个人 | `~/.claude/skills/<name>/SKILL.md` |
| 项目 | `.claude/skills/<name>/SKILL.md` |
| 嵌套 | 子目录 `.claude/skills/...`(在该子树工作时加载) |
| 附加目录 | `--add-dir` 目录下 `.claude/skills` |
| 插件 | `<plugin>/skills/<name>/SKILL.md`,调用名 `/plugin:skill` |

`.claude/commands/<name>.md` 与 `.claude/skills/<name>/SKILL.md` 等价,都生成 `/<name>`。

### 2.2 frontmatter 字段

`name`、`description`、`when_to_use`、`argument-hint`、`disable-model-invocation`、`user-invocable`、`allowed-tools`、`model`、`effort`、`context`(如 `fork`)、`agent`(如 `Explore`)、`hooks`、`paths`、`shell`。编辑器按字段类型生成控件,未知字段原样保留。

### 2.3 GUI 功能

- 按作用域分组的列表与搜索,显示是否被覆盖、是否禁用模型调用。
- 可视化编辑 frontmatter 与 Markdown 正文,实时校验 YAML。
- 新建向导:模板(用户手动调用型、模型自动调用型、fork 子代理型)。
- 一键运行(`/skill-name`)、重载(`/reload-skills`)。
- 打开目录、符号链接目录识别、`${CLAUDE_SKILL_DIR}` 变量提示。

## 3. Plugins

- 通道 C:`claude plugin` 系列命令(市场添加/移除、安装、更新、卸载、启用/禁用、作用域)。
- 通道 B(只读):解析 `~/.claude/plugins` 的 `installed_plugins.json`、`known_marketplaces.json`、插件 manifest,展示插件内的 skills / hooks / MCP / commands / agents。
- 安全:安装前展示来源与"插件可在本机执行代码"的信任提示。
- 组织策略:展示被托管设置限制的项。

## 4. Subagents

- 位置:`~/.claude/agents/*.md`、`.claude/agents/*.md`、插件内。
- 字段:`name`、`description`、`tools`、`model` 等 frontmatter + 正文系统提示。
- GUI:列表、编辑器、运行时的嵌套会话查看(ACP subagent sessions)。

## 5. Hooks

- 存储:各层 `settings.json` 的 `hooks` 字段,以及 plugin / skill frontmatter。
- 类型:command、http、prompt、mcp_tool。
- GUI:事件 → matcher → 处理器 的三级树状编辑器;JSON 输入/输出与退出码说明;只读 `/hooks` 汇总视图(显示来源文件)。
- 校验:matcher 语法、超时、同步/异步。

## 6. 记忆与指令

- 层级:托管 → 用户 `~/.claude/CLAUDE.md` → 项目 `CLAUDE.md` / `AGENTS.md` → 子目录 → `.claude/rules/*.md`(可带 `paths` 限定)→ auto memory。
- GUI:多层级编辑器,显示"本次会话实际加载了哪些文件"(`InstructionsLoaded`)。
- `/init` 一键生成项目 `CLAUDE.md`。

## 7. 其他对象

| 对象 | 处理 |
| --- | --- |
| Output styles | 设置页下拉选择与自定义编辑 |
| Statusline | GUI 底栏等价呈现,支持自定义脚本(沿用 `statusLine` 配置) |
| Checkpointing | DiffKit 检查点 |
| Workflows | 透传 + 后台任务面板展示 |
| Routines / 定时任务 | 本地定时(`/loop`、`/schedule`)入口;云端 routines 仅状态展示与跳转 |
| 沙盒 | 设置 → 权限 → 沙盒开关与路径/网络白名单 |
