# UI 视觉与交互规范

> @author ygw
> 风格:Cursor 的信息密度与布局 + Liquid Glass 的系统材质

## 1. 窗口布局

```
┌──────────────────────────────────────────────────────────────┐
│ 一体化玻璃 Toolbar:项目名 · 分支 · 模型/强度 · 模式 · 用量环   │
├────────────┬──────────────────────────────┬──────────────────┤
│ 玻璃侧栏    │  Agent 时间线(纯色)          │ 右侧面板(纯色)  │
│ 会话/文件   │  用户消息、思维、工具卡片     │ Diff / 编辑器 /  │
│            │  权限卡片、Plan                │ 终端              │
│            ├──────────────────────────────┤                  │
│            │  输入区 + 浮动玻璃操作条       │                  │
└────────────┴──────────────────────────────┴──────────────────┘
        Quick Ask Bar:全局热键呼出的浮动玻璃条
```

- 侧栏、右侧面板可折叠(⌘B、⌘⌥B)。右侧面板宽度可拖拽并记忆。
- 窗口使用 `NSWindow` 一体化标题栏、全尺寸内容视图,支持系统窗口状态恢复、Stage Manager、全屏。

## 2. 材质分区

| 区域 | 材质 | 说明 |
| --- | --- | --- |
| 编辑器、Diff 正文、终端 | 高对比纯色 | 不加玻璃、模糊、折射 |
| Agent 时间线正文 | 纯色 | 与编辑器同级可读性 |
| 侧栏、Toolbar、Quick Ask Bar、浮动操作条 | `.glassEffect()` | 系统标准玻璃 |
| 权限卡片、工具卡片 | 纯色卡片 + 轻边框 | 重要信息不放在玻璃上 |
| 按钮组(Accept/Reject、重试、模型切换) | `GlassEffectContainer` 内合并采样 | 降低 GPU 采样次数 |

## 3. 自适应回退

- 监听 `NSWorkspace.accessibilityDisplayShouldReduceTransparency` 与低电量模式通知。
- 回退通过 `DesignSystem` 的单一环境值切换材质,不重建视图树。
- 对比度不足时自动提高纯色区边界与文字对比。

## 4. 颜色与字体

- 文本:SF Pro;代码:SF Mono(可替换)。
- 语义色:使用系统语义色(`labelColor`、`separatorColor`),强调色跟随用户设置。
- Diff:新增 `systemGreen` 15% 底色 + 行首标记;删除 `systemRed` 15% 底色。
- 深浅色均需通过 WCAG AA 对比度(代码区 AAA 目标)。

## 5. 组件规范

### 5.1 时间线
- 项目类型:用户消息、助手文本、思维面板、工具卡片、权限卡片、Plan、Subagent、系统通知、压缩事件。
- 虚拟化:`NSCollectionView` 承载,按需布局,高度缓存;流式项只重算末尾。
- 自动滚动:贴底时跟随,用户上滚后暂停,出现"回到底部"浮标。

### 5.2 思维面板
- 默认折叠为一行摘要;流式时展开并半透明弱化;完成后自动折叠。

### 5.3 工具卡片
- 头部:kind 图标、标题、状态指示(转圈/勾/叉)、耗时。
- 展开:输入/输出、终端输出、Diff 预览、受影响文件跳转。

### 5.4 权限卡片
- 显示命令/路径/风险摘要,按钮:允许一次 / 总是允许 / 拒绝 / 修改后允许。
- 键盘:⏎ 允许、Esc 拒绝、⌘E 编辑。

### 5.5 Diff 视图
- 双栏与行内切换;hunk 折叠;行号;红绿底色。
- 快捷键:⌘⇧A / ⌘⇧R 文件级;⌥⌘A / ⌥⌘R hunk 级;↑↓ 在 hunk 间移动。

### 5.6 输入区
- 多行自适应高度,`@` 与 `/` 触发补全浮层;粘贴图片显示缩略图;⌘↩ 发送,⏎ 换行(可设置互换)。

## 6. 动效

- 玻璃元素的合并/分离使用系统流体动画。
- 文本流式渐显 ≤ 80ms 淡入,不使用位移动画。
- 卡片展开 150–200ms 弹簧动画;尊重"减弱动态效果"。

## 7. 无障碍

- 所有控件提供 VoiceOver 标签与动作;时间线项可逐条导航。
- 键盘全可达:焦点环清晰,支持完全键盘操作。
- 支持动态字体缩放与高对比度。

## 8. 原生感清单

- 原生菜单栏(文件/编辑/视图/会话/窗口/帮助)与标准快捷键。
- 拖放:文件拖入输入区作为 `@` 引用;图片拖入作为图片块。
- Quick Look / 拖拽导出会话。
- 系统分享、服务菜单。
- 状态恢复与多窗口。
