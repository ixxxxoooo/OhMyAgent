# 主题系统与 Google Antigravity 接入

> @author ixxxxoooo

## 目标
1. 主题渗透整个界面(侧栏、设置页、终端、Git、Diff、编辑器语法、聊天代码块、Mermaid、文件图标、标签、托盘、等待动画、状态点),支持更多独立风格主题与自定义主题。
2. 一批界面打磨(搜索窗、就地编辑、模型切换分割线、等待动词、滚动条、托盘重启、阴影与空状态、面板互相拖动)。
3. 通过官方 ACP 服务端 `agy_acp_server` 接入 Google Antigravity,应用内一键安装。

## 主题
- `ThemeTracker.revision` 由 `ThemeRuntime` 的各令牌读取,Observation 自动让依赖视图失效;AppKit 桥接监听 `ThemeRuntime.didChange`。
- `ThemePackage.all` = 内置主题 + 自定义主题。自定义主题为 JSON(`version: 1`),保存在 `Application Support/OhMyAgent/themes`,字段缺失时回落默认值。
- 终端 ANSI 16 色由 `ThemeStyle` 派生(蓝/品红/青去重,避免同色)。
- 规范见 `AGENTS.md` 4.3;`Scripts/ui-lint.py` 负责拦截写死色值。

## Antigravity 接入
```
设置 → Agent 注册表 → 官方 Agent → 一键安装
  AgentInstallModel.install()
    └ AgentInstaller.install(RegistryAgent)
        ├ 校验:HTTPS + 主机 == dl.google.com,无用户信息
        ├ 下载到暂存目录(可取消、带进度)
        ├ ditto 解压 → 拒绝越界链接 → chmod 755 → 清除隔离属性
        └ 原子移动到 agents/<id>/<version>/,写 manifest.json,清理旧版本
    └ AgentRegistryModel.upsert(.antigravity)   // registryId = antigravity-acp,不保存命令路径
```
- 启动:`GenericACPProvider` 见到 `registryId` 就从安装目录解析可执行文件;未安装抛 `AgentLaunchError.notInstalled`。
- 默认模型:环境变量 `AGY_ACP_DEFAULT_MODEL`(设置页「默认模型」写入)。
- 登录:`session/new` 返回认证错误(-32000 或登录类文案)时,按 `initialize` 返回的首个认证方式调用 `authenticate` 后重试;失败给出「先在终端运行 `agy` 登录」的指引。
- 安全:只在用户点击「一键安装」后联网下载;不读取任何令牌;日志不记录密钥。
- 测试:`AgentInstallerTests`(白名单/解压/升级/拒绝场景)、`AgentInstallModelTests`、`ProtocolTests`(`requireAuth`)。

## 面板互相拖动
- `PanelItem`(项目栏/工具栏/终端/输出)共用手柄 `terminalDragHandle`、落点 `PanelItem.dropTarget` 与 `WorkbenchModel.place`。
- 项目栏、工具栏只能在左右侧(按左右半幅判定);终端、输出可去左/右/底部/编辑区。
- 终端/输出标签右键可移回侧栏或底部。
