# OhMyAgent 产品需求规格(PRD)

> @author ygw
> 版本:v1.0(2026-10-16)
> 基线:macOS 27(Golden Gate)、Xcode 27、Swift 6.4、Apple Silicon(arm64)

## 1. 产品定位

OhMyAgent 是 macOS 27 独占的原生 AI 编程客户端,外观参考 Cursor 的 Agent Window,视觉语言采用 Liquid Glass。它以 GUI 宿主身份,通过 ACP(Agent Client Protocol)接管 Claude Code,并为未来接入其他 Agent 预留扩展接口。

### 1.1 目标

1. **绝对美观**:Cursor 风格的 Agent Window 加 Liquid Glass,代码区保持纯色高可读。
2. **最高性能**:纯原生、无 WebView;后台 actor 处理 I/O;TextKit 2 编辑器。
3. **绝对原生感**:原生菜单、快捷键、拖放、窗口状态恢复、无障碍。
4. **功能完整**:Claude Code 的每项功能在 GUI 中有等价入口(见《ClaudeCode功能映射矩阵》)。
5. **可扩展**:预留 MCP 与多 Agent 接入接口。

### 1.2 非目标

- 不复刻终端 TUI 的交互形态(如 `/vim` 输入模式、`/terminal-setup`)。
- 不上 Mac App Store(沙盒会阻止拉起 `claude` 与读写 `~/.claude`)。
- 不支持 Intel Mac、不支持低于 macOS 27 的系统。
- 不读取、转存或代持用户的 Claude 订阅凭据。

## 2. 技术栈基线

| 项 | 约束 |
| --- | --- |
| 语言 | Swift 6.4,严格并发(`-strict-concurrency=complete`) |
| UI | SwiftUI 为壳,AppKit 承担编辑器、时间线、终端 |
| 禁止 | WebView、Electron、跨平台自绘外壳 |
| 协议 | ACP v1(稳定),v2 作为实验开关;传输为 Stdio 换行分隔 JSON-RPC 2.0 |
| Claude Code 接入 | `@agentclientprotocol/claude-agent-acp`(Node 子进程,封装 Claude Agent SDK) |
| 分发 | Developer ID + 公证,非沙盒,仅 arm64 |

## 3. 用户故事与功能需求

### 3.1 对话与推理

- 流式文本(`agent_message_chunk`)零延迟渐显,Markdown 与代码块语法高亮同步完成。
- 思维流(`agent_thought_chunk`)进入可折叠半透明面板,流式时自动展开,默认折叠。
- Plan / Todo 实时面板。Subagent 以嵌套会话呈现,可单独取消。
- 输入区支持 `@` 文件/符号/MCP 资源、图片粘贴与拖入、`/` 命令补全、消息队列。

### 3.2 工具、权限与审查

- 工具调用卡片按 kind 显示图标与状态,并支持"跟随 Agent"自动跳转编辑器位置。
- 权限审批取代终端 y/n:对 `session/request_permission` 弹出原生面板,选项为 allow_once / allow_always / reject_once / reject_always,支持修改命令后允许。
- 文件修改审查:双栏/行内 Diff,红绿标记,行级、hunk 级、文件级 Accept/Reject,快捷键驱动。
- 检查点:会话级文件快照,支持 `/rewind` 回滚。
- Elicitation:结构化表单与 URL 跳转(MCP OAuth)。

### 3.3 MCP / Skills / Plugins / Subagents / Hooks / Memory

详见《MCP与技能扩展支持》。要点:

- MCP:传输(stdio/HTTP/SSE/WebSocket)、作用域(local/project/user/plugin/connector/managed)、OAuth、状态、重连、启停、工具/资源/prompt 浏览。
- Skills:多作用域浏览、frontmatter 可视化编辑、新建向导。
- Plugins:经 `claude plugin` 管理市场与安装。
- Subagents、Hooks、Memory(`CLAUDE.md` / `AGENTS.md` / rules / auto memory)可视化编辑。

### 3.4 会话与并行

- 会话列表、搜索、重命名、`load` / `resume` / `fork` / `delete`、导出。
- 每个 Workspace 窗口独占一个 ACP 适配器子进程与 `cwd`,窗口关闭回收。
- 多会话标签、worktree 并行会话、`additionalDirectories`。

### 3.5 设置

16 个设置页面,详见《设置项全景清单》。

### 3.6 扩展预留

- `AgentProvider` 协议与 `agents.json` 注册表(兼容 ACP Registry 条目格式)。
- Agent-as-MCP:把其他 Agent 登记为 MCP 工具源。
- OhMyAgent Bridge:内置本地 MCP 服务器,让 Agent 反向驱动 GUI。
- `ClaudeDirectProvider`:`claude -p --input-format stream-json` 兜底通道。

## 4. 鉴权需求(无感订阅)

- 以用户环境启动官方 `claude` 二进制,由其自行使用已登录的 Pro/Max 或 `apiKeyHelper` 凭据。
- 客户端只负责:展示 `claude auth status`、触发 ACP `authenticate`、登录失效提示。
- 严禁读取 Keychain 中的 OAuth token。

## 5. 性能需求

| 指标 | 目标 | 度量方式 |
| --- | --- | --- |
| 冷启动到可输入 | ≤ 300ms(主进程首帧) | `os_signpost` + `xctrace` |
| 空载主进程内存 | 40–80MB | `footprint` |
| 编辑器 5 万行滚动 | 60/120Hz,hitch ratio 门槛 | Instruments Animation Hitches |
| 流式渲染主线程单帧 | < 4ms | signpost |
| 子进程 | Node 适配器、claude 单独计量并在诊断页展示 | 诊断页 |

详见《性能预算与测试方案》。

## 6. 视觉需求

- 代码编辑区、终端、Diff 正文:高对比纯色,不使用玻璃与模糊。
- 侧栏、一体化 Toolbar、Quick Ask Bar、浮动操作条:`.glassEffect()`。
- 按钮组统一包裹 `GlassEffectContainer`。
- "减少透明度"与低电量模式自动回退为不透明材质。

详见《UI视觉与交互规范》。

## 7. 验收标准(摘要)

1. 能在任一项目目录打开窗口,完成一次"提问 → 思维流 → 工具调用 → 权限审批 → Diff 审查 → 回滚"的全流程。
2. 命令映射矩阵中通道 A 的项 100% 可用,B/C/D 通道的项各有 GUI 入口,TUI 专属项有说明。
3. 性能指标在 M0 基线数据基础上达到门槛。
4. 无障碍:VoiceOver 与键盘可完整操作。

## 8. 风险与假设

| 风险 | 应对 |
| --- | --- |
| ACP 适配器依赖 Node | 可配置路径,自动探测 nvm 与系统路径;保留 `ClaudeDirectProvider` 兜底 |
| ACP 未覆盖配置面 | 通道 B(配置文件)、C(CLI)、D(客户端自实现)补齐 |
| Liquid Glass API 细节随 SDK 变化 | M0 对照 Xcode 27 SDK 核对,并封装在 `DesignSystem` |
| 300ms/80MB 为目标值 | M0 先量基线,再决定是否调整口径 |
| 订阅凭据合规 | 不触碰 token,由官方进程使用 |
