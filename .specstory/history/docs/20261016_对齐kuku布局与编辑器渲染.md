# 对齐 kuku 布局与编辑器渲染

> @author ygw

## 目标
参照 `~/kuku` 补齐 OhMyAgent 在布局、编辑器渲染、设置项、模型配置上的差距;保留已有的会话流工具调用展示。

## 交付(K0–K7)
1. Diff 绿色行边缘:不透明预混色 + 行间外扩 0.5pt + 统一行号槽。
2. 标签页保活:`TabKeepAlive`(LRU)+ 活动状态环境值,隐藏标签不重建、不抢焦点、暂停轮询。
3. 高亮与预览:`CodeHighlighter`、`FilePreview`(Markdown/Mermaid/SVG/图片/PDF/CSV)。
4. Markdown 就地渲染:`MarkdownLive` + `MarkdownStyler`,渲染/源码/预览三态。
5. 侧栏:左 180–520、右 240–800,双击分隔条恢复默认。
6. 右栏:改动 / 文件 / 搜索 / Git / 终端 / 计划。
7. 设置:发送键、运行中发送、提示音、聊天宽度、网络、提示词、项目信任。
8. 模型:高级参数、官方与 OpenCode 预设、模型列表获取、输入框按会话切换提供商。

## 验证
- `Scripts/ci.sh` 零警告、测试全绿;`Scripts/restart.sh` 重启后用 `OMA_RIGHT_PANE`、`OMA_OPEN_SETTINGS` 等钩子后台截图核对。
- 详见「开发进度.md」的 K0–K7 与偏差说明。
