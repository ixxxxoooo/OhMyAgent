├── Sources/

## 3. 各里程碑细化

### M0
- 搭建 SwiftPM 骨架,确认 `swift build` 通过。
- Spike A(玻璃 API):`Spikes/GlassSpike` 在 Xcode 27 SDK 下编译 `.glassEffect()`、`GlassEffectContainer`。
- Spike B(ACP 握手):`Spikes/ACPSpike` 启动适配器完成 initialize、session/new。
- Spike C(TextKit 2 五万行):`Spikes/EditorSpike` 生成 5 万行并测量加载与布局耗时。
- Spike D(Node 打包策略):`AgentHost` 的探测逻辑 + 文档结论。

### M1
- `JSONRPC`:`JSONValue`、`RequestID`、`Message`(请求/响应/通知)、行分帧。
- `ACPModels`:initialize、session/*、prompt、session/update 变体、ContentBlock、ToolCall、Permission、Plan、Elicitation、Terminal、FS。
- `ACPConnection`(actor):请求表、通知流、客户端方法处理器、取消、背压。
- `StdioTransport`:`Process` + `Pipe`。
- `AgentHost`:`AgentDescriptor`、`AgentProcess`、`ExecutableLocator`。
- 测试:编解码、分帧、FakeAgent 场景、对真实适配器集成。

### M2
- `WorkspaceWindow`(`WindowGroup`,每窗口一个 `SessionActor` 与适配器进程)。
- 玻璃侧栏、一体化 Toolbar、时间线(`NSCollectionView` 或 SwiftUI 对比后择优)、输入区。
- 流式文本与思维面板;Markdown 渲染。

### M3
- 工具卡片、权限卡片、Elicitation 表单、Plan 面板、Subagent 嵌套。
- `EditorKit`、`DiffKit`(行级 diff、hunk、接受/拒绝、检查点)。
- 终端:PTY 管理与视图。

### M4
- `/` 与 `@` 补全;模式与 config option 选择器;会话列表/resume/fork/delete;用量环;鉴权桥(`claude auth status`)。

### M5
- `ClaudeConfigKit`:读写 settings、`.mcp.json`、`~/.claude.json`、skills、agents、hooks、plugins、memory;FSEvents 监听。
- 对应 GUI 管理页。

### M6
- 设置窗口 16 页;偏好存储与 `settings.json` 写回;热更新。

### M7
- `AgentRegistry` + `agents.json`;窗口内切换 Agent。
- `BridgeServer`:本地 Unix socket 的 MCP 服务器,提供 `ohmyagent.*` 工具。
- Agent-as-MCP 条目注入 `session/new`。
- `ClaudeDirectProvider`:`claude -p` stream-json 兜底。

### M8
- 性能调优;无障碍;本地化(简中/英);签名公证脚本;更新机制。

## 4. 工程约定

- Swift 文件头加 `@author ygw`;注释全部中文;方法注释含用途、参数、返回值。
- 空值判断使用 `isEmpty` 类惯用法;单方法 ≤ 300 行。
- 提交信息:中文 Conventional Commits(如 `feat: 新增 ACP 连接层`)。
- 每次改代码后:构建 → 重启应用与适配器子进程 → 确认生效(`Scripts/restart.sh`)。
- 完成功能后更新 `开发进度.md`。

## 5. 风险登记

| 风险 | 级别 | 缓解 |
| --- | --- | --- |
| 适配器版本变化导致协议差异 | 中 | 前向兼容解码、版本检测、集成测试 |
| Node 缺失 | 中 | 路径探测与引导;DirectProvider 兜底 |
| 性能目标不达标 | 中 | M0 基线,按数据调整口径 |
| 玻璃 API 差异 | 低 | 封装在 DesignSystem |
| 子进程占用内存 | 低 | 诊断页展示,窗口关闭回收 |
