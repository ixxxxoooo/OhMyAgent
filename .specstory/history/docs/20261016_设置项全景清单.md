# 设置项全景清单

> @author ixxxxoooo
> 原则:凡属 Claude Code 自身配置的项,写回对应 `settings.json`(通道 B);仅属客户端的项存于 `~/Library/Application Support/OhMyAgent/preferences.json`。

## 1. 通用
- 启动时打开:上次窗口 / 空窗口 / 项目选择器。
- 语言:跟随系统 / 简体中文 / English。
- 全局热键:呼出 Quick Ask Bar(默认 ⌥Space)。
- Dock 图标与菜单栏图标显示。
- 更新通道:稳定 / 预览;自动检查更新。
- 重置所有设置。

## 2. 外观
- 主题:跟随系统 / 浅色 / 深色。
- 强调色。
- 界面字号、时间线字号、行距。
- 玻璃强度(标准 / 低),不影响纯色保护区。
- 紧凑度:舒适 / 紧凑。
- 动效:标准 / 减弱(同步系统"减少动态效果")。
- 透明度策略:跟随系统"减少透明度" / 始终使用不透明材质。
- 低电量模式:自动回退不透明材质(开关)。

## 3. Agent 与模型
- 默认模型、思考强度(effort)、fast 模式。
- 上下文窗口与 auto-compact 阈值。
- Output style。
- 默认 Agent(Claude Code / 注册表中的其他 Agent)。
- API 提供方展示:firstParty / Bedrock / Vertex / Foundry(只读)与 `apiKeyHelper` 状态。

## 4. 权限
- 默认模式:default / acceptEdits / plan / dontAsk;auto 与 bypassPermissions 需二次确认,托管策略可禁用。
- 规则编辑器:allow / ask / deny 三栏,支持 `Tool(pattern)` 语法校验与"测试匹配"。
- 受保护路径提示。
- 沙盒:启用开关、文件与网络白名单。
- `blockReadsOutsideWorkingDirectories` 开关。
- 项目 `.mcp.json` 审批记录管理。

## 5. MCP
见《MCP与技能扩展支持》§1.3,含列表、添加、导入、OAuth、运行参数。

## 6. Skills / Plugins / Subagents / Hooks
见《MCP与技能扩展支持》§2–§5。

## 7. 记忆与指令
- 各层 `CLAUDE.md` / `AGENTS.md` / rules 编辑。
- auto memory 开关与内容管理。
- 本会话已加载指令来源。

## 8. 编辑器
- 字体、字号、行高、连字。
- 编辑器配色(浅/深各一套,纯色背景)。
- 自动换行、缩进、空白显示。
- Minimap 开关。
- 超大文件模式阈值(默认 20,000 行起降级:关闭换行与复杂高亮)。
- 保存时处理:去尾随空白、末尾换行。

## 9. 终端
- Shell 路径、启动参数。
- 字体与字号、光标样式。
- 滚动缓冲行数。
- 环境变量继承策略。

## 10. 快捷键
- 全部动作可自定义;冲突检测;导入导出。
- 默认:⌘N 新会话、⌘K 命令面板、⌘L 聚焦输入、⌘↩ 发送、Esc 取消、⌘⇧A/R 接受/拒绝文件、⌥⌘A/R 接受/拒绝 hunk、⌘B 侧栏、⌘J 终端。

## 11. 账号与鉴权
- 登录状态(`claude auth status`):方式、账号、提供方。
- 登录 / 登出。
- 订阅额度与速率限制提示。

## 12. 用量与成本
- 当前会话:token、费用、上下文占用。
- 累计:按日/周统计(读取 `claude` 的统计,通道 C)。
- 预算提醒阈值(客户端侧)。

## 13. Agent 扩展
- Agent 注册表:增删改 `AgentDescriptor`(命令、参数、环境、传输、能力)。
- OhMyAgent Bridge:开关与暴露的工具白名单。
- 外部 Agent-as-MCP 条目管理。
- 额外注入 `session/new` 的 MCP 服务器勾选。

## 14. 隐私与遥测
- 客户端遥测:默认关闭。
- 日志脱敏(路径、令牌)。
- 转发 Claude Code 遥测相关环境变量(`DISABLE_TELEMETRY` 等)的透传开关。

## 15. 高级
- `claude`、`node`、适配器路径与自动探测结果。
- 环境变量表。
- ACP:v2 实验开关、请求超时、日志级别。
- MCP 运行参数。
- 数据目录、缓存清理。

## 16. 诊断
- 进程:GUI、Node 适配器、claude 的内存与 CPU。
- 冷启动耗时、首帧耗时、首次发送延迟。
- `claude doctor` 结果。
- 导出诊断包(脱敏日志 + 版本信息 + 基线数据)。
