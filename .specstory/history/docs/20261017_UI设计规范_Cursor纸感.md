# Cursor 纸感 UI 设计规范(4.4)

> @author ixxxxoooo
> 来源:Refero「Cursor」风格(styles.refero.design/style/4e3b4717-84c8-4599-baaf-a343c3d619b6)的暖纸色视觉 DNA,
> 与本项目既有令牌工程(`ThemePackage` / `OMColors` / `OMFonts`)合并后的落地规范。

## 1. 结论

- 默认主题为「Cursor 纸感」(`paper-light`,另有暖墨深色 `paper-dark`),「跟随系统」与其余主题保持原样,作为参考。
- **结构规则对所有主题生效**(字重、按钮层级、圆角令牌、三档阴影、强调色角色);**取值**(色板、圆角大小、是否玻璃)由主题通过 `ThemeStyle` / `ThemePalette` 提供,缺省值保持旧行为。
- 纸感主题关闭玻璃(`allowsGlass = false`):卡片为不透明 Bone + 发丝线;其余主题仍使用 Liquid Glass。

## 2. 色板(纸感浅色)

| 角色 | 色值 | 令牌 / 用途 |
| --- | --- | --- |
| Parchment | `#F7F7F4` | `OMColors.surface` 内容区 |
| Bone | `#F2F1ED` | `OMColors.card` 卡片 |
| 侧栏 | `#EFEEE9` | `OMColors.sidebar`(必须 ≠ surface) |
| Stone | `#CDCDC9` | `OMColors.outline` 强描边 |
| Ink | `#26251E` | 正文 |
| Ember | `#F54E00` | `OMColors.accent`:仅文字/链接/强调,不做大面积填充;文字用 `accentText`(对比度 ≥ 4.5) |
| Amber | `#C08532` | `actionWarm`:「继续 / 执行计划」类按钮(`.omWarm`) |
| Forest | `#34785C` | `actionPositive`:「提交 / 完成」类按钮(`.omPositive`) |
| Crimson | `#CF2D56` | `danger` |
| 选区 | `#8BC4F8` | 文本/终端选区 |

禁止纯 `#FFFFFF` / `#000000`;禁止在视图写死色值,一律经 `OMColors`。

## 3. 形状、间距、动效

- 圆角只用 `OMRadius`:`tag / control / card / floating / modal`(纸感 4/4/4/8/8;旧主题 5/8/12/14/20)。禁止字面量 `cornerRadius: N`。
- 标签、芯片、徽标用 `OMPillShape`(纸感为小圆角矩形,旧主题为胶囊)。`Capsule()` 仅用于进度条/滑块轨道等几何。
- 间距用 `OMSpacing`(4 的倍数)。动效用 `OMMotion.standard`(150ms,cubic-bezier(0.4,0,0.2,1)),经 `omWithAnimation` 遵循「减弱动态效果」。
- 阴影三档:`omCardShadow`(纸感下为无阴影,仅发丝线)、`omFloatingShadow`(浮层)、`omFloatShadow`(弹窗)。
- 禁止装饰性渐变、发光、毛玻璃(纸感下)。渐变只允许作为遮罩/淡出。

## 4. 字体

- 字重上限 `medium`;`OMFonts.title` / `sectionTitle` 均为 medium。内容强调(搜索命中、终端 ANSI 加粗、编辑器 Markdown)可行内 `// ui-lint:allow 原因`。
- 标题统一用 `OMFonts.title`;字体一律系统字体,禁止衬线(曾试用 New York 衬线标题,已按用户要求回退)。`omEditorialHeading` 仅作备用令牌(系统字体 regular 22/26pt),默认不使用。

## 5. 按钮层级(`OMButtonStyle`)

- `.omPrimary`:填充跟随主题强调色(纸感取加深 Ember `accentText`,选中背景/加载/状态点同理);每个区域至多一个。
- `.omWarm`(Amber)与 `.omPositive`(Forest)用于语义明确的动作(继续/提交),与主按钮同组最多共存两个实心按钮。
- `.omSecondary`、`.omPlain`(悬停下划线)、`.omDestructive`、`.omIcon` 不变。

## 6. 选中态

- 选中背景用 `OMColors.selectedFill`(纸感下为中性色,不再套强调色),强调色仅用于文字/图标/焦点。

## 7. 守卫

- `Scripts/ui-lint.py --check`(已接入 CI)新增规则:字重(>medium)、字面量圆角、`Capsule()`、渐变。
- `Tests/OhMyAgentAppTests/PaperThemeTests.swift`:主题目录与默认值、文字对比度(正文 ≥ 7、次要 ≥ 4.5、语义色 ≥ 4.5)、按钮前景可读、sidebar ≠ surface、无纯黑白、旧主题风格默认值不变。

## 8. 新增主题 / 控件检查清单

1. 主题:提供 `surface`、`sidebarBackground`、`accent`、`accentText`(必要时)、语法/Diff/状态色与 `style`;通过 `ThemeTokenTests`、`PaperThemeTests`。
2. 控件:颜色走 `OMColors`、圆角走 `OMRadius`、字号走 `OMFonts`、字重 ≤ medium、动效走 `OMMotion`。
3. 视觉验证:纸感浅/深、「Cursor 浅色」、一个深色主题各截一张,检查侧栏与内容区层次、状态点颜色。

## 9. 右键菜单与对话框(自绘,全仓统一)

- 右键菜单一律用 `omContextMenu { … }`(`OMMenuItem`/分隔线/子菜单,`OMMenuBuilder` 声明式),**禁止 `.contextMenu`**;菜单是不透明卡片(`OMRadius.card` + 发丝线 + `omFloatingShadow`),↑↓ 切换、回车执行、Esc 关闭,子菜单在行内展开。菜单内容在点击时才求值,嵌套视图里最内层的锚点优先。
- 模态对话框一律用 `OMDialog.confirm/prompt/alert` 或 `OMModal.run`,**禁止 `NSAlert`**;按钮层级沿用 `OMButtonStyle`(取消 = secondary,主操作 = primary,破坏性 = destructive),带输入框的对话框支持校验与错误文案。
- 守卫:`Scripts/ui-lint.py` 的「菜单」「对话框」两条规则已接入 CI。
