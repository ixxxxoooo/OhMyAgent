# 反重力(Antigravity)ACP 适配与跨引擎会话保留

> @author ixxxxoooo

## 背景
Antigravity(`agy_acp_server`)接入后:左侧会话列表像是没有恢复;读文件/执行命令/编辑的工具行点不开,失败时也不显示错误。

## 协议差异(实测,非猜测)
| 项 | Claude Code 适配器 | Antigravity |
| --- | --- | --- |
| 回放 `rawInput` | 对象 | **JSON 字符串**,键 PascalCase |
| 实时 `rawInput` | 对象 | 对象,snake_case,行号为 double |
| 命令结果 | `content` | `rawOutput.combinedOutput` + `exitCode` |
| 读/改成功 | `content`/diff | `rawOutput:""` |
| 失败 | `status: failed` + content | `rawOutput` 为纯文本错误 |
| 标题 | 动词 + 对象 | `Running <工具名>` |
| `session/list` | 真实会话 | 含大量从未使用的空会话(每次连接新建) |
| `session/load` 他引擎 ID | - | 错误 -32002 |

## 方案
- `ToolInputNormalizer`:统一入参(别名、字符串 JSON)、结果文本、退出码、由标题推断工具名。
- 工具行:不可展开的读取类工具点击直接在编辑器打开文件;失败显示原因;命令显示退出码。
- 会话保留:缓存按引擎分别合并;侧栏合并实时 + 其他引擎缓存;点击其他引擎的会话用原引擎新开标签;空会话隐藏(`EmptySessionRegistry`)。

## 验证
`Scripts/ci.sh` 全绿(含 `AntigravityToolTests` 使用真实抓取的载荷)。

## Antigravity 一键安装与启动(原《主题系统与反重力接入》中的接入部分)
通过官方 ACP 服务端 `agy_acp_server` 接入 Google Antigravity,应用内一键安装。

```
设置 → Agent 注册表 → 官方 Agent → 一键安装(AntigravityInstallSection)
  AgentInstallModel.install()
    └ AgentInstaller.install(RegistryAgent)
        ├ 校验:HTTPS + 主机在白名单(dl.google.com),无用户信息
        ├ 下载到暂存目录(可取消、带进度)
        ├ ditto 解压 → 拒绝越界符号链接 → chmod 755 → 清除隔离属性(com.apple.quarantine)
        └ 原子移动到 agents/<id>/<version>/,写 manifest.json,清理旧版本
    └ AgentRegistryModel.upsert(.antigravity)   // registryId = antigravity-acp,不保存命令路径
```

- 安装目录:`Application Support/OhMyAgent[-Dev]/agents/<id>/<version>/`;当前内置回退条目版本为 1.4.0(`AgentInstaller.antigravityFallback`,仅 `dl.google.com` 的 zip)。
- 启动:`GenericACPProvider.makeLaunch` 见到 `registryId` 就从安装目录解析可执行文件;未安装抛 `AgentLaunchError.notInstalled`,提示到设置 → Agent 注册表点击「一键安装」。
- 默认模型:环境变量 `AGY_ACP_DEFAULT_MODEL`(`AgentDescriptor.antigravityModelEnv`,设置页「默认模型」写入,对新开的会话生效)。
- 登录:`session/new` 返回需要认证的错误时,`SessionModel.newSessionAuthenticating` 按 `initialize` 返回的首个认证方式调用 `authenticate` 后重试一次;失败提示「先在终端里完成登录(Antigravity 运行 `agy`)再重试」。
- 安全:只在用户点击「一键安装」后联网下载;不读取任何令牌;日志不记录密钥。
- 测试:`AgentInstallerTests`(白名单/解压/升级/拒绝)、`AgentInstallModelTests`、`ProtocolTests`、`AntigravityToolTests`。
