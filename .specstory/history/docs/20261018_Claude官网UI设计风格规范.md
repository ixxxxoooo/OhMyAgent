# Claude 官网 UI 设计风格规范(分析与参考指南)

> @author ixxxxoooo
> 分析时间:2026-10-18 · 样本:https://claude.com/ 首页(claude.ai 当日被 Cloudflare 拦截,未纳入)
> 数据来源:实拍截图 + 站点 CSS(Next.js 产物)+ HTML 内联 SVG;色值/字号/圆角均取自站点令牌,非目测。

## 1. 设计基调

**暖纸感编辑风**:暖白纸底 + 暖黑墨色;衬线体承担标题、无衬线体承担正文与控件;大量留白,
低信息密度;陶土橙(clay)只作点睛(Logo、发送键、焦点、少量插画);圆角克制、阴影极轻、
1px 发丝线为主;动效短而安静。一句话:**中性色承担 95% 画面,强调色只做 5% 的标点。**

## 3. 字体系统

| 角色 | 字体 | 回退栈 |
|---|---|---|
| 标题/展示 | `anthropicSerif` | `Georgia, serif` |
| 正文/UI | `anthropicSans` | `system-ui, sans-serif` |
| 代码/等宽 | `anthropicMono` | `ui-monospace, monospace` |

三者均为 Anthropic 自有可变字体(woff2,Roman/Italic),支持 300–700 及中间字重;中文环境覆盖为 Noto Sans,
即**中文不使用衬线标题**,回退无衬线。

字重:衬线大标题 400、正文 400、主按钮 **480**(可变字重)、次按钮/导航 500、强调小标题 500–600、极少 700。
> 按钮 480 是产品化细节:比 400 稳,又不像 500 那么重。

字号阶梯(桌面端 clamp):

| 令牌 | 范围 | 行高 | 令牌 | 范围 | 行高 |
|---|---|---|---|---|---|
| display-1 | 42→72px | 1.1 | headline-4 | 23→32px | 1.5 |
| display-2 | 36→64px | 1.1–1.2 | headline-5/6 | 16→19px | 1.2–1.5 |
| headline-1 | 34→52px | 1.2 | body-1 | 19→20px | 1.6–1.7 |
| headline-2 | 30→44px | 1.2 | body-2 | 17px | 1.6–1.7 |
| headline-3 | 28→36px | 1.2–1.3 | body-3 | 15→17px | 1.6 |
| caption | 12→15px | 1.6 | | | |

字距:常规 `0.01em`;全大写小标签 `0.05em`;超大标题 `-0.02em`。
行长用 `ch` 限制:标题 30/45ch、正文 60ch、长文 80ch。

## 4. 布局与间距

容器:`main 90rem(1440)`、`medium 74.5rem(1192)`、`small 60rem(960)`、`narrow 41.25rem(660,登录卡)`。
间距为 4px 网格:`2/4/6/8/12/16/20/24/32/40/48/56/64/80/96/128`;区块纵向间距 `clamp()` 约 40–64px。

首页节奏:顶栏(约 80px,左 wordmark,右次按钮 + 黑主按钮 + 汉堡)→ 居中 Hero(超大衬线标题 + 17–24px 副标题)
→ 660px 登录卡(白底、24px 圆角、1px 描边、两个全宽按钮)→ 居中"Download desktop app"→ 约 200px 留白
→ "Explore plans"(衬线标题 + 分段控件 + 3 列价格卡)→ FAQ 手风琴 → 深色 Footer。

## 5. 形状、描边、阴影

- 圆角:`2/4/6/8/12/16/24/32/48/64px` + `999px`;按钮/输入 **12px**、卡片 **16–24px**、小控件 6–8px。
- 描边:`0.5/1/1.5/2px`;卡片与输入框普遍 **1px `#E8E6DC`**。
- 阴影极轻:`sm 0 2px 8px rgba(0,0,0,.04)`、`md 0 4px 20px .04`、`lg 0 4px 16px .10`。
- **层级靠底色差与描边,不靠阴影**;白卡只是从暖白底上"浮起 1mm"。

## 6. 组件规范

**按钮**:主按钮 `#141413` 底白字、12px 圆角、高 44–48px、字重 480;次按钮白底 + 1px 描边 + 墨色字;
三级按钮透明底;图标按钮悬停才出现极轻填充;一个区域最多一个黑色主按钮,登录/价格卡用全宽。
**分段控件**:轨道 `#F0EEE6`、12px 圆角、内边距 4px;选中白底 + 极轻阴影 + 墨色字;高约 40–44px。
**卡片**:白底 + 1px `#E8E6DC` + 16–24px 圆角,内边距 24–32px;区块内用发丝线分隔,不再套卡。
**输入框**:白底 + 1px `#E8E6DC` + 12px 圆角,高 44–48px,placeholder gray-500,焦点 clay ring(非蓝)。
**图标**:统一 20×20 网格(少量 16×16);实心 filled 路径、`fill="currentColor"`、无 stroke;单 path 为主,
圆角端点由路径本身画出;品牌图标保留原色。
**导航**:暖白吸顶;左 wordmark,右侧次按钮 + 黑主按钮 + 汉堡;下拉为白卡 + 1px 描边 + 12–16px 圆角。
**Footer**:`#141413` 深底反白;顶部"Ask Claude"输入框 + clay 圆形发送键;链接列小号灰标题 + 浅灰链接;
Anthropic wordmark、社交图标、语言切换胶囊、细线法律行。

## 8. 动效

颜色/透明度 `.2s`;位移 `transform .3s cubic-bezier(0.25,1,0.5,1)`(ease-out-quart);
大面积颜色 `color .5s ease-out-expo`。无弹跳、缩放强调、发光;焦点态为静态 ring 或颜色变化。

## 9. 在 OhMyAgent 中如何参考(不要照搬)

**可借鉴**:暖白纸底 + 暖黑墨色主题变体;clay 橙作第二强调色(≤5%,只用于 Logo/运行状态/焦点/发送);
1px 发丝线 + 极浅阴影的层级方式;控件 12px、卡片 16–24px 圆角(对齐 `OMRadius`);
低频动效(沿用 `OMMotion.standard`);大留白、单一主操作、全宽按钮、分段轨道 + 白底选中。

**不可照搬**:

| 项 | 原因 | 替代 |
|---|---|---|
| Anthropic 三种字体 | 专有字体,不可再分发 | 系统字体;需衬线氛围时先改规范并用开源衬线 |
| Claude/Anthropic Logo、星芒 | 商标与版权 | 自绘品牌图形,不引用其视觉标识 |
| 官网 SVG 图标 | Anthropic 设计资产 | 沿用本项目 Lucide;或自绘 filled 20×20 经 `Scripts/gen-icons.py` 生成 |
| 72px Hero | 应用型 UI 不适用 | 只借鉴层级关系,字号遵循 `OMFonts` |

> 本项目 `AGENTS.md` 4.4 明确「字体一律系统字体,禁止衬线」,官网衬线大标题**不应**直接引入界面。

**落地路径**:
1. 先做主题包,不改组件:新增"Claude 暖纸"主题,给出 `surface #FAF9F5`、`sidebar #F0EEE6`(必须 ≠ surface)、
   `primaryText #141413`、`secondaryText #5E5D59`、`tertiaryText #87867F`、`accent #D97757`、
   `accentText #C6613F`、`hairline #E8E6DC`、`card #FFFFFF`;跑 `ThemeColorTests`/`PaperThemeTests` 对比度守卫。
2. 再在主题里调 `ThemeStyle`(圆角/描边/阴影/填充倍率),禁止写死颜色。
3. 图标保持自有体系,不要混入 filled 图标;若要试,单独新增一套并全局一致替换。
4. 用演示模式 `OMA_THEME=<新主题>` 截图,与 claude.com 并排比对**明度层次、强调色占比、圆角/描边强度**,
   不逐色对齐。
5. 文案与留白比配色更接近气质:每屏一个主操作,正文行长约 60ch。
