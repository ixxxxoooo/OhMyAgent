# 模型来源切换(原生 ⇄ 自定义映射)

> @author ixxxxoooo

- 输入框模型下拉分两组:「Claude Code 原生(~/.claude)」与「自定义映射」。仅配置了默认槽位映射时才出现分组。
- 选择另一组的任意模型即切换来源:写入 `providers.json` 的 `useMapping`(全局),空闲会话自动恢复(保留上下文),运行中则等本轮结束。
- 原生:不注入网关与 `ANTHROPIC_*` 覆盖,使用终端同款 `~/.claude/settings.json` 与官方登录。
- 映射内容在切回原生后依然保留;也可在 设置 → Claude Code 模型映射 里用「使用自定义映射」开关切换。
