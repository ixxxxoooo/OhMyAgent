# 演示场景目录

> @author ixxxxoooo · 2026-10-18

演示模式下可用的全部场景。触发方式:输入框 `/demo-<id>`(带补全)、⌘K「演示场景」、提示词写 `#demo-<id>`、`Scripts/demo.sh --scenario <id>`(即 `OMA_DEMO_SCENARIO`)。
本表由场景注册代码生成;新增场景后请重新生成,并同步 `Scripts/demo-tour.sh` 与覆盖守卫测试。

演示模式下 Agent 呈现为 Claude Code,模型为 Fable 5.1 / Opus 5.5 / Sonnet 5.5 / Haiku 5.5(默认 Sonnet 5.5),有六种权限模式与五档思考强度;新建会话以场景标题命名。

共 56 个场景。

## 说明

- **交互**场景要在界面里批准权限/回答问题,覆盖逻辑靠 `DemoCoverageTests` 与 `DemoScenarioTests` 自动化验证;`OMA_AUTOALLOW=1` 自动批准第一个「允许」类选项(含计划批准)。
- **以非正常方式收尾**的场景(模型拒绝、输出上限、各类报错)只在末尾出现对应提示,不属于 `all` 串联。
- `all`(全量回归)只串联自动场景,跳过终端、长时间任务、慢速输出与「疑似提前结束」。
- 带图片的场景(`tools-browser`、`tools-image`、`user-variants`)使用 `ScenarioImages` 现场绘制的示意图,不依赖外部文件。
- Plan:`plan-approval` 批准后会在 `~/.claude/plans/` 写出 `*.plan.md`(演示模式下是沙盒主目录),计划卡显示「已 Build」与随进度同步的 TODO;调试钩子 `OMA_OPEN_PLAN=1` 在计划落盘后自动打开计划标签页。
- 子代理:卡片状态(启动中 / 运行中 / 后台运行 / 已完成 / 已失败)用 `subagents-cards` 一次看全(冻结,需取消);`subagents-lifecycle` 是实时过程,约 4 秒,适合手动观看。
- 历史会话(`DemoHistory`)回放时,权限请求变为已完成的工具,回合终止/报错/限额/提问步骤被忽略。

## 已知缺口(应用本身)

- Markdown 暂不渲染数学公式与图片语法(`markdown-edge` 场景展示当前的回退表现)。
- 用量面板上半部分的「上下文窗口」明细来自固定的 `/context` 模拟报告,与场景里的用量数字不联动。
- 模式切换场景只能在界面里观看色调变化,静态截图只能看到终态。
- Plan 标签页有未保存修改时关闭标签不会提示;计划文件在磁盘上被外部改动后需手动点「重新读取」。
