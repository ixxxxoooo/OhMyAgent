# UI 验证与调试钩子清单(完整版)

> @author ixxxxoooo · 2026-10-23 · 自 `AGENTS.md`「6. UI 验证约定」原样迁出(精简原因同 `20261023_模块地图.md`)。以 `grep -rn OMA_ Sources` 为准。

## UI 验证约定与调试钩子
- 启动:`open -g -n build/OhMyAgent.app --env OMA_AGENT=fake --env OMA_PROJECT_ROOT=$PWD`。
- 演示模式:`OMA_DEMO=1`、`OMA_DEMO_ROOT`、`OMA_DEMO_RESET=1`、`OMA_DEMO_SCENARIO=<场景名>`、`OMA_THEME=<主题 id>`(仅演示模式,如 `paper-light`/`paper-dark`/`cursor-light`,用于主题对比截图);输入框 `/demo-<场景名>` 或命令面板「演示场景」运行场景;新增工具卡/条目类型必须补演示场景(覆盖守卫测试会失败提醒)。
- 调试钩子:`OMA_DRAFT`、`OMA_OPEN_SETTINGS`、`OMA_SETTINGS_PAGE`、`OMA_AGENT=fake`、`OMA_LSP_PROBE=行:列`、`OMA_AUTOALLOW`(自动批准权限)、`OMA_USAGE_PANEL`(展开上下文用量面板)、`OMA_BRANCH_MENU`(展开分支切换弹层)、`OMA_ATTACH_IMAGE=路径1:路径2`(给输入框添加图片附件)、`OMA_PERF_OUT`、`OMA_TOGGLE_LEFT=秒`(延迟切换左栏)、`OMA_TAB_OVERFLOW=1`(标签溢出时自动展开「全部标签」下拉)、`OMA_SIDEBAR_SIDE`/`OMA_TOOLS_SIDE=left|right`、`OMA_SHOW_TERMINAL=1`/`OMA_SHOW_OUTPUT=1`(右栏终端/输出标签)、`OMA_HUB=all|sessions|projects|files|actions|settings`(打开中央搜索窗)、`OMA_HUB_QUERY`(预填搜索词)、`OMA_DEMO_BENCH=<分类|all>`/`OMA_DEMO_BENCH_OUT`/`OMA_DEMO_BENCH_EXIT=1`(演示空间启动即跑基准并写 JSON)、`OMA_DEMO_OPEN_SESSIONS=N`、`OMA_IDE=1`(启动后打开 IDE 窗口,根目录取 `OMA_IDE_ROOT` 否则当前项目)、`OMA_IDE_EXPAND`/`OMA_IDE_OPEN_FILE=路径[:行]`/`OMA_IDE_SIDEBAR`/`OMA_IDE_QUERY`/`OMA_IDE_PANEL`/`OMA_IDE_PALETTE=<输入>`(IDE 窗口预置界面状态,见 `IDEDebugHooks.swift`)、`OMA_IDE_SWEEP=N`(IDE 窗口开关/切换基准,perf 日志「IDE 窗口基准」「IDE 窗口基准汇总」;`restart.sh` 不转发,用 `OMA_IDE_SWEEP=20 Scripts/demo.sh`)、`OMA_SIDEBAR_SWEEP=idle,scroll,gentle,expand,hover,status,unrelated|all`(项目栏流畅度基准,配合 `OMA_DEMO_SIDEBAR_PROJECTS=50`,输出 perf 日志「项目栏基准」:帧间隔、掉帧、RunLoop 忙碌时间、各视图 body 次数;`hover` 需窗口在前台)、`OMA_DEMO_PROJECT=<项目名>`、`OMA_TIMELINE_TURNS=<轮数>`(性能实验室长会话轮数)、`OMA_OPEN_ITEM=<名称片段>`(设置页的技能/子 Agent/记忆自动打开对应条目)、`OMA_OPEN_AUTOMATION=1`(打开自动化页;`Scripts/restart.sh` 不转发,需直接 `open -g -n … --env`)。`OMA_OPEN_BROWSER=<url>`(启动后打开浏览器标签并导航,演示模式/截图验证用)。`OMA_EXPLORER_DROP=<目标文件夹>|<源1>|<源2>`(按资源管理器拖放的同一流程移动/复制文件:工作区内移动、外部复制)。`OMA_BROWSER_PROBE=<输出文件>` + `OMA_BROWSER_ACTIONS="snapshot;type:e2:文本;click:e3;scroll:bottom;screenshot;console;network;tabs"`(配合 `OMA_OPEN_BROWSER`,在浏览器标签里按顺序执行 Agent 同款浏览器命令,结果写入输出文件,截图为 `<输出文件>.png`;另有 `hover:ref`、`dblclick:ref`、`rightclick:ref`、`back`/`forward`/`reload`、`network:序号`、`pickon`、`pick:ref`(合成鼠标事件选择元素并输出输入框草稿与附件))。
- 其余调试钩子(按用途分组,以 `grep -rn OMA_ Sources` 为准):日志 `OMA_LOG_LEVEL`/`OMA_LOG_TRAFFIC`;打开页面 `OMA_OPEN_FILE|LINE|DIFF|BLAME|HISTORY|PLAN|CANVAS|MERMAID|SUBAGENT|TERMINAL|CUSTOMIZE|PROJECTS`;面板 `OMA_SHOW_RIGHT`、`OMA_RIGHT_PANE`(配合 `OMA_FILES_OPEN=<相对路径>`/`OMA_FILES_TREE=expanded` 验证 Files 工作区)、`OMA_TOGGLE_RIGHT`、`OMA_SPLIT`;命令面板/搜索 `OMA_PALETTE`/`OMA_PALETTE_QUERY`/`OMA_SEARCH_QUERY`;终端 `OMA_CYCLE_TERMINALS`/`OMA_TERM_INPUT`/`OMA_TERMINAL_NAMES`/`OMA_VIEW_AGENT_TERMINAL`;编辑 `OMA_EDIT_APPEND`/`OMA_EDIT_SAVE`;其他 `OMA_AUTOSEND`、`OMA_EXPAND_ALL`、`OMA_SECTION`;性能基准 `OMA_SETTINGS_SWEEP=轮数`(依次切换全部设置页,perf 日志「设置页切换」记首帧耗时)/`OMA_RESIZE_SWEEP`/`OMA_DRAG_SWEEP`/`OMA_SCROLL_SWEEP`/`OMA_SWITCH_SESSIONS`/`OMA_SWITCH_DELAY`/`OMA_HITCH_SAMPLE`/`OMA_PERF_SAMPLE_SECONDS`(用法见性能优化记录)。
- 截图用 `screencapture -x -o -l<windowId>`;禁止用 osascript 发送按键;验证后删除截图。


- (已移除)`OMA_EDITOR_ENGINE`:旧 TextKit 引擎已删除,不再有引擎开关。
- `OMA_IDE_EDITOR_SWEEP=秒数`:IDE 窗口里对第一个原生编辑器匀速滚动并用显示链接采样帧间隔,结束输出 perf 日志「编辑器滚动基准」(frames/avgMs/maxMs/hitches/nominalMs);合成素材的内核基准见 `Scripts/editor-bench.sh`。
- `OMA_IDE_OPEN_DIFF=路径`:IDE 窗口打开后在编辑器里打开该文件的 Diff 标签;`OMA_DIFF_SCOPE=unstaged|staged|main`:预置 Diff 范围(默认「全部」)。native2 引擎下为原生并排/内联 Diff 编辑器。
- `OMA_IDE_SWITCH=路径1|路径2|…`(配合 `OMA_IDE=1`):IDE 窗口里在这些文件间循环切换并逐帧采样窗口(`IDEFrameSampler`),`OMA_IDE_SWITCH_MS`(间隔,默认 1200)、`OMA_IDE_SWITCH_ROUNDS`(轮数,默认 6)、`OMA_IDE_SWITCH_PREVIEW=1`(按单击预览方式替换)、`OMA_IDE_SWITCH_OUT=目录`(输出 `report.txt` 与「连续多帧都在变化」的片段 PNG,用来定位闪烁的中间帧);`OMA_SWITCH_SAMPLE_OUT=目录`(配合 `OMA_SWITCH_SESSIONS=N`)对会话冷开/热切同样采样,`OMA_SWITCH_DUMP_ALL=1` 保存全部帧。
