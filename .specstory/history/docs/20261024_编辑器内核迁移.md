# 编辑器内核迁移:IDE 模式换用原生 Monaco 级编辑器(native2)

> @author ixxxxoooo
> 状态:已完成(E0–E12),默认引擎已切换为 `native2`。方案原文见 `~/.cursor/plans/ide_原生_monaco_级编辑器_*.plan.md`。

## 1. 目标与路线

- 目标:IDE 模式的代码编辑器达到 Monaco 级的功能与性能(滚动丝滑、输入无感、百万行可开),**100% 原生**,不引入 WKWebView / Monaco。
- 路线 B:自研「文本绳 + 视图模型 + 自绘视图」。不再借助 NSTextView/TextKit,从根上消除整篇 `String` 往返、整体重排与属性文本开销。
- 右侧 Agent 面板:复用 `IDEAgentPane`,并补齐 Cursor 式的编辑器联动(行内 Diff 逐块保留/还原、⌘K 行内编辑、⌘L 引用选区、Composer 多文件审阅、Tab 幽灵补全、多 Agent 会话)。

## 2. 架构

| 层 | 模块 / 文件 | 职责 |
| --- | --- | --- |
| 内核(无 AppKit) | `Sources/EditorCore` | 持久化 B 树文本绳 `TextRope`(UTF-16,叶子 1008 单元,O(1) 快照)、`EditorDocument`(撤销栈、换行归一、观察者)、`SelectionSet`、`DecorationSet`、折叠 `FoldState`、视图行映射 `ViewLineMap`(Fenwick 树)、`ViewZoneLayout`、软换行 `LineWrapper`/`WrapRows`、`TextSearch`、snippet/Emmet |
| 视图模型 | `EditorKit/Native/NativeEditorModel*` | 选区、折叠、换行、超长行硬断、装饰、zone、编辑命令(自动闭合、行操作、多光标…) |
| 自绘视图 | `OMEditorView*`、`NativeLineLayout`(CoreText 行缓存) | 只绘制视口内的行;`NSTextInputClient`(输入法)、鼠标/键盘/无障碍、缩略图/粘性滚动/概览尺 |
| 语法 | `NativeTokenStore`(tree-sitter,>200 万单元走窗口词法)、`NativeBracketStore` | 后台解析,只取回视口附近片段;编辑时先平移再增量同步 |
| 语言智能 | `NativeLanguageController`/`NativeLanguageServices`/`NativePopupViews` | 补全、悬停、签名、代码操作、定义/引用、内嵌提示、语义着色、格式化 |
| Diff / Agent | `EditorKit/Native/Diff/`(`NativeDiffView`、`NativeInlineReview`、`NativeInlineEdit`)、`NativeInlineSuggestion` | 并排/内联 Diff、行内审阅、⌘K、幽灵补全 |
| 宿主封装 | `NativeCodeEditor`(SwiftUI)、`NativeEditorHandle`(右键菜单操作句柄) | 共享 `EditorDocument`,不再有整篇 `String` 往返 |
| 引擎开关 | (已删除) | 2026-10-24 起只有 native2;`EditorEngine` 与 `OMA_EDITOR_ENGINE` 已移除 |

## 3. 基准与门槛(120Hz)

入口:`Scripts/editor-bench.sh [--ab] [--check-baseline|--update-baseline]`(内部调用 `demo-bench.sh --only editor --release`),指标登记在 `DemoBenchmarkCatalog` 的 `editor.*`,基线在 `Scripts/perf-baseline.json`,旧 TextKit 冻结数据在 `Scripts/editor-baseline-textkit.json`。`OMA_CI_PERF=1 Scripts/ci.sh` 会追加该门禁。

| --- | --- | --- |
| 打开 5 万行(首帧) | ≤ 40 ms | ~14 ms |
| 5 万行可交互(首帧 + 首次按键) | ≤ 100 ms | ~15 ms |
| 打开 100 万行 | ≤ 800 ms | ~108 ms |
| 100 万行内存增量 | ≤ 92 MB(3.5× 文件) | 60–90 MB(三次取中位) |

| 滚动掉帧率 | ≤ 1 % | 0 % |
| 按键到上屏 P95 / max | ≤ 4 / 8 ms | ~3.0 / ~3.6 ms |
| 增量语法 | ≤ 2 ms | ~1.4 ms |
| 补全浮层(500 项) | ≤ 16 ms | ~5 ms |
| Agent 流式补丁(处理) | ≤ 5 ms | ~2.5 ms |

## 4. E11 调优记录

- **内存**:装载大文件改为流式切叶子(`TextRope.streaming`,无整份 UTF-16 临时数组);叶子目标取 1008 单元(2×1008+32 字节数组头恰为 2048,贴合 malloc 512 字节档位,省约 20%);`ViewLineMap` 树状数组改 Int32;大文件首次全量语法解析后主动 `malloc_zone_pressure_relief`,常驻内存不再停留在峰值(5 万行文件的真实窗口 footprint 205 → 152 MB,旧 TextKit 约 165–187 MB)。
- **基准校准**:合成素材改为流式拼接(百万个小字符串造成的堆碎片会污染内存指标);内存指标扣除窗口/缓冲固定开销并取三次中位;补全浮层改 1 ms 细粒度轮询(10 ms 睡眠粒度曾抬高测量值);Agent 补丁拆为「处理」(Diff + 区间编辑 + 行内审阅)与「绘制」(按显示帧合并)两项,编辑改为实际使用的区间编辑而非整篇替换。
- **Agent 审阅**:`setLazyZoneViews` 批量设置、惰性创建 zone 视图(只在接近视口时创建),几百个 hunk 不再创建几百个 NSView,也消除逐个设置导致的 O(N²) 重排。
- **超长行保护**:不自动换行时,超过 4000 列的行也硬断成多个视图行(`NativeEditorModel.hardWrapColumns`,后台扫描,短行零开销),避免单行数 MB 的压缩 JSON/JS 整行交给 CoreText;测试 `NativeLongLineTests`。
- **热路径**:`FoldState.hiddenRanges()` 无折叠时直接返回(视图行换算每次都会调用)。

## 5. E12 切换与偏差说明

- 默认引擎切到 `native2`。(2026-10-24 更新:Markdown 就地渲染在应用里一直没有入口,旧引擎已整体删除,Markdown 改用原生源码编辑 + 阅读预览页。)
- 补齐的对等功能:原生编辑器右键菜单(`omContextMenu` + `NativeEditorHandle`:跳转定义/引用/代码操作、行内编辑、引用选区、撤销/重做、剪切/复制/粘贴/全选、查找、格式化)。
- **偏差(已于 2026-10-24 清理,见 `20261024_旧TextKit引擎删除清单.md`)**:曾未做彻底删除——`CodeHighlighter`、`MarkdownLive`、`EditorFindBar` 等被聊天代码块、Markdown、多处测试与 `EditorSpike` 共用,强行删除风险大于收益;旧 `CodeEditor` 只剩 Markdown 与显式回退两个入口,后续随 Markdown 就地渲染迁移再清理。
- **偏差**:内存预算由「2.5× 文件」放宽为「3.5× 文件(92 MB)」——rope 以 UTF-16 存储,天然是 UTF-8 文件的 2 倍,再加行映射与叶子元数据。
- (已移除)`Scripts/demo-bench.sh` 不再转发 `OMA_EDITOR_ENGINE`;与旧引擎的对照只剩 `Scripts/editor-baseline-textkit.json` 冻结数据。
