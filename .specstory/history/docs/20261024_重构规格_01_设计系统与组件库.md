## 1. 总览

OhMyAgent 的界面层**禁止**直接使用系统语义色、SF Symbol、`.font(.system(size:))`、`.bordered` 按钮、`.contextMenu`、`.help`、`NSAlert`、`.pickerStyle(.menu)` 等绕开设计系统的写法。所有视觉与交互必须经本文件列出的令牌与组件完成；CI 通过 `Scripts/ui-lint.py --check` 扫描 `Sources/OhMyAgentApp`、`Sources/EditorKit`、`Sources/MermaidKit`、`Sources/DesignSystem`（令牌定义文件除外）。

**架构关系（ASCII）：**

```
AppearanceModel (UserDefaults appearance.*)
        ↓ 写入
ThemeRuntime + SyntaxPrefs + OMScale + MaterialPolicy
        ↓ 缓存
ResolvedTokens → OMColors.*（Observation 热更新）
        ↓
SwiftUI 视图 / AppKit 桥接（ThemeRuntime.didChange）
```

**默认体验：**

| 项 | 默认值 |
| --- | --- |
| 主题包 id | `paper-light`（显示名「Cursor 纸感」） |
| 外观模式 | `system`（跟随系统；仅「跟随系统」主题包时生效） |
| 主/次强调色 | `system`（跟随主题） |
| 界面字号缩放 | `1.0`（范围 0.85–1.3） |
| 时间线字号缩放 | `1.0`（范围 0.85–1.5） |
| 代码高亮方案 | `theme`（跟随主题语法色） |
| Diff 跟主题 | `true` |
| 流光样式 | `classic`（设置项「经典」/「流光溢彩」） |
| 滚动条 | `custom`（自绘细滚动条） |
| 玻璃回退 | 跟随系统「减少透明度」；低电量可回退（默认开启） |

## 2. 设计令牌

### 2.1 字号 `OMFonts` 与缩放 `OMScale`

**缩放来源：** `AppearanceModel` 写入 `OMScale.ui`、`OMScale.timeline`；每次变化递增 `fontRevision`，依赖 `renderKey` 的视图整体刷新。

| 令牌 | 基准字号 (pt) | 字重 | design | 缩放规则 |
| --- | --- | --- | --- | --- |
| `title` | 15 | medium | default | × `OMScale.ui` |
| `sectionTitle` | 13 | medium | default | × `OMScale.ui` |
| `body` | 13.5 | regular | default | × `OMScale.ui` |
| `small` | 11.5 | regular | default | × `OMScale.ui` |
| `caption` | 11 | regular | default | × `OMScale.ui` |
| `mono` | 12.5 | regular | monospaced | × `OMScale.ui` |
| `monoSmall` | 11.5 | regular | monospaced | × `OMScale.ui` |
| `reading` | 13 | regular | default | × `OMScale.ui` × `OMScale.timeline` |
| `readingMono` | 12 | regular | monospaced | × `OMScale.ui` × `OMScale.timeline` |
| `custom(size,weight,design)` | 传入基准 | 可指定 | 可指定 | × `OMScale.ui` |

**行高：**

- 时间线正文/代码目标行高 = 字号 × **1.5**（`readingLineHeightRatio`）。
- 额外 `lineSpacing` = `max(0, size×1.5 − 自然行高)`；自然行高由 `NSLayoutManager.defaultLineHeight(for:)` 缓存（`LineHeightCache`）。
- 便捷属性：`readingLineSpacing`、`readingMonoLineSpacing`、`readingLineSpacing(forBaseSize:)`。

**编辑性大标题（默认不用）：** `omEditorialHeading(_ level:)` — `small` 22pt / `medium` 26pt，regular，字距 -0.11 / -0.312，× `OMScale.ui`。

**规范：** 全应用字号上限字重 **medium**；禁止 semibold/bold 等（内容渲染特例需 `// ui-lint:allow`）。

### 2.2 圆角 `OMRadius` 与 `OMMetrics`

**逻辑：** 若当前 `ThemeStyle.radiusSet != nil`，取集合内 pt 值；否则 legacy：`tag=5`，`control/card` = 8/12 × `cornerScale`，`floating=14`，`modal=20`。

| 令牌 | 用途 | 纸感 `ThemeRadiusSet.paper` | Zed `.zed` | Legacy（`cornerScale=1`） |
| --- | --- | --- | --- | --- |
| `tag` | 标签、徽标、紧凑按钮、chip | 4 | 3 | 5 |
| `control` | 按钮、输入框、列表行 | 4 | 4 | 8×scale |
| `card` | 卡片、代码块、工具卡 | 4 | 6 | 12×scale |
| `floating` | 下拉、菜单 | 8 | 6 | 14 |
| `modal` | 模态、搜索窗、输入坞 | 8 | 8 | 20 |

**`OMMetrics` 固定值：**

| 属性 | 值 (pt) |
| --- | --- |
| `cardRadius` | = `OMRadius.card` |
| `controlRadius` | = `OMRadius.control` |
| `sidebarWidth` | 248 |
| `toolbarHeight` | 44 |
| `timelineMaxWidth` | 820 |
| `spacing` | 12 |
| `fileIconInline` / `fileIconList` | 14 |

### 2.3 间距 `OMSpacing`

| 令牌 | pt |
| --- | --- |
| `xs` | 4 |
| `sm` | 8 |
| `md` | 12 |
| `lg` | 16 |
| `xl` | 20 |
| `xxl` | 24 |
| `xxxl` | 32 |

### 2.4 动效 `OMMotion`

- **standard：** duration **0.15s**，timing curve **cubic-bezier(0.4, 0, 0.2, 1)**。
- 视图内过渡：`omWithAnimation(_:body:)` — 当 `AppearanceModel.reduceMotion` 或系统「减弱动态效果」为真时**直接执行 body、无动画**。

### 2.5 阴影三档

均使用 `OMColors.shadowInk`（黑色）× `ThemeRuntime.style.shadowScale`；**纸感** `flatCards == true` 时 **`omCardShadow` 不绘制阴影**（仅描边分层）。

| 修饰符 | 条件 | 参数 |
| --- | --- | --- |
| `omCardShadow(cornerRadius:yOffset:)` | 非 flatCards | 单层：opacity **0.12**，radius **12**，y **4**（可调 yOffset） |
| `omFloatingShadow(cornerRadius:yOffset:)` | 始终 | 双层：opacity **0.06** radius **18** y **6** + opacity **0.10** radius **3** y **y/4** |
| `omFloatShadow(cornerRadius:)` | 始终 | 双层：opacity **0.14** radius **28** y **10** + opacity **0.10** radius **14** y **5** |

实现为**仅外侧**阴影（mask 抠除卡片内部），浮层需预留约 **32pt** 边距防硬切。

### 2.6 形状 `OMPillShape`

- 有 `radiusSet` 的主题：圆角矩形，半径 `OMRadius.tag`。
- 无 `radiusSet`：几何等同 **Capsule**（全圆角）。
- 进度条/滑块轨道等仍可用 `Capsule()`，需 `// ui-lint:allow 滑块轨道几何`。

## 3. 颜色语义 `OMColors`

所有读取走 `ResolvedTokens.current`（键：`ThemeTracker.revision` + `ThemeRuntime.generation`），**禁止**用 `.id(theme)` 强制重建。

| 令牌 | 含义与计算要点 |
| --- | --- |
| `surface` | 内容区/时间线/编辑区背景；系统浅色 **#F6F6F7**，深色 **#1E1F22** |
| `sidebar` | 侧栏+设置左栏；系统浅色 **#EFEFEF**；主题包取 `sidebarBackground` 或 surface 与前景混合 |
| `card` | 卡片底 |
| `opaqueChrome` | 玻璃回退不透明 chrome（主题 card / 系统 windowBackground） |
| `primaryText` | 正文；主题 `editorForeground` / 系统 label |
| `secondaryText` / `tertiaryText` | 次要/三级；主题可显式 `secondaryTextColor`/`tertiaryTextColor`，否则混合推导 |
| `hairline` | 分隔线；surface 与前景混合 × `strokeScale` |
| `outline` | 输入框/次按钮描边；主题 `outline` 或 hairline |
| `accent` | 主强调色：用户覆盖 > 主题 > 系统 accentColor |
| `accent2` | 第二强调色；默认 accent |
| `accentText` | 小字号强调/链接加深色；纸感 `#C23E00` 等；缺省 = accent |
| `link` | 内联链接；纸感 = accentText，其它 often accent2 |
| `onAccent` | 强调色实底前景；纸感 Parchment 等，禁纯白 |
| `actionFill` / `onAction` | 主按钮填充/前景；纸感 `primaryButton==.ink` 时为墨色+surface 前景 |
| `actionWarm` / `onWarm` | 暖色动作（继续/计划）；默认 warning / 自动对比前景 |
| `actionPositive` / `onPositive` | 正向动作（提交/PR）；默认 success |
| `success` / `danger` / `warning` | 语义色；`diffAdded`/`diffRemoved` 通常同 success/danger |
| `subtleFill` | 前景 × **4%** × `fillScale` |
| `hoverFill` | 前景 × **7%** × `fillScale` |
| `selectedFill` | `selectionTint==.neutral`：前景 **8%**；否则 accent **14%** × `fillScale` |
| `pressedFill` | 前景 × **12%** × `fillScale` |
| `statusActive`/`Running`/`Waiting`/`Unread` | 均 accent（形状/动画区分） |
| `statusIdle` | tertiaryText |
| `scrollThumb` | tertiaryText **70%** |
| `scrollThumbActive` | secondaryText **80%** |
| `scrim` | 模态遮罩：浅色黑 **26%**，深色 **46%**（动态） |
| `shadowInk` / `maskInk` | 阴影/渐变 mask 基色（黑） |
| `chart(index)` | 8 色循环：accent, accent2, success, warning, keyword, type, danger, function |
| `contentBackground` | 等同 `surface` |
| `systemContentBackground` / `systemSidebar` | 与是否选主题包无关，供预览 |

### 4.5 自定义主题 JSON `CustomThemeFile`

**路径：** `{AppEnv.supportDirectory}/themes/{id}.json`（开发版目录带 `-Dev` 后缀）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `version` | Int | 仅支持 **1** |
| `id` | String | 保存时规范为 `custom-{sanitized}` |
| `name` | String | 显示名，非空 |
| `base` | String | `"light"` / `"dark"` → 基线 `ThemePalette.lightBase` / `darkBase` |
| `colors` | `[String:#RRGGBB]` | 键见下表 |
| `ansi` | `[String]?` | 可选，**必须 16** 个有效 hex |
| `style` | `[String:Double]?` | `cornerScale` 0.3–1.6, `strokeScale` 0.3–2, `shadowScale` 0–2, `glassTint` 0–0.3, `fillScale` 0.5–2 |

**可覆盖颜色键：** `surface`, `card`, `sidebarBackground`, `editorBackground`, `editorForeground`, `gutterBackground`, `gutterForeground`, `currentLine`, `accent`, `accent2`, `success`, `danger`, `warning`, `diffAdded`, `diffRemoved`, `keyword`, `string`, `comment`, `number`, `type`, `function`, `property`。

**缺省行为：** 仅给 `surface` 时 `editorBackground` 跟随；无 `sidebarBackground` 时按明暗混合推导。

**示例：**

```json
{
  "version": 1,
  "id": "my-theme",
  "name": "示例主题",
  "base": "dark",
  "colors": {
    "surface": "#1B1A16",
    "accent": "#F54E00",
    "keyword": "#83D6C5"
  },
  "style": {
    "cornerScale": 0.8,
    "strokeScale": 1.2,
    "shadowScale": 0.6,
    "glassTint": 0,
    "fillScale": 1
  }
}
```

（注：JSON `style` **仅**支持上述五个键；`allowsGlass` / `flatCards` / `radiusSet` / `primaryButton` / `selectionTint` **不能**通过 JSON 设置，继承 `base` 对应 `lightBase`/`darkBase` 的默认 `ThemeStyle.standard`。）

### 12.2 `SmoothWheel`

**档位（`SmoothWheelLevel`，偏好 `appearance.smoothWheelLevel`，默认 `light`）：**

| 档位 | 存储 raw | τ (s) | 体感 |
| --- | --- | --- | --- |
| 轻快 | `light` | **0.07** | 衰减最快 |
| 标准 | `standard` | **0.11** | — |
| 柔和 | `soft` | **0.17** | 衰减最慢 |

**共享常量（`SmoothWheelModel`）：** `pixelsPerLine = 36`；`maxRemaining = 6000` px；`epsilon = 0.5` px。

**算法要点：** 离散滚轮经 `lineDelta`（\|Δ\|&lt;1 行补足 ±1 行）× `pixelsPerLine` 写入 `remaining*`；反向滚动清零旧剩余；每帧 `fraction = 1 - exp(-dt/τ)` 指数衰减取整像素；`CADisplayLink` 驱动，`maxFrameTime = 1/20 s` 封顶单帧 dt；合成事件 marker `0x4F4D5357`、无 scroll phase；触控板/精确滚动/带修饰键滚轮不拦截。

- 偏好 `appearance.smoothWheel`（默认 **true**）、`appearance.smoothWheelLevel`。
- 仅离散鼠标滚轮；触控板/精确滚动/修饰键放行。
- 合成事件 marker `0x4F4D5357`；CADisplayLink 衰减；点击取消惯性。

| 常量 | 值 |
| --- | --- |
| hitThickness | 9 |
| lineThickness | 1 |
| activeThickness | 2（accent 35%/55%） |

竖线分隔左右（cursor ↔↕）；拖动用**屏幕坐标**；阈值 **1pt** 起拖；支持 optional 双击。

## 20. 重构注意事项

1. **令牌热更新：** 读 `OMColors` 即订阅 `ThemeTracker`；不要用 `.id(themePackage)` 整树重建。
2. **ResolvedTokens 缓存：** 主题/强调色/direct ThemeRuntime 变更需 `ThemeRuntime.bump()`。
3. **玻璃性能：** 会话流大量行用 `omSolidChrome`，避免每行 `glassEffect` 采样。
4. **循环动画：** 必须经 `OMLoopGated` + Core Animation，避免 SwiftUI 15ms 定时器。
5. **Picker/Menu 面板：** 必须 `canBecomeKey` 才能搜索/键盘；childWindow 生命周期与 focus 归还。
6. **侧栏色：** `#EFEFEF/#F6F6F7` **仅**系统+Cursor 浅色；其它主题必须自带 sidebarBackground。
7. **纸感 flatCards：** 卡片阴影关闭，靠 outline/hairline 分层。
8. **ui-lint 与特例：** 任何豁免必须行内注释原因，禁止整文件豁免。
9. **Icon 回退 SF Symbol：** 仅作容错，重构目标应消除未知 symbol。
10. **CustomTheme style 字段：** 当前无法表达 `allowsGlass`/`flatCards`/`radiusSet` — 自定义主题玻璃行为继承 dark/light 基线。

### 22.2 纸感 `selectionTint` 与 `paper-dark` 对比度

| 项 | 源码事实 |
| --- | --- |
