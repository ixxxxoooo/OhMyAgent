## 1. 总览

### 1.1 产品定位（本规格范围）

Agent 主窗口是 **SwiftUI `Window` 场景**（id `"main"`），一个窗口对应一个 `WorkbenchModel` 实例。窗口内根视图为 `WorkbenchView`，在两种模式间切换：

| 模式 | `WorkbenchMode` | 根视图 |
| --- | --- | --- |
| 工作台 | `.workspace` | 三栏 + 顶部浮层 + 全局 overlay（搜索窗、Mermaid、图片预览等） |
| 设置 | `.settings` | 整页 `SettingsView`（通过设置入口进入，「返回」回到工作台） |

本规格 **不写** 会话时间线、输入区、编辑器正文、Git/搜索面板 **内部** 交互（由文档 03/04 负责），只写它们在窗口中的 **位置、尺寸约束、标签外壳与布局联动**。

### 1.2 视觉令牌（与本窗口强相关）

| 用途 | 令牌 / 常量 | 说明 |
| --- | --- | --- |
| 项目栏背景 | `OMColors.sidebar` | 纸感浅色侧栏 `#EFEEE9`（须 ≠ `surface`） |
| 中栏 / 右栏内容区背景 | `OMColors.surface` | 纸感内容区 `#F7F7F4` |
| 顶栏 / 标签条高度 | `TitlebarMetrics.height` = **35 pt** | 标签栏、侧栏顶条、右栏头部统一 |
| 标签条背景 | `OMColors.surface` | 与中栏一致 |
| 面板显隐动画 | `0.22 s`，曲线 `(0.25, 0.1, 0.25, 1)` | 仅面板 `transition`；拖动改宽无动画 |
| 紧凑窗口阈值 | `CompactLayout.threshold` **780** / 退出 **820** | 自动收起左右栏 |

### 1.3 组件树（工作台 `.workspace`）

```
WorkbenchView
├── workspaceBody
│   ├── GeometryReader → HStack(spacing: 0)
│   │   ├── [左] panelColumn(.sidebar) + PanelResizer
│   │   ├── [中] CenterColumn → DockView(host: .center)
│   │   └── [右] PanelResizer + panelColumn(.tools)  // 顺序由内向外
│   ├── overlay(topTrailing): RightRail（条件显示）
│   ├── overlay(top): TitlebarOverlay
│   ├── overlay: TerminalDropOverlay
│   └── onGeometryChange → TerminalDragState.workspaceFrame
├── overlay: HubOverlay / MermaidFloatingOverlay / ImagePreviewOverlay
├── frame(minWidth: 480, minHeight: 480)
└── CompactLayout 宽度档位监听
```

## 2. 窗口形态与场景

### 2.1 SwiftUI 场景声明

| 项 | 值 |
| --- | --- |
| 场景类型 | `Window("OhMyAgent", id: "main")` |
| 默认尺寸 | **1280 × 820** pt（`.defaultSize`） |
| 窗口样式 | `.windowStyle(.hiddenTitleBar)` |
| 内容最小尺寸 | **480 × 480** pt（`WorkbenchView.frame(minWidth:minHeight:)`） |
| 系统标题 | `.navigationTitle` 动态：`activeSession.sessionTitle` → `selectedEntry.name` → `"OhMyAgent"`（仅 Mission Control / 辅助功能） |

**刻意不用** `.unifiedCompact` 空工具栏：系统 `NSTitlebarView` 会横跨顶部并吞掉点击，导致浮层按钮不可点。

### 2.2 无标题栏与红绿灯（WindowChrome）

`WindowChrome.apply(to:)` 在窗口成为 key 时重复调用（`WindowFocusReader`）：

| 属性 | 值 |
| --- | --- |
| `titlebarAppearsTransparent` | `true` |
| `titleVisibility` | `.hidden` |
| `styleMask` | 含 `.fullSizeContentView` |
| `isMovable` | 默认 **`false`**（避免标签/面板标题误拖窗） |
| 红绿灯 | **保留显示**；强制 `standardWindowButton` 及其 superview `alphaValue = 1` |

**拖动窗口**：

- 专用 `WindowDragArea`（NSView）：按下即 `performDrag`，**双击** `performZoom`（系统缩放行为）。
- SwiftUI `windowDragGesture()`：用于标签栏尾部空白等（`contentShape` + 手势，避免被 SwiftUI 吞掉）。

### 2.3 顶栏 35 pt 与红绿灯让位

常量见 `TitlebarMetrics`：

| 常量 | 值 (pt) |
| --- | --- |
| `height` | 35 |
| `trafficLightInset` | 88（左上浮层 leading padding） |
| `buttonSize` | 26 |
| `buttonSpacing` | 2 |
| `modeSwitchWidth` | 124（Agent「IDE ↗」/ IDE「Agents Window ↗」共用，防切换窗口时右侧跳动） |
| `sidebarSwitchWidth` | `buttonSize * 2 + buttonSpacing` = **54** |
| `sidebarSwitchInset` | 8 |

左簇宽度公式（`leftClusterWidth(toggles:collapsed:)`）：

- 按钮数 = `(collapsed ? 2 : 3) + toggles`（toggles 为左侧面板开关数，项目栏/工具栏各 1）。
- 宽度 = `trafficLightInset + buttonSize × count + buttonSpacing × (count - 1)`。
- `toggles == 1` 且未 collapsed 时总宽约 **198 pt**（注释对齐 Cursor：红绿灯 → 侧栏开关 → 搜索 → 后退 → 前进）。

右簇宽度（`rightClusterWidth(toggles:includesModeSwitch:)`）：

- 无模式切换：`buttonSize × toggles + spacing + 8` 尾边距。
- 含模式切换：`buttonSize × toggles + modeSwitchWidth + spacing + 8`。

### 2.4 全屏与扩展右栏

| 行为 | 说明 |
| --- | --- |
| 系统全屏 | 未单独定制；跟随 `NSWindow` 标准行为 |
| `rightExpanded` | **临时**状态（**不持久化**）：右栏可见且用户点「扩展全屏」时，中栏 `maxWidth = 0`、`opacity = 0`、`allowsHitTesting = false`，右栏占满「除项目栏外」宽度；右栏收起或 `rightVisible = false` 时自动 `rightExpanded = false` |
| 扩展 + 项目栏也收起 | 右栏 `padding(.top, TitlebarMetrics.height)`，避免红绿灯/左浮层盖住标签条 |

### 2.5 应用级联动

| 行为 | 条件 |
| --- | --- |
| 关闭最后窗口后是否退出 | `applicationShouldTerminateAfterLastWindowClosed` → **`!ClientPrefs.trayEnabled()`**（托盘开启则驻留菜单栏） |
| 点击 Dock 图标无可见窗口 | `applicationShouldHandleReopen` → `AppActions.showMainWindow()` |
| 鼠标侧键 | 按钮 3 后退 / 4 前进（`MouseNavigationMonitor`，Agent 工作台且非 IDE 路由时） |

## 3. 整体三栏骨架与尺寸规则

### 3.1 ASCII 线框（默认：项目栏左、工具栏右）

```
┌─ NSWindow (min 480×480, default 1280×820) ─────────────────────────────┐
│ [●●● 红绿灯 ~88pt 让位区]  TitlebarOverlay 浮层 (高 35pt, 全宽)          │
├──────────┬─────────────────────────────────────┬──────────────────────────┤
│ 项目栏   │ PanelResizer │    中栏 Dock       │ PanelResizer │ 右栏 Dock │
│ sidebar  │   1pt 柄     │  (center)          │   1pt 柄     │  tools    │
│ 宽 Wl    │              │  min 400pt         │              │  宽 Wr    │
│ 200–520  │              │  (可扩展时被压 0)   │              │ 240–动态  │
│ 默认 260 │              │                     │              │ 默认 480  │
└──────────┴─────────────────────────────────────┴──────────────────────────┘
     ↑ 可 hidden (leftVisible)                      ↑ 可 hidden (rightVisible)
```

> **项目栏宽度**：源码 `PanelMetrics.leftRange` = **200…520 pt**（默认 260）。全文与矩阵均以此为准。

**列顺序**（由 `WorkbenchLayout.placement` 决定物理左右）：

- 左侧：`visibleColumns(on: .left)` → 仅 `.sidebar` / `.tools` 中落在 left 的列，**由外向内**。
- 右侧：`visibleColumns(on: .right)` **reversed** 渲染 → **由内向外**（靠近中栏的 tools 先画，sidebar 在最外缘时在外侧）。

### 3.2 PanelMetrics（源码为准）

| 维度 | 范围 / 默认值 | 说明 |
| --- | --- | --- |
| 项目栏 `leftRange` | **200 … 520** pt | 注释：须容纳左浮层 ~198pt |
| 项目栏默认 `leftDefault` | **260** pt | |
| 右栏 `rightRange` 下限 | **240** pt | 上限持久化兜底 10000；**实际上限**见下 |
| 右栏默认 `rightDefault` | **480** pt | |
| 中栏最小 `centerMinimum` | **400** pt | 拖宽右栏时中栏不低于此值（超出部分 clip） |
| 右栏动态上限 `rightMax(window:sidebar:)` | `max(240, window - sidebar - 400)` | 拖动/布局时用 `TerminalDragState.workspaceFrame.width` |
| 终端列表宽 `terminalListRange` | 120 … 320，默认 **180** | 右栏终端标签内 |
| Files 树宽 `filesTreeRange` | 200 … 480，默认 **260** | Files 工作区内 |

### 3.3 列宽计算（WorkbenchView.panelColumn）

拖动中：`PanelDragState.effective(dimension, committed: layout)`，**不每 tick 写** `WorkbenchLayout`。

显示宽度：

```
others = 其它可见列宽度之和 + 分隔条(每列 1pt)
width = min(stored, max(0, total - centerMinimum - others - 1))   // 非 expanded
expanded 时右栏: width = max(0, total - others - 1)
```

### 3.4 OMSplitHandle / PanelResizer（侧栏分隔条）

| 项 | 行为 |
| --- | --- |
| 位置 | **左栏**：列右侧（靠中栏）；**右栏**：列左侧（靠中栏） |
| 拖动 | `onBegan` 记 base；`onChanged` 只写 `PanelDragState`；`onEnded` → `commitPanelDrag` |
| 方向 | 左栏：`base + translation`；右栏：`base - translation` |
| 双击 | 项目栏：恢复 **defaultWidth**；右栏：`PanelMetrics.doubleClickTarget` — 若当前 ≠ 默认则回默认，若已是默认则 **min(max(window/2, default), maximum)** |
| 无障碍 | Label「调整左栏宽度/右栏宽度」；AdjustableAction 步进 **20 pt** |
| zIndex | 2（盖在面板内容上） |

### 3.5 面板显隐动画与性能

| 项 | 值 |
| --- | --- |
| 动画 | `.move(edge: leading/trailing)`，**无淡入淡出**；`omShouldReduceMotion()` 时为 `.identity` |
| 禁止 | 对整个 `HStack` 加动画（会导致中栏每帧变宽、会话全量重排） |
| zIndex | 面板列 1，分隔条 2；滑出时面板仍盖在中栏上 |

### 3.6 CompactLayout（窄窗口）

| 阈值 | 行为 |
| --- | --- |
| 宽度 **< 780** | 进入 compact：若 `leftVisible`/`rightVisible` 为 true 则收起，并记 `autoCollapsedSidebar` / `autoCollapsedTools` |
| 宽度 **≥ 820** | 退出 compact：仅恢复「仍是收起且标记为自动收起」的栏 |
| 780–820 | **回差区**，不改变 compact 状态 |
| 用户手动 | 在 compact 期间手动打开的栏，拉宽后 **保持** 用户选择 |

实现：`onGeometryChange` 只观察宽度 **Bucket**，避免拖动时每帧写 layout。

### 3.7 PanelPlacement（换边）

| 字段 | 默认 | 持久化键 |
| --- | --- | --- |
| `placement.sidebarSide` | `.left` | `workbench.json` → `layout.placement.sidebarSide` |
| `placement.toolsSide` | `.right` | `layout.placement.toolsSide` |

**拖放换边**：

- 载荷：`oma-panel:sidebar` / `oma-panel:tools`（`PanelItem`）。
- 落点：指针在工作区内，**x < width/2 → 左栏 zone**，否则右栏（`PanelZone`）。
- 高亮：目标侧 **25%** 宽度矩形（`edgeFraction = 0.25`）。
- 触发：`TerminalPlacementViews` — 「工作区」分区标题 `terminalDragHandle`；设置页 `LayoutDragEditor` 卡片 drag。

## 4. 顶部标题栏浮层 TitlebarOverlay

浮层 **盖在整个工作区顶部**，按钮坐标 **不随** 侧栏展开/收起变化。

### 4.1 左簇（leading = trafficLightInset）

顺序（项目栏在左且可见时）：

1. **项目栏开关** — 图标 `panel-left`；文案 `WorkbenchPanelNames.toggleTitle(.sidebar, visible:)` →「隐藏项目栏」/「显示项目栏」；快捷键 **⌘B**（可自定义，`ShortcutAction.toggleSidebar`）。
2. **搜索** — `search`；文案「搜索 (⌘K)」→ `HubModel.present(.all)`。
3. **回退 / 前进** — `arrow-left` / `arrow-right`；enabled 绑定 `nav.canGoBack/Forward`；**侧栏收起时隐藏**，改为 **「+」新对话**（仍可用快捷键回退/前进）。

侧栏收起判定：`workbench.layout.visibleColumns(on: .left).isEmpty`。

### 4.2 右簇（trailing padding 8）

由内向外（`toggles(on: .right).reversed()`）：

1. **工具栏开关** — `panel-right`；「隐藏工具栏」/「显示工具栏」；**⌘⌥B**（`toggleInspector`）。
2. **扩展** — 仅 `column == .tools` 且工具栏 **已可见**：`maximize-2` / `minimize-2`；「扩展全屏」/「还原」→ `rightExpanded.toggle()`。
3. **模式切换** — 非会话模式（`leftPane != .sessions`）显示 `ModeSwitchButton(target: .ide)`：文案 **「IDE」** + `external-link`；宽 **124 pt**；**⌃⌘I**；**⌥ 点击**强制新开 IDE 窗口。

**会话模式**（`leftPane == .sessions`）：若工具栏未打开，**不显示**工具栏开关与 IDE 按钮；若工具栏已打开仍显示开关以便关闭。

### 4.3 OverlayButton 样式

| 项 | 值 |
| --- | --- |
| 图标尺寸 | Lucide **14 pt** |
|  hit 区域 | **26 × 26** |
| 悬停 | `OMColors.pressedFill` + `OMRadius.tag` |
| 禁用 | `tertiaryText` 60% 不透明 |

### 4.4 标签栏让位 titlebarInsets

`WorkbenchLayout.titlebarInsets(for:)`：

- **项目栏**本身顶区已是空白，**不让位**。
- **右栏 tools** 若为该侧 **最外缘可见列**：trailing = `rightClusterWidth(toggles + 扩展按钮, includesModeSwitch: true)`；leading 若贴左缘则含左簇宽。
- **中栏** `TabGroupView`：若左右面板都收起，标签条 leading/trailing 用 collapsed 左簇宽 + 右簇（含模式切换）。

## 5. 左侧项目栏 ProjectTreeView

背景：`SidebarBackground()` → `OMColors.sidebar`。

### 5.1 纵向结构

```
VStack(spacing: 0)
├── SidebarTopStrip          // 35pt 拖动区 + 模式切换
├── navigation               // 主操作三行
├── SidebarWindowedList      // 分区 + 会话/项目行（窗口化虚拟滚动）
└── footer                   // 设置 + 更新 + 徽章
```

### 5.2 SidebarTopStrip

| 项 | 行为 |
| --- | --- |
| 高度 | 35 pt 透明 + `WindowDragArea` |
| 模式切换 | 右侧 `SidebarModeSwitch`（若 `sidebarSwitchFitsInStrip`） |
| 放不下 | 模式切换 **换行**到下方一行，`padding horizontal 10, bottom 6` |
| _fit 判定_ | `leftClusterWidth(toggles) + sidebarSwitchWidth + sidebarSwitchInset ≤ sidebarWidth`，且浮层压在侧栏上（侧栏在右时不压） |

### 5.3 SidebarModeSwitch（会话 / 代码）

| 按钮 | 图标 | 文案（tooltip / a11y） | 选中态 |
| --- | --- | --- | --- |
| 会话模式 | `messages-square` | 「会话模式」 | `selectedFill` + `primaryText` |
| 代码模式 | `code` | 「代码模式」 | 同上 |

逻辑：`workbench.switchLeftPane(_:)` — 见 [14.3 侧栏模式记忆](#143-侧栏模式与-pane-记忆)。

**会话模式列表**：仅 `isChatArea` 项目（通用会话）。  
**代码模式列表**：`workspaceProjects`（真实项目 + 会话树）。

### 5.4 主操作区 navigation

容器：`padding horizontal 10, bottom 8`，行间距 **2**。

| 标题 | 图标 | 快捷键显示 | 行为 |
| --- | --- | --- | --- |
| 新对话 | `square.and.pencil` | 新对话快捷键（默认 **⌘N**） | `newConversationInContext()` |
| 自动化 | `workflow` | — | `openAutomation()` → 中栏标签 |
| 自定义 | `sliders-horizontal` | — | `openCustomize()` → 中栏标签 |

`NavRow`：高 **30 pt**，水平 padding 10，圆角 `OMRadius.control`，hover `hoverFill`；图标 14 pt 在 16 pt 槽内。

### 5.5 分区与行类型（SidebarRow）

| 行 kind | 内容高度 | cellHeight（含 2pt 间距） |
| --- | --- | --- |
| title / session / project | 30 | 32 |
| hint / more | 24 | 26 |

**分区顺序**（`sidebarRows`，受 `SidebarScope` 过滤）：

1. **置顶** — 标题「置顶」；跨项目 `pinnedSessions` 合并。
2. **会话**（仅 chat scope）— 标题「会话」+ 右侧 `message-circle-plus`「新会话(无需项目)」。
3. **工作区**（仅 code scope）— 标题「工作区」+ 折叠全部/筛选/添加项目；标题行带 **面板拖动手柄**。

**空状态文案**：

| hint | 文案 |
| --- | --- |
| noGeneral | 「还没有会话,直接提问即可」 |
| noWorkspace | 「添加一个项目目录,或把文件夹拖到这里。」 |
| noSessions | 「暂无会话」 |

**显示更多**：

- 文案：未展开「显示更多(还有 N 条)」/ 展开「收起」。
- 默认条数：项目下 **5** 条；通用会话列表 **20** 条；有 viewport 时 **3…15**（项目）/ **5…60**（通用）自适应。

### 5.6 项目行 ProjectHeaderRow

| 项 | 值 |
| --- | --- |
| 行高 | **30 pt** |
| 左缩进 | horizontal 8 |
| 图标 | `ProjectIconView`（可自定义 icon） |
| 工作树 | `git-fork` 11 pt + tooltip「Git 工作树 · {branch}」 |
| 置顶 | `pin.fill` 9 pt |
| 多根工作区 | `+N` caption（`extraFolders.count`） |
| 右侧 | 悬停显示 `plus` 22×22「在 {name} 下新对话」；固定保留宽 **24 pt** |
| 点击 | 折叠/展开项目 `toggleCollapsed`（snappy 0.18s） |
| tooltip | 项目路径缩写 |

**右键菜单（项目）**：

- 新对话；选中此项目
- — 取消置顶/置顶；更换图标…；重命名项目…（仅侧栏名）；编辑工作区…；在 Finder 中显示；在 IDE 中打开（子菜单）；拷贝路径
- — 全部标为已读；归档全部会话
- — 移除项目（destructive）

### 5.7 会话行 SessionLine

| 项 | 值 |

## 15. 重构注意事项

1. **浮层 vs 原生标题栏**：任何放回 `NSTitlebarView` 的方案都会重现「顶部按钮点不动」；浮层必须独立于侧栏宽度动画。
2. **PanelDragState**：侧栏拖动时不得每 tick 赋值整个 `@Observable WorkbenchModel.layout`，否则标签条/时间线全局失效（已用临时宽度 + 提交模式）。
3. **中栏宽度**：必须用外层 Geometry 算死列宽；HStack 均分会卡死右栏约半窗宽。
4. **侧栏开关动画**：只对面板 transition；中栏宽度应一次到位。
5. **TabKeepAlive + 隐藏会话**：隐藏标签仍占焦点链时曾导致秒级卡顿；冻结尺寸 + 降预算至 5 权重。
6. **会话模式隐藏中栏标签栏**：切换模式时 dock 整树交换，勿在错误模式回收会话（`otherDocks` 顺序）。
7. **跨区 moveTab**：必须先目标 dock open 再源 close，否则 chat 会话被回收。
8. **CompactLayout 与用户手动**：用 autoCollapsed 标记区分，避免拉宽后强行展开用户故意收起的栏。
9. **Git 轮询**：RightRail / RightDock 在右栏收起时仍可能跑 watch，避免重复高频 refresh。
10. **主题**：中栏 `themeRevision` 整列 `.id` 重建；终端进程不在此列销毁。

## 17. 未覆盖 / 待确认项

1. **⇧⌘T 与右栏**：关闭栈含右栏标签，但恢复仅中栏 `dock.open`——若产品要求「在原 host 恢复」需改 `reopenClosedTab`（现状见 02b §B.8）。
2. **红绿灯精确像素**：`trafficLightInset 88` 为经验让位，未绑定系统 titlebar 布局 API；多版本 macOS 需实测。
3. **全屏 / Stage Manager**：无专用布局分支；融合模式在全屏时 **不** 原地换框（`fusionSource` 为 nil）。
4. **极窄宽度 (<200+400)**：声明中栏 min 400 与窗口 480 并存时，HStack 可能 clip；极端组合需 UI 实测。
