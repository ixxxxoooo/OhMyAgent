## 1. 总览

### 1.1 范围

本文档描述 **Agent 工作台对话区底部** 的完整用户可见行为：输入框（Composer）、其上方浮动卡片（权限/提问/计划/目标/任务坞/用量）、页脚（分支/连接状态/用量环/Agent 切换），以及 **ChatKit `SessionModel`** 驱动的会话级能力（发送、排队、引导、斜杠命令、历史、休眠、标题、上下文用量等）。

### 1.2 模块边界

| 层级 | 职责 |
| --- | --- |
| `OhMyAgentApp` | SwiftUI/AppKit 视图：Composer、Dock、Footer、面板、MCP 浮层 |
| `ChatKit` | 无 UI：`SessionModel`、补全引擎、本地命令、审批策略、注意力 |
| `WorkbenchKit` | 多项目/标签、会话驻留休眠调度 |
| `DesignSystem` | 令牌：`OMFonts`/`OMColors`/`OMRadius`、玻璃 `omGlass`、按钮 `OMButtonStyle` |

### 1.3 默认视觉（Cursor 纸感 `paper-light`）

- 输入卡片：`omGlass(in: RoundedRectangle(cornerRadius: OMRadius.modal))`；纸感主题 `allowsGlass == false` 时为不透明 Bone + 发丝线（见 UI 规范 4.4）。
- `OMRadius.modal`：纸感 **8pt**，旧主题 20pt。
- 输入区内边距：水平 **12pt**，垂直 **8pt**；VStack 子项间距 **6pt**。
- 正文字号：输入框 AppKit 字体 **13pt**（非 `OMFonts` 令牌，与 `body` 13.5 接近）；工具条控件 **`OMFonts.small`（11.5）**。

## 2. 对话区布局与输入栈

### 2.1 ChatView 三区关系

- **非空会话**：上方 `ScrollView` 时间线 + 下方 `composerStack`（贴底）。
- **空会话**（`timeline.entries.isEmpty && !isReplaying`）：时间线隐藏，输入栈 **垂直居中**（上下 `Spacer`，底部额外 **72pt** 留白使视觉上移）。

### 2.2 宽度

- 内容最大宽度：`ChatWidth.resolve(raw: chat.width, custom: chat.widthCustom)`（默认档位 `standard` = **820pt**）。
- 空会话时 Composer 最大宽度：`min(contentMaxWidth, ChatWidth.narrow.points)` = **680pt**。
- `composerStack` 水平 padding：**16pt**；非空会话底 padding：**12pt**。

### 2.3 composerStack 自上而下（线框）

```
┌──────────────────────────────────────── composerMaxWidth ────────────────────────────────────────┐
│  [PermissionCard × N]  权限待批（有则显示，可多个并列）                                            │
│  [ElicitationCard]     提问向导（队列首条 + 「还有 N 个待回答」）                                  │
│  [ConnectionFailureCard]  仅 phase == .failed                                                │
│  [PlanDock]            待办折叠卡（时间线最后一条 plan 条目）                                     │
│  [GoalChip]            /goal 目标条                                                            │
│  ┌─ ContextUsagePanel ──────────────────── 悬浮，不占布局高度 ─────────────────────────────┐   │
│  │  锚点：height=0 的 Color.clear + overlay(alignment: .bottom) 向上展开                      │   │
│  └──────────────────────────────────────────────────────────────────────────────────────────┘   │
```

### 2.4 用量面板关闭

- 点击 `OMColors.surface` 背景、或时间线 overlay（面板展开时）→ 关闭用量面板（`usageOpen = false`）。
- 调试：`OMA_USAGE_PANEL=1` 启动即展开。

## 3. Composer 输入卡片

### 3.1 组件树

```
ComposerView
├── VStack(spacing: 6)
│   ├── ScrollView(.horizontal) → AttachmentThumbnail × N  [size 56, spacing 8, top padding 2]
│   ├── ComposerTextView
│   └── HStack(spacing: 6) 工具条
│       ├── OptionMenu(category: "mode", icon: "slider.horizontal.3")
│       ├── OptionMenu(category: "model", icon: "cpu")
│       ├── ContextWindowMenu
│       ├── OptionMenu(category: "thought_level", icon: "brain")
│       ├── MCPPanelButton
│       ├── Spacer(minLength: 8)
│       ├── Text「连接后发送:…」  [queuedPrompt 存在时]
│       ├── PromptOptimizeButton
│       └── sendButton (停止 + 发送)
├── padding h12 v8
├── omGlass(modal 圆角)
├── overlay 补全 CompletionPopup
├── onDrop 文件/图片 + 拖入高亮边框
└── overlay 拖入提示 pill「松开以添加图片或引用文件」
```

### 3.2 输入框高度

| 项 | 值 |
| --- | --- |
| 初始 `textHeight` | **34pt** |
| 最小高度 | **34pt**（`max(used + inset*2, 34)`） |
| `textContainerInset` | 宽 **4**，高 **6** |
| 默认 `maxHeight` 参数 | **220pt** |
| 动态上限 | `min(max(windowHeight * 0.4, 120), 320)`；超出后出现垂直滚动条 |
| 字体 | 系统 **13pt** regular |

### 3.3 占位符文案（随状态变化）

| 条件 | 占位符 |
| --- | --- |
| `connecting` 且 `connectNote != nil` | 显示 `connectNote` 原文 |
| `phase == .failed` | 「Agent 未连接,发送将尝试重新连接」 |
| 默认空闲 | 「输入消息,@ 引用文件,/ 使用命令」 |
| 运行中 + 发送键 Return + 可引导 + 偏好 steer | 「运行中:Return 引导 {agentName},⌘Return 排到本轮之后」 |
| 运行中 + 发送键 Return + 可引导 + 偏好 queue | 「运行中:Return 或 ⌘Return 排到本轮之后发送」 |
| 运行中 + 发送键 ⌘Return + steer | 「运行中:⌘Return 引导 {agentName},Return 换行」 |
| 运行中 + 发送键 ⌘Return + queue | 「运行中:⌘Return 排到本轮之后发送,Return 换行」 |

连接中占位：`connectNote` 由 Agent 侧设置（如安装适配器）。

### 3.4 发送 / 停止按钮

**玻璃主题**（非纸感）：

- 停止：`Image.om("stop.fill", 11, bold)`，**26×26**，`.buttonStyle(.glass)` 圆形，`omTooltip("停止 (Esc)")`，`accessibilityLabel("停止生成")`。
- 发送：空闲 `arrow.up` / 运行中 `corner-down-right`，**26×26**，`.glassProminent`，无内容 `disabled`，`keyboardShortcut(ShortcutStore.send)`，`accessibilityLabel` 运行中为「引导当前轮次」否则「发送」。

**纸感主题**（`primaryButton == .ink` 或 `!allowsGlass`）：

- `ComposerPaperStopButton`：危险色 `stop.fill`，圆底 `primaryText` 6%/12% 悬停，描边 `hairline` 0.5。
- `ComposerPaperSendButton`：Ink 填充 `actionFill`，无内容时 8% 灰底；图标 `arrow.up` / `corner-down-right` 12pt bold。

**显示逻辑**：

- 运行中：始终显示停止；发送按钮在 **有内容**（草稿非空或附件非空）时显示。
- `hasContent` =  trim 草稿非空 **或** `attachments` 非空。

**Tooltip（sendHelp）**：

- 空闲 Return 发送：「发送 (Return),Shift+Return 换行」
- 空闲 ⌘Return 发送：「发送 (⌘Return),Return 换行」
- 运行中 steer + Return：「引导当前轮次 (Return);⌘Return 排到本轮之后」
- 运行中 steer + ⌘Return：「引导当前轮次 (⌘Return);Return 换行」

### 3.5 拖放高亮

- 整张卡片注册 `onDrop`：`UTType.fileURL`、`.image`。
- 文本区 AppKit 另注册拖放；`cardDropTargeted || textDropTargeted` 时：
  - 边框：`accent` **1.5pt** 虚线 `[6,4]`，`OMRadius.modal`。
  - 顶部 pill：caption + `actionFill` 背景，`offset y: -12`，文案「松开以添加图片或引用文件」。

### 3.6 工作树首条发送

- 若 `runInWorktree == true` 且时间线空、草稿非空、非斜杠命令：清空草稿/附件、关 `runInWorktree`，调用 `WorktreeActions.sendInWorktree`（失败则恢复草稿）。

### 3.7 Esc

- 运行中：`ComposerTextView.onEscape` → `model.cancel()`。

## 4. ComposerTextView 键盘与粘贴拖放

### 4.1 发送键（与设置 `chat.sendKey` 同步）

| `SendKey` | Return（无修饰） | ⌘Return | Shift+Return / Option+Return |
| --- | --- | --- | --- |
| `enter`（默认） | **发送** `onSubmit` | **排到本轮后** `onSubmitAfterTurn` | 换行 |
| `commandEnter` | 换行 | **发送** | 换行 |

- 输入法 **组合态**（`hasMarkedText()`）时不拦截 Return/补全键。
- 补全激活时：↑↓ 切换、Return/Tab 接受、Esc 关闭（见 §5.3）。

### 4.2 Shift+Tab

- `onBacktab` → `SessionModel.cycleMode()` 循环权限模式。

### 4.3 粘贴 / ⌘V

- 可读类型：string、fileURL、png、tiff、jpeg、heic。
- 优先图片 → `onImages`；非图片文件 → `onFileURLs`；否则纯文本。
- `prefersImage`：有图片文件必图片；仅 bitmap 时若剪贴板有「实质文字」则走文字。
- 图片解码失败且无文字：beep，不插入空内容。

### 4.4 复制 / 剪切

- 选区导出为 **纯文本**（chip 还原为 `@路径`）。

### 4.5 非激活标签拖放

- `tabIsActive == false` 时 `unregisterDraggedTypes()`，避免隐藏标签抢拖放。

### 4.6 无障碍

- `accessibilityLabel`：「消息输入框」。

## 5. 补全系统

### 5.1 触发

| 触发 | 条件 |
| --- | --- |
| `/` | 光标前整段以 `/` 开头，且 **命令段无空白**（整行单命令） |
| `@` | 最近 `@` 在开头或空白后，且 `@` 到光标间 **无空白** |

- 用户 Esc 关闭后：同一份草稿文本不再弹出，直到草稿变化（`dismissedAt`）。

### 5.2 候选来源（`SessionModel.completionItems`）

**斜杠**（`CompletionEngine.slashItems`）：

1. **客户端命令**（`LocalCommands.catalog`），徽标「客户端」。
2. **Agent 通告** `availableCommands`（过滤 `__` 前缀、`hiddenFromCompletion`）。
3. Agent 空列表时兜底：`ClaudeBuiltinCommands` + 本机 `SlashEntry`（Skills/自定义/MCP）。

**提及**（异步文件索引）：

- `@browser`（工具）
- 子 Agent（`agentCatalog`）
- 文件（最多 24）+ 文件夹（最多 8）

### 5.3 浮层 CompletionPopup

| 属性 | 值 |
| --- | --- |
| 宽度 | **420pt** |
| 行高 | 候选 **36pt**，分节标题 **22pt** |
| 最大高度 | **320pt**（可滚动） |
| 背景 | `OMColors.card` + `OMRadius.card` + `hairline` + `omCardShadow` |
| 位置 | 输入卡片 **左上**，`offset(x:4, y:-(height+8))` |
| 动画 | items 变化 `easeOut 0.12s`（减弱动态时关闭） |

**键盘**（补全激活且无修饰键）：↑↓ 循环选中、Return/Tab 接受、Esc 关闭。

**鼠标**：点击行 `onPick`；选中行背景 `selectedFill`。

**分节标题**：多类别且各类别在列表中 **连续** 时才显示 groupTitle；斜杠命令按相关度交错时不分节。

**行内容**：文件/夹 `OMFileIcon` 15→框 18；其他 Lucide 图标；`badge` pill；`subtitle` caption 截断。

### 5.4 接受补全

- 斜杠 / 子 Agent / browser：插入文本后若无 trailing 空格则 **补空格**。
- 文件：`CompletionEngine.mentionInsertText` → 含空白则 `@\"path\" `，目录 trailing `/`，末尾空格。

### 5.5 FuzzyMatcher 排序

- 子序列匹配；首字符 +8、词边界 +5、驼峰边界 +4、连续 +4、间隔扣分。
- 最终分：`score * 4 - min(len,200)/8`。
- 同分顺序：`localCommand(0) < customCommand(1) < agentCommand(2) < skill(3) < mcpPrompt(4)`，再比原始索引。

## 6. 内联提及、附件与图片灯箱

### 6.1 草稿与 chip

- **`SessionModel.draft`** 始终为带 `@路径` 的 **纯文本**。
- TextStorage 中每个 chip 占 **1** 个 UTF-16 附件字符；`ComposerMentionLayout` 做坐标换算。
- 仅当提及 **后跟空白**（或 `allowTrailingEnd` 且在文末）才渲染 chip，避免输入中途被替换。
- chip 与相邻文字插入时自动补空格，防止 `@a.swiftx` 破坏 token。

### 6.2 拖入 / DropClassifier

- 图片扩展名：png,jpg,jpeg,gif,webp,heic,heif,tif,tiff,bmp → 附件；其余 file/directory → `@提及`。
- 工作区内 **相对路径**；含空白 → `@\"…\"`；目录 trailing `/`。

### 6.3 图片附件限制

| 项 | 值 |
| --- | --- |
| 单条消息最多 | **8** 张 |
| 单图上限 | **5 MB**（`ImageAttachment.maxBytes`） |
| 不支持 Agent | notice「当前 Agent 不支持图片输入,图片未添加。」 |
| 过大 | notice「图片太大(上限 5 MB),已忽略:{name}」 |

### 6.4 AttachmentThumbnail

- 默认 **56×56**（输入区）；`OMRadius.control` 圆角；点击 → `ImagePreviewStore.present`。
- 悬停显示移除（输入区传入 `onRemove`）：右上角 **17×17** 反色圆钮 `x`。
- Tooltip：「点击查看原图」。

### 6.5 灯箱 ImagePreviewOverlay

- 全窗口 `maskInk` **72%** 遮罩；点击遮罩或图片外关闭。
- 交互：平移、滚轮/⌘滚/捏合缩放、双击适应/100% 切换；工具栏图标：缩小、放大、适应、复制、下载、关闭。
- 动画：`easeOut 0.15s`。

## 7. 提示词优化

### 7.1 PromptOptimizeButton（工具条右侧）

| 状态 | 图标 | Tooltip |
| --- | --- | --- |
| 空闲可优化 | `wand-sparkles` 12 | 「优化提示词」 |
| 优化中 | `OMSpinner.mini` | 「正在优化提示词,点击取消」 |
| 可撤销 | `undo-2` | 「撤销优化,还原原文」 |

- 按钮区域 **20×20**；不可优化且非上述状态时 **disabled**。

- 成功：替换 `draft`；若优化期间用户改草稿则不覆盖。

### 7.2 模型

- 设置 `prompt.optimizeModel`（`UtilityModelChoice`）；映射开启时走网关小模型槽位，否则 `claude -p` 无工具会话。

## 8. 任务坞 ComposerDock 与待办 PlanDock

### 8.1 出现条件

- 排队条数 + 后台子 Agent + 后台终端 **总数 > 0**；否则高度 0 并重置 `dockHidden`。

### 8.2 胶囊 DockChip

- 高度 **26**，水平 padding **11**，`OMGlassLabel` pill；图标 **11**，计数 `tertiaryText` monospaced。
- 文案：**排队** / **子 Agent** / **终端**；图标 hourglass / bot / terminal。
- 点击：选中分区展开面板；再点同一胶囊 → `dockHidden = true`（仅留胶囊）。
- 动画：`snappy 0.18s`。

### 8.3 面板

- `omGlassCard`；标题行高 **32**，左右 padding **12**。
- 标题文案：
  - 排队：「{n} 条排队,本轮结束后发送」
  - 子 Agent：「{n} 个子 Agent 运行中」+ 按钮「停止本轮」→ `cancel()`
  - 终端：「{n} 个终端运行中」+ 若有非外部终端「全部终止」
- 关闭：**x** 22×22，「收起」。

## 14. 发送、排队、引导与运行中策略

### 14.1 正常发送 `send`

1. 空文本且无图 →  return。
2. 无图且匹配 `LocalCommands` → `perform`，不发 Agent。
3. **运行中**：
   - `!afterTurn && canSteer && runningSendMode == .steer` → **steer**（ACP `_session/steering`）；成功时间线用户消息 `steered: true`。
   - 否则 → **enqueueFollowUp**（排队）。
4. **非运行**：
   - ready 且存档同步中 → 存 `queuedPrompt`/`queuedImages`。
   - ready → `start`。
   - idle/failed/connecting → 排队 + `connect()`。

### 14.2 全局偏好 `chat.runningSend`

| 值 | 含义 |
| --- | --- |
| steer（默认） | 运行中 Return/发送 → 引导（不支持则排队） |
| queue | 运行中 → 一律排队 |

设置页文案：「引导当前轮次」/「排到本轮结束后」；Note 说明 steer 不支持时自动排队。

### 14.3 第三态「打断并发送」

- **非全局偏好**；仅排队面板在 **`isRunning && !canSteer`** 时显示「打断并发送」。
- `interruptAndSend`：设 `interruptSendID`，`cancel()`，轮次结束后发该条。

### 14.4 连接排队 UI

- 工具条 caption：「连接后发送:{queued}」单行省略。

### 14.5 ⌘Return 语义

- 见 §4.1：`onSubmitAfterTurn` → `sendDraft(afterTurn: true)` 强制排队路径（即使 steer 偏好）。

### 14.6 canSteer

`capabilities.canSteer && phase == .ready && sessionId && client`。

## 15. 会话生命周期

### 15.1 新建 / 清空

- `/new`、`/clear`、侧栏新对话、`newConversation()`：同项目新 ACP session；清 timeline、标题、goal、排队、用量等；`EmptySessionRegistry.hide(newId)`。

### 15.2 切换引擎

见 §10.4；偏好 `chat.lastAgent`。

### 15.3 历史

- `refreshHistory`：`capabilities.canList`；过滤 `EmptySessionRegistry`；标题合并 `session.titleOverrides` + `session.generatedTitles`。
- `/resume`、菜单选择 → `openSession(summary)`（细节见 Workbench/侧栏规格）。
- `prepareRestore`：idle 时预登记，避免闪「新对话」。

### 15.4 标题

- 首条消息：`TitleGenerator.fallbackTitle` 截取 → 异步生成 3–8 字（`generatedTitles`）。
- 手动 `/rename` 或侧栏：`session.titleOverrides`。
- 优先级：manual > adapter > generated > truncated。

### 15.5 存档与回显

- 长会话：`archiveHiddenTurns`、EarlierTurnsRow、`loadEarlierArchive`（SessionModel+Archive；面板行为见时间线规格）。

### 15.6 休眠 / 唤醒

| 设置键 | 默认 |
| --- | --- |
| session.hibernateEnabled | true |
| session.idleHibernateMinutes | **10**（0=从不） |
| session.maxLiveSessions | **3**（0=不限） |
| session.hibernateUnderPressure | true（收紧为 1min + maxLive 1） |

- `hibernate()`：杀 Agent 进程，保留 timeline/draft/标题；有对话则 `dormantSessionId` 供 resume。
- `wake()`：输入非空草稿或发送时触发；hibernated 时 `setConfigOption` 等走 `whenAwake` 队列。
- **不休眠**：运行中、待权限/提问、后台 shell（`canHibernate` 假）、可见标签。

### 15.7 空白会话

- `isPristine`：无对话 + 空草稿 + 无附件 → 复用标签。
- `hasNoConversation`：仅 notice 或空 → 切换 Agent 原位替换。

### 15.8 状态点 OMSessionDot（侧栏/托盘）

| kind | 视觉 | 语义 |
| --- | --- | --- |
| running | 实心呼吸 0.6s | statusRunning |
| waiting | 空心环呼吸 0.9s | statusWaiting |
| unread | 静止小实心 | statusUnread |
| idle | 灰点 | statusIdle |

| 数据 | 存储位置 | 持久化 | 恢复/保留规则 |
| --- | --- | --- | --- |
| 文本草稿 `SessionModel.draft` | 内存（`WorkbenchModel.conversations[ConversationKey]`） | **否**（不落盘） | 切换本会话标签保留；关闭标签或杀进程丢失；重启后只恢复 `sessionId`（`chatSlots`），草稿需用户重输或从 Agent 历史侧间接恢复 |
| `@` chip 展示 | 草稿纯文本 + TextStorage 附件字符 | 同上（实质是 draft） | chip 由 `ComposerMentionLayout.pieces` 在输入框渲染；发送后 draft 清空 |
| 图片 `attachments: [ImageAttachment]` | 内存 | **否** | 随 SessionModel；发送时清空；切换 Agent（无实质对话）时 `replaceSession` 带到新引擎 |
| 选区引用 | 写入 `draft`（`EditorReference.appending`） | **否** | IDE/编辑器「在对话中引用」追加 token，不单独存盘 |
| 输入框内选区 `selectedText` | 内存 | **否** | 供 Bridge/自动化读取，不写 UserDefaults |

**Workbench 落盘**：`AppEnv.supportDirectory/workbench.json` → `WorkbenchState.chatSlots: [ChatSlotRecord]`；**不含** draft/attachments。

**休眠**：`hibernate()` 明确保留 timeline、**draft**、标题、sessionId；唤醒后 draft 仍在。

**调试 `OMA_DRAFT`**（`WorkbenchView` 启动任务）：等待 `activeSession` 最多约 8s → `workbench.activeSession?.draft = env`；常与 `OMA_AUTOSEND` 联用。`OMA_ATTACH_IMAGE=path1:path2` 给当前会话加附件。

### 21.2 任务坞状态与分区

| 字段 | 类型 | 持久化 | 说明 |
| --- | --- | --- | --- |
| `dockSelection` | `ComposerDockSection?` | **否** | 用户上次点的胶囊分区 |
| `dockHidden` | `Bool` | **否** | `true` = 只显示胶囊、不显示面板；计数归零时 `onAppear` 重置为 `false` |

**展开规则**（`ComposerDockSection.effective`）：`hidden == true` → 无面板；否则若 `selection` 对应分区 `count > 0` 用 selection；否则 **按 enum 顺序**（queued → subagents → terminals）取第一个 `count > 0` 的分区。

**空态**：`queued + subagents + terminals == 0` → 整个 `ComposerDockView` 高度 0，不显示胶囊（无文案空状态）。

**三分区准入条件**（非「后台命令」独立区；后台 Bash 归 **终端**）：

| 分区 | 计数来源 | 空时 |
| --- | --- | --- |
| 排队 | `followUps.count` | 胶囊隐藏 |
| 子 Agent | `timeline.runningBackgroundSubagents()`（仅 **后台** 运行中子 Agent，含嵌套 depth） | 胶囊隐藏 |
| 终端 | `terminals.values.filter(\.showsInDock)`：`showsInDock = isRunning && (!isExternal \|\| isBackground)` | 胶囊隐藏 |

面板标题见 §8.3；子 Agent/终端行每秒刷新 liveMeta。

### 21.3 `/goal` 与 GoalChip

**GoalState 字段**（`SessionModel.swift`）：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `objective` | `String` | 目标正文 |
| `startedAt` | `Date` | 客户端记录开始时间 |
| `isActive` | `Bool` | 目标仍在推进（所在轮次未结束） |

**状态来源（仅客户端）**：

1. 用户发送以 `/goal` 开头的消息且参数非空 → `trackGoal`：参数为 `clear/stop/off/reset/none/cancel`（不区分大小写）→ `goal = nil`；否则 `goal = GoalState(..., isActive: true)`。单独 `/goal` 无参 **不** 改状态（仅 Agent 侧查看）。
2. 轮次正常结束 → `finishTurn` 里若 `goal?.isActive` → 置 `isActive = false`（目标条显示「已结束」）。
3. `newConversation` / 打开其他会话 / `openSession` 路径会 `goal = nil`。
4. GoalChip 点 x → `clearGoal()`：若仍 active 则 `send("/goal clear")` 给 Agent，并 `goal = nil`。

**GoalChip UI**（`ChatStatusViews.swift`）：高 30，horizontal 12；`target` 图标 12（active → `accent`，否则 `secondaryText`）；目标 1 行；pill「进行中」/「已结束」caption + `pressedFill`；x 清除；`omGlassCard(floating)`；tooltip = 完整 objective。

**不同步**：Adapter 不推送结构化 goal；`/status` 若本地有 goal 会列一行，但与 Agent 内存可能不一致。

### 21.5 融合模式与 IDE Agent 面板草稿

| 模式 | `agentSession` | 草稿同步 |
| --- | --- | --- |
| **融合开启** `general.fusionMode` | `workbench.sessions[projectID]`（与 Agent 窗口 **同一** `SessionModel`） | 同一对象：`draft`/`attachments` 天然一致；IDE 与 Agent 各渲染一套 `ChatView`，Observation 同步 |

### 21.6 输入区键盘与 IME（无历史上翻）

| 按键 | 条件 | 行为 |
| --- | --- | --- |
| Return / KP Enter | 无 IME 组合态；补全未拦截 | 见 `chat.sendKey`：enter→发送，commandEnter→换行 |
| ⌘Return | 无 IME | enter 模式→发送；commandEnter 模式→**排到本轮后** `onSubmitAfterTurn` |
| Shift+Return / Option+Return | 无 IME | 换行 |
| Esc | 无 IME | 运行中 **取消轮次**；Composer 绑定 `model.cancel()` |
| ↑ / ↓ | 补全激活、无修饰 | 补全候选 |
| Tab (48) | 补全激活 | **接受**补全（非 Shift+Tab） |
| Shift+Tab | 无 IME | **循环权限模式** `cycleMode()` |
| ⌘V | `SubmitTextView` 拦截 | 粘贴图片/文件/纯文本 |
| 其他字符 | IME 组合态 `hasMarkedText()` | **不**拦截 Return/补全/Esc；走系统 IME |
| 补全 Esc (53) | 补全激活 | 关闭补全，同 draft 不再弹 |

**无** 输入框「上一条消息历史上翻」实现（↑ 仅在补全浮层生效）。

**菜单快捷键**：`.send` 默认 **⌘Return**（`ShortcutAction`），触发 SwiftUI `submit()`，与 Enter 偏好独立。

**发送键设置**（设置 → 输入）：`Return 发送,Shift+Return 换行` / `⌘Return 发送,Return 换行` → 键 `chat.sendKey`。

### 21.7 模型选择器与模式 Menu

**数据来源**：运行时 `SessionModel.configOptions` 中 `category == "model"|"mode"|"thought_level"`（ACP `set_config_option` 刷新）。选项 **`name`/`value` 由 Agent 通告**，非写死列表。

**模型 OMPickList**（宽 300，placeholder「搜索模型」）：

- **搜索字段**：`ModelPickerRow.searchText` = name + detail + copyText + group 拼接。
- **当前项**：`currentValue.stringValue` 与 row.id（或去前缀后的 value）比较 → `isSelected`。
- **厂商图标**：`BrandIcon.resolve(modelId:providerPreset:providerName:)`；映射行用 `MappedModel`；原生 Claude 组固定 `claude`；菜单 fallback `cpu` 14pt。
- **空列表**：`OptionMenu` 在 `rows.isEmpty` 时 **不渲染**该控件。

**分组生成**（`OptionMenu.modelPickerRows`）：

1. 无 `configuredMappings` + 映射未启用：Agent `option.options` 全列，id=value。
2. 无 mappings + 映射启用：只列 `mappedModels` 有值的槽位。
3. 有 mappings：「Claude Code 原生(~/.claude)」`native:{value}`（映射启用时名称用 **槽位 title**）+「自定义映射」`mapped:{value}`（须 `configuredMappings[slot]` 存在）；选中态：映射启用时 mapped 组 isSelected，否则 native 组。

**模式 Menu**（原生 `Menu` 例外）：每行 Agent `option.name` + 当前项 `check`；标签色 = `ModeTone.tone(forMode: currentValue)` → §10.1 令牌色；**无**单独说明 subtitle（名称即 Agent 文案）。

### 21.8 排队行按钮真值表

前提：行仅当 `followUps` 含该项时出现；**编辑/删除**始终可用（悬停显示）。

| `isRunning` | `canSteer` | 主按钮文案 | 点击行为 | 禁用/无操作 |
| --- | --- | --- | --- | --- |
| false | — | **发送** | `sendFollowUpNow` → 直接 `send` | — |
| true | true | **引导** | 从队列移除 → `steer`（**忽略** `chat.runningSend` 偏好） | 若 `!canSteer` 不会出现本行 |
| true | false | **打断并发送** | `interruptAndSend` → `cancel()`，轮次结束后发该条 | — |

**对比：输入框直接发送（非排队行）**

| `isRunning` | `afterTurn` | `canSteer` | `runningSend` | 行为 |
| --- | --- | --- | --- | --- |
| false | — | — | — | 正常 `start` / 连接排队 |
| true | false | true | steer | **steer** |
| true | false | true | queue | **enqueueFollowUp** |
| true | false | false | * | **enqueueFollowUp** |
| true | true | * | * | **enqueueFollowUp**（⌘Return 路径） |

`canSteer` = `capabilities.canSteer && phase == .ready && sessionId && client`（Claude ACP 通常 true；OpenCode 等可为 false）。

## 22. 重构注意事项

1. **输入栈顺序固定**：权限/提问必须在 Composer 之上，否则运行中无法先批权限；PlanDock/Goal 在 Dock 之上便于扫一眼任务。
2. **空会话居中但 Composer 勿重建**：ChatView 用同一 `composerStack` 结构，避免首条消息发送时丢焦点/草稿。
3. **双通道拖放**：SwiftUI 卡片 + AppKit 文本区都要回报 `dropTargeted`，否则高亮闪烁。
4. **Claude `/context`**：用量面板禁止 fallback 到对话内 `/context`（每次 ~2.5k token 永久进上下文）；必须走 `_session/context_usage`。
5. **setConfigOption 并发**：新建会话应用偏好时必须 **串行** await，否则后到的旧列表覆盖新模型/模式。
6. **steer vs queue vs interrupt**：三者条件不同；OpenCode 等无 steer 时 UI 必须暴露「打断并发送」。
7. **隐藏标签拖放**：`tabIsActive` 注销 AppKit 拖放，否则 opacity 0 的输入框仍抢事件。
8. **chip 与 plainText 双坐标**：补全、`SessionModel.draft`、发送提及时 **只用 plainText**；存储坐标仅 UI 渲染。
9. **EmptySessionRegistry**：Antigravity 类 Agent 空 session 污染侧栏；首条消息务必 `unhide`。
10. **性能**：补全文件搜索走 `FileIndex` 异步；上下文刷新避免运行中重复 probe。
