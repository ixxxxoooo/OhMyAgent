## 1. 总览与标签分发

### 1.1 入口

| kind | 视图 | 背景 |
| --- | --- | --- |
| `.chat` | `ChatPane` → `ChatView` | `OMColors.surface` |

| `.agentTerminal` | `AgentTerminalTabView` | surface |

**`.preview(id)` 分支**(固定 id 常量见 `WorkbenchModel`):

| id 模式 | 内容 |
| --- | --- |

## 2. 文件标签与编辑器

### 2.1 名称与触发

- **名称**: 文件标签 / 内嵌 Files 编辑器  
- **打开**: 资源管理器单击(预览)、双击(固定)、Hub ⌘P、搜索命中、拖放 URL、`workbench.openFile`  
- **目标**: `fileOpenTarget` 设置(默认右栏;⌥ 反向);Files 内嵌走 `ExplorerHooks.openFile`

### 2.2 FileHeaderBar

| 元素 | 尺寸/样式 | 文案/图标 | 行为 |
| --- | --- | --- | --- |
| 后退/前进 | 图标 13pt,按钮区 24×22,圆角 `OMRadius.tag` | `arrow-left`/`arrow-right`, tooltip「后退」「前进」 | Files 内嵌 `FilesHeaderControls` |
| 面包屑 | `OMFonts.monoSmall`, 分隔符 `›` tertiary | 段名;末段 primary,目录 secondary | 点击 `BreadcrumbButton` → 下拉宽 **280**, 搜索、↑↓、回车、Esc |
| 模式切换 | HeaderIconButton | `eye`(切源码) / `code`(切阅读) | tooltip「切换到预览」「切换到源码」 |
| 右键(整条路径) | `omContextMenu` | 「在中栏打开」「在 Finder 中显示」「拷贝路径」 | 中栏打开时 `FilesWorkspaceStore.closeIfCurrent` |

**对比 HEAD**(普通文件标签,非 Files 通栏时由 `FileTabView` 传入): `onToggleCompare` 非 nil 时显示切换;叠加 `GitFileDiffView(embedded: true)` 于编辑器上。

### 2.3 FileDocumentStore

| 项 | 值/行为 |
| --- | --- |
| 可编辑上限 | **5_000_000** 字节;超出 `isReadOnly`, 横幅:「文件超过 5 MB,以只读方式打开」 |
| 编码 | UTF-8 → UTF-16 BOM → GB18030;含 NUL 视为二进制 |
| 脏标记 | rope `editorDirty` 或 `text != savedText` |
| 镜像同步 | 停止输入 **250ms** 后 rope → `text` |
| 外部修改 | 无脏:静默重载;有脏:`externalChange`, 横幅「文件已在磁盘上被修改,与你的未保存编辑冲突」,按钮「重新载入」「保留我的」 |
| 轮询 | 活动标签 `WorkspaceWatchCenter.follow(path, poll: 2s)` |

持久化: 文档在内存;保存原子写盘,保留原 encoding。

### 2.4 Agent 行标记与 Git 行号栏(IDE)

- **Agent 标记**: 时间线最近 `FileChange` 为 pending/partiallyReverted,且缓冲区仍等于 Agent 写入文本 → 新增行 `LineMarker.agent`(优先于 Git)  
- **Git gutter**(仅 `ideHost != nil`): 相对 HEAD,UTF-8 ≤ **2MB**, 防抖 350ms;标记 added/modified/removed  
- **Blame 内联**: IDE 且文档非脏时有 `blameLines` 行末注释

### 2.5 编辑器偏好绑定(FileTabView)

| UserDefaults 键 | 默认 | 作用 |
| --- | --- | --- |
| `editor.lsp` | true | LSP |
| `editor.minimap` | true | 缩略图(IDE chrome) |
| `editor.wrap` | true | 软换行 |
| `editor.largeFileLines` | 20000 | 超过则禁用 wrap(防主线程卡死) |
| `editor.autoClose` 等 | 见 §5 | 行为 |

**IDE chrome**: `[stickyScroll, folding, overviewRuler]` + 可选 `.minimap`;Agent 窗口 `chrome: []`(无缩略图/粘性/折叠 UI 由设置? — Agent 侧 chrome 空,仅 IDE 宿主显示 minimap 等)。

顺序与快捷键(来自 `nativeEditorMenuEntries`):

## 3. Files 工作区

### 3.1 名称与入口

右栏标签 `ToolsPane.files` 或拖入中栏的 `ToolsTabView`;**不是**独立 `TabKind`,而是 `preview(toolsPaneID)`.

### 3.2 布局线框

```
┌─────────────────────────────────────────────────────────────┐
│ header h=30 (有 current 时完整 FileHeaderBar + list-tree)    │
├──────────────────────────┬──┬──────────────────────────────┤
│ leftContent              │▐│ ExplorerView                  │
│ minWidth 240             │ │ treeWidth 200…480 (默认 260)  │
│ FileTabView 或 Empty     │ │ 可 collapse (layout flag)     │
└──────────────────────────┴──┴──────────────────────────────┘
```

- 分栏: `OMSplitHandle`;双击复位宽度 → `PanelMetrics.filesTreeDefault`(260)  
- `filesTreeCollapsed`: `WorkbenchLayout`,持久化在工作台 JSON  
- 树宽: `PanelMetrics.filesTreeRange` = **200…480**

### 3.3 导航语义

- **单击树**: `FilesWorkspaceModel.open` → `FilesNavStack`(与全局 `NavHistory` **独立**)  
- **双击/⌥单击**: 独立文件标签,`oppositeTarget` 规则  
- **状态**: `FilesWorkspaceStore` 按 **projectID** 内存;无 JSON 持久化(切换项目再回来看当前文件)  
- **最近文件**: `RecentStore.recordFile`;空状态展示最多 **8** 条

### 3.4 空状态 FilesEmptyState

- 文案:「搜索文件或路径…」按钮 → Hub(带 `fileOpener` 原地打开)  
- 「新建文件…」→ `ExplorerActions.create`  
- 最近文件列表

## 5. 原生编辑器内核(OMEditorView)

### 5.1 组件树(逻辑)

```
NativeCodeEditor (SwiftUI)
└─ OMEditorView (AppKit)
   ├─ NativeEditorModel + EditorDocument (EditorCore rope)
   ├─ NativeTokenStore / HighlightEngine (词法 + tree-sitter)
   ├─ NativeLanguageController (补全/悬停/签名/灯泡)
   ├─ NativeInlineSuggestion (幽灵补全)
   ├─ inlineEdit (行内 AI 编辑)
   ├─ EditorFindBar (NSHostingView)
   ├─ NativeMinimapView (宽 84pt)
   └─ sticky scroll / overview ruler / folding
```

### 5.2 尺寸与视觉

| 令牌 | 值 |
| --- | --- |
| 默认 gutter 宽 | 56pt(随行号位数动态) |
| 折叠列宽 | 14pt |
| 缩略图宽 | **84**;行高 **2**;列宽 **1**;最多 **80** 列/行 |
| 字体 | `EditorFontPrefs`: 默认 **12pt**,范围 **11–20** |
| 行高 | 13pt 字 → **18pt** 行高,等比缩放 |
| 选区色 | 主题 `ThemePalette` / 纸感选区 `#8BC4F8` 角色 |
| 当前行 | `EditorBehaviorPrefs.currentLine` → `EditorTheme.currentLine` |
| 括号匹配 | `EditorBehaviorPrefs.bracketMatch` |
| 空白字符 | `editor.renderWhitespace`(默认 selection); 设置页无 UI — 见 [05c §2](./20261024_重构规格_05c_标签页补遗.md#2-编辑器设置与空白字符) |
| Git/诊断 overview | `EditorChrome.overviewRuler` |

### 5.3 SyntaxLanguage 与 tree-sitter

**词法语言枚举**: swift, javascript, typescript, python, json, markdown, shell, rust, go, java, c, yaml, plain, html, css, sql, ruby, php, lua, toml, dockerfile(扩展名映射见 `Syntax.swift`).

**tree-sitter 语法**(增量高亮): swift, javascript, typescript, python, json, rust, go, css, html — 文本 UTF-16 长度 ≤ **2_000_000** 否则退回词法.

### 5.4 EditorChrome 与设置

| 键 | 默认 | 功能 |
| --- | --- | --- |
| `editor.minimap` | true | 缩略图 |
| `editor.stickyScroll` | true | 粘性滚动 |
| `editor.inlayHints` | false | LSP 类型内联 |
| `editor.ghostCompletion` | false | 幽灵补全 |
| `editor.autoClose` | true | 自动闭合括号引号 |
| `editor.currentLine` | true | 当前行高亮 |
| `editor.bracketMatch` | true | 括号配对 |

设置页:**设置 → 编辑器**(`EditorPage`);含字体、wrap、大文件行数、跟随 Agent、自动保存(IDE)、语法方案 `SyntaxScheme`.

## 6. EditorCore 行为级说明

> 实现细节不要求重写;以下为产品行为契约.

| 能力 | 行为 |
| --- | --- |
| TextRope | 持久化文本结构,O(log n) 编辑 |
| EditorDocument | 单路径共享(`EditorDocumentRegistry`);撤销栈 per 文档;版本号递增供 LSP |
| 撤销/重做 | 恢复选区;与 UI ⌘Z 绑定 |
| ChangeOrigin | user / undo / redo / external |
| 外部 apply | Agent 写盘、reload → `external`,可 markSaved |
| SelectionSet | 多光标;primary + secondary |
| 折叠/装饰 | 视图模型;折叠隐藏行范围 |
| ViewZone | 只读嵌入区(如 diff 块) |

## 15. 重构注意事项

1. **Agent vs IDE 文件宿主**: `ideFileHost` 环境值分流脏标记、LSP 状态条、Git gutter、blame、chrome;重构须两套 QA.  
2. **终端视图唯一实例**: `TerminalContainerView.claim` 防止多窗口抢 SwiftTerm 视图(见 05b).  
3. **大文件**: 5MB 只读、2万行禁 wrap、2MB 禁 Git gutter、2M UTF-16 禁 tree-sitter.  
4. **主题渗透**: 编辑器背景用 `EditorTheme`/`ThemePalette.editor*`, 禁止 `Color.primary`.  
5. **Hub 主题预览**: 必须在 dismiss 时回滚或提交,避免「预览污染」.  
6. **Files 与标签历史分离**: 勿把 FilesNavStack 与全局标签后退混为一谈.  
7. **性能**: Explorer 窗口化行列表;Hub 异步 rank;Search 索引 `WorkspaceIndexModel`.
