## 1. 源代码管理 SCMView

### 1.1 入口

- 右栏 `RightPane.git` 或中栏 `ToolsTabView(pane: .git)`  
- 无项目:空状态「没有项目」/「添加一个项目后,这里会显示它的 Git 状态。」

### 1.2 布局线框

```
┌─────────────────────────────────────────┐
│ [多根] 仓库切换条 h=28 (可选)            │
├─────────────────────────────────────────┤
│ header pad 10×6                         │
│  [分支▼]  Spacer  busy?  [↓pull][↑push] [⋯]│
├─────────────────────────────────────────┤
│ commitBox pad 10                        │
│  状态行 + 提交说明 TextField            │
│  [✨ AI] + Commit 主按钮 + [▼]          │
├─────────────────────────────────────────┤
│ changeList (分组 ScrollView)            │
│  Agent 改动 / 冲突 / 已暂存 / 更改 / 未跟踪 │
└─────────────────────────────────────────┘
 errorBanner? (底部)
```

### 1.3 头部控件

| 控件 | 文案/图标 | 行为 |
| --- | --- | --- |
| 分支菜单 | `git-branch` + 分支名 + chevron | `OMPickList` 宽 **260**, 搜索分支;本地/远程分组;「新建分支…」→ `GitDialogs.prompt` placeholder `feature/xxx` |
| 拉取 | `arrow-down` + behind 数 | `model.pull()` |
| 推送 | `arrow-up` + ahead 数 | `model.push()` |
| 更多 ⋯ | 见下 | 原生 Menu 嵌套 |

**分支标题变体**: 正常分支名 / 「游离 HEAD」/ 「无提交」

**更多菜单项**(原文):

- 获取(fetch)  
- 拉取并 rebase(无 upstream 时 disabled)  
- 中止合并(destructive,有冲突时)  
- 刷新  
- 在标签页打开提交历史  
- 删除分支(子菜单,destructive)  
- 暂存当前更改到 stash…  
- Stash 子菜单(应用 pop / 丢弃)

### 1.4 提交区

| 元素 | 说明 |
| --- | --- |
| 状态 | 「工作区干净」或「未提交 +±行数 · N 个文件」 |
| 输入框 placeholder | `Message (⌘↩ to commit on "<分支>")` |
| ⌘↩ | 提交(与主按钮同) |
| AI 按钮 | 设置 `scm.aiCommitMessage` 默认 **true**; `sparkles`; tooltip「根据改动与最近提交风格生成提交说明」 |
| 主按钮 | 无暂存:「Commit」;有暂存:「Commit (Staged)」;Amend:「修补提交」;图标 `check` |
| 下拉 | Commit & Push / 修补上一条提交 (Amend) / 暂存全部并提交 |
| syncMode | 无可提交内容时:「同步更改 ↓n ↑m」或「发布分支」 |
| 警告 | 「存在冲突,解决后才能提交。」; amend+已推送:「上一次提交已推送,修补后需要强制推送。」 |

**无暂存提交**: 确认框「没有已暂存的更改,提交全部 N 个文件?」/「将先暂存所有改动(包含未跟踪文件)再提交。」按钮「提交全部」

**偏好**:

- `scm.coAuthor` — Co-authored-by 署名(默认关)  
- `scm.collaborators` — JSON 协作者名单  
- `scm.aiCommitMessage` — AI 按钮

### 1.5 改动列表 SCMSections

分组(顺序见 `SCMSections.swift`):

1. **本轮 Agent 改动**(若有) — 链到会话 `FileChange`  
2. **合并冲突** — 冲突文件  
3. **已暂存**  
4. **更改**(已跟踪未暂存)  
5. **未跟踪**

行交互:

- 点击文件 → 打开 Git diff 或 Agent diff 标签(视上下文)  
- 行内按钮: 暂存/取消暂存、打开、丢弃(confirm)  
- 右键 `omContextMenu`: 打开、暂存、取消暂存、丢弃、在 Finder 显示等(见 `SCMView`/`SCMSections` 567 行附近)

### 1.6 刷新与数据

- `GitStore.shared.model(for: root)` 每仓库一个 `GitModel`  
- 可见时 `WorkspaceWatchCenter.followProject` 轮询 **5s** + 文件系统事件  
- `phase`: unknown → spinner; notRepository → 说明; ready → 内容

## 2. Git 历史 / Blame / 提交 Diff

### 2.1 GitHistoryTabView(`TabKind.history`)

**线框**(上下分栏,非 HSplit):

```
┌─────────────────────────────────────┐
│ 提交列表 + 泳道图  height ≥50% 窗口   │
├─────────────────────────────────────┤
│ 选中提交: 文件列表 + diff 预览        │
└─────────────────────────────────────┘
```

| 状态 | 文案 |
| --- | --- |
| 加载 | spinner |
| 非仓库 | 「不是 Git 仓库」/「这个项目还没有 Git 历史。」 |
| 无提交 | 「还没有提交」/「提交后这里会显示历史。」 |
| 错误 | 「无法读取历史」+ 详情 |

- 初始加载 **200** 条;滚动哨兵 +200  
- 「所有分支」切换 `allBranches`  
- 泳道色:`OMColors.chart(0..5)`  
- 右键提交: 复制 hash、checkout、cherry-pick 等(见 `GitHistoryView` 148/316 行菜单)  
- 打开方式: SCM 更多菜单 / Explorer Git 历史 / 命令

### 2.2 GitBlameTabView(`TabKind.blame`)

- 只读 blame 列 + 文件内容(与 IDE blame 内联不同,整页视图)  
- 打开: Explorer「Git Blame」/ 命令「查看当前文件的 Git Blame」

### 2.3 GitCommitDiffTabView(`TabKind.commitDiff`)

- 参数: `root`, `commit`, `path`  
- 展示某提交内单文件相对父提交的 diff  
- id: `"\(commit)#\(path)"` 防复用状态

## 3. Git 文件 Diff 与工作区 Diff

### 3.1 GitFileDiffView

用于: 独立 Git diff 标签;**嵌入** FileTabView「对比 HEAD」(`embedded: true` 隐藏部分按钮).

**Header**:

- 路径(缩写) + ±行数  
- 范围分段:「全部 / 已暂存 / 未暂存 / 主分支」(`GitDiffScope`)  
- 并排/统一: `@AppStorage("diff.sideBySide")` 默认 **true**  
- 块导航: 上一处/下一处 hunk  
- 块级暂存/放弃(工作区 diff 时)  
- 非 embedded:「在编辑器中打开」

**状态**: loading / notRepository / binary / diff(FileDiff) / failed

**刷新**: 活动标签 + `WorkspaceWatchCenter` debounce **300ms**, 轮询 **3s**

### 3.2 DiffTabView(Agent 单文件,`TabKind.diff`)

- 优先展示时间线 `FileChange`  
- 顶栏: 路径、±、并排/统一、「在编辑器中打开」、「撤销」(pending 时)  
- 无 Agent 改动 → 回退 `GitFileDiffView`

## 6. 交互终端 TerminalTabView

### 6.1 入口

- `TabKind.terminal(id)` — 每终端独立标签;常驻根目录 `WorkbenchModel.residentTerminalRoot(id)`  
- 新建: ⌃⇧\` 默认(`newTerminal`)、命令「新建终端」、右栏 + 菜单

### 6.2 布局

```
┌─────────────────────────────────────┐
│ SwiftTerm 视图 padLeading 6         │
│ bg OMTerminalPalette.background     │
├─────────────────────────────────────┤
│ exitedBar? (进程结束)               │
└─────────────────────────────────────┘
```

**exitedBar**: 图标 info +「进程已退出(退出码 n)」或「进程已结束」+ 按钮「重新启动」secondary

### 6.3 TerminalController 行为

- 创建在 `.task(id:)` 非 body 内(forkpty)  
- `TerminalContainerView`: 仅**可见且未最小化**窗口 claim 视图; 多窗口共享同一 controller  
- `LiveResizeGate`: 实时缩放时终端尺寸延迟应用,避免 SwiftTerm 全量重排卡顿  
- `TerminalOSC`: 解析 OSC 标题等  
- 偏好 `TerminalPrefs.load()` — 见下表  
- 配色 `OMTerminalPalette` + 主题 ANSI

### 6.4 终端偏好(设置 → 终端)

| UserDefaults 键 | 默认/范围 |
| --- | --- |
| `terminal.shell.fontFamily` | System monospace |
| `terminal.shell.fontSize` | **12**, 9–24 |
| `terminal.shell.cursorShape` | block / bar / underline |
| `terminal.shell.cursorBlink` | true |
| `terminal.shell.scrollback` | **5000**, 500–100000 |
| `terminal.shell.optionAsMeta` | true |
| `terminal.shell.path` | 空= `$SHELL` |
| `terminal.shell.login` | true |
| `terminal.shell.startDirectory` | project / home |
| `terminal.inheritEnvironment` | true |
| `terminal.outputLimitKB` | 1024 (64–16384 KB) |
| `terminal.fontSize` | Agent 工具输出行字号(另键) |

### 6.5 Agent 终端沙箱(用户可见)

| 键 | 默认 |
| --- | --- |
| `terminal.sandbox.enabled` | **false** |
| `terminal.sandbox.network` | local / off / all |

- `TerminalSandbox`: sandbox-exec 限制写入与网络  
- 输出清洗: 去掉 OSC/DCS 等(Agent 只读终端显示)  
-  blocked 检测 → UI 提示重试非沙箱(`retryWithoutSandbox`)

## 15. 重构注意事项

1. **Git 刷新**: 项目 watch + 5s 轮询;操作后即时 refresh — 勿双重全量 log.  
2. **History 不用 NSSplitView**: 曾导致宽度撑爆;用 GeometryReader 比例分栏.  
3. **终端 claim**: 重构多窗口时必须保留「仅 key 窗口显示 PTY 视图」.  
4. **浏览器与 Agent 共视图**: browser_navigate 与用户地址栏竞态需单线程到 main.  
5. **Canvas PNG 导出**: 820pt 宽与 on-screen 布局一致,否则截图偏差.  
6. **xlsx 大表**: 必须在后台解析,主线程只持 visibleRows.  
7. **Agent 改动 vs Git 改动**: Agent 改动走时间线/Changes 标签; SCM 仅 Git status(注释中的「Agent 分组」当前未实现 — 见 [05c §5](./20261024_重构规格_05c_标签页补遗.md#5-scm-完整规格)).
