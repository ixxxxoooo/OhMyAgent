## 1. 全局搜索 SearchModel

### 1.1 持久化

**不持久化。** `SearchModel`(`WorkspaceModels.swift`) 全部为内存 `@Observable` 字段;应用重启后 `query`、`caseSensitive`、`wholeWord`、`isRegex`、`pathFilter` 均恢复默认。仅 `root` 在 `SearchPaneView.onAppear` / 切换项目时设为 `workbench.selectedProjectID`。

防抖:**250ms** 后执行;空 `query` 时清空 `output` 且不发起任务。

### 1.2 搜索选项(无「排除 glob」)

| UI 控件 | 绑定字段 | 默认 | 行为 |
| --- | --- | --- | --- |
| TextField「搜索」 | `query` | `""` | 变更即 `schedule()`;回车同 |
| Toggle `Aa` | `caseSensitive` | false | tooltip「区分大小写」 |
| Toggle `W` | `wholeWord` | false | tooltip「全字匹配」 |
| Toggle `.*` | `isRegex` | false | tooltip「使用正则表达式」 |
| TextField「限定路径(包含该文本的文件)」 | `pathFilter` | `""` | **子串包含**过滤相对路径(小写比较),非 glob;空=不限 |

底层 `SearchOptions`(`WorkspaceFiles.swift`) 仅此四选项 + `query`;**没有 exclude glob / 排除模式**。

### 1.3 扫描与结果

- 单文件上限 **2_000_000** 字节;总命中上限 **3_000**(`truncated` 时摘要追加「(已截断)」)  
- 优先用 `WorkspaceIndexModel` 索引;多附加文件夹分别 `(root, files)` 扫描  
- 正则非法 → `output.error` 红色 `OMFonts.small` 顶栏展示  
- 摘要行:`N 个结果,M 个文件(已截断)?`;搜索中 mini spinner

### 1.4 结果列表布局

```
summary  caption secondary  pad 10×4
├─ fileHeader  chevron + OMFileIcon 14 + 文件名 small medium
│              [可选根目录名 accentText] + 目录 caption head 截断
│              右侧 命中数 caption
└─ HitRow (未折叠时)
     行号 30pt trailing caption monoDigit
     预览 readingMono 单行;命中 accent 30% 背景 + bold( ui-lint:allow )
     行 pad 10×2; hover hoverFill
```

- 文件组可折叠:`collapsed: Set<String>` 存 file.id  
- 点击命中:`openFile(root+path, line: hit.line, preview: true)`

### 1.5 替换与撤销

**右栏全局搜索无替换 UI。** 批量替换能力在 `WorkbenchKit/SearchReplace.swift`(供其它调用方),与 `SearchPaneView` 未接线。

编辑器内替换见 §9(`⌘⌥F` 打开替换行;`replaceAll` **一次 `commit` = 一步撤销**)。

## 3. Agent vs IDE 编辑器 Chrome

`FileTabView.codeEditor` 传入:

```swift
chrome: ideHost == nil ? [] : editorChrome
```

| Chrome 位 | Agent 窗口 (`ideHost == nil`) | IDE 窗口 (`IDEFileHost`) |
| --- | --- | --- |
| `.minimap` | **关**(忽略 `editor.minimap` 偏好) | 开/关随 `editor.minimap` |
| `.stickyScroll` | **关** | 随 `editor.stickyScroll` |
| `.folding`(行号栏折叠箭头) | **关** | **开**(恒插入 `editorChrome`) |
| `.overviewRuler`(诊断/查找/Git 尺) | **关** | **开** |
| LSP 状态条 | **有**(`LSPStatusBar`) | **无**(问题面板) |
| Git gutter 相对 HEAD | **无** | **有** |
| 行内 blame | **无** | **有**(非脏时) |
| Agent 块行内审阅 | **无** | **有**(`FileTabView+IDEExtras`) |
| 幽灵补全 | 偏好仍读,但无 IDE 侧 provider 时无效 | 随设置 |

**键盘折叠/查找等仍可用**;仅视觉 chrome 与部分 IDE 宿主能力缺失。设置页文案已注明缩略图/粘性滚动/幽灵补全面向 IDE。

## 4. PaletteModel 与 Hub

`PaletteModel` **不是独立 UI**;仅为兼容入口:

```swift
PaletteModel.present(.files)   → HubModel.present(.files, …)
PaletteModel.present(.commands) → HubModel.present(.actions, …)
```

| 入口 | Agent 窗口行为 |
| --- | --- |
| ⌘K / 菜单「搜索…」 | 直接 `HubModel.present(.all)` |
| ⌘P / 菜单「快速打开…」 | `IDEWindowManager.route(.quickOpen)` **成功则 IDE 处理**;否则 `PaletteModel.present(.files)` → Hub **文件** 分段 |
| ⇧⌘P / 「命令面板…」 | 同上 `.commandPalette` → Hub **操作** 分段 |
| 「在文件中搜索」⇧⌘F | **不经过 Hub**;`workbench.showRight(.search)` + `SearchModel.requestFocus()` |
| Hub 内「快速打开文件」命令 | 再次 `PaletteModel.present(.files)`(仍 Hub 文件段) |

调试:`OMA_PALETTE=files|commands` 打开 Hub 并可选 `OMA_PALETTE_QUERY`; `OMA_HUB=<segment>` 直达分段。

**结论**: Agent 窗口只有 **一套** 中央搜索 UI(HubOverlay);旧 Palette 面板已删除,无并存。

## 5. SCM 完整规格

### 5.1 结构(自上而下)

1. 多根仓库切换条(可选) h=28  
2. `header` 分支/拉取/推送/更多  
3. `commitBox`  
4. `changeList` ScrollView + LazyVStack  
5. 底部 `errorBanner`(可关)

**「本轮 Agent 改动」**: `SCMSections.swift` 文件头注释仍描述该分区,但 **当前 `changeList` 未实现独立 Agent 分区**;Agent 改动入口为时间线 `ChangesSummaryView`、标签 `ChangesTabView`、命令「在标签中查看本轮改动」。以代码为准。

### 5.2 变更分组 SectionHeader

| 分组标题 | 条件 | 分组操作(图标 12) |
| --- | --- | --- |
| **冲突** | `conflicts` 非空 | 无;tint `warning` |
| **已暂存的更改** | staged 非空 | `minus`「全部取消暂存」 |
| **更改** | unstaged 非空 | `arrow-left-right`「与主分支对比」(打开首个 diff); `undo-2`「放弃全部更改」(confirm); `plus`「全部暂存」 |
| **未跟踪的文件** | untracked 非空 | `undo-2`「放弃全部更改」(文案为删除未跟踪); `plus`「全部暂存」 |
| **提交图谱** | 见 §5.6 | CollapsibleHeader |

SectionHeader: caption medium + 数量 tertiary; pad 10, top 8, bottom 3.

### 5.3 ChangeRow(文件行)

- 高 **24**; padH 10; 图标 14 + 文件名 small + 目录 caption head  
- **悬停**右侧操作按钮(不改变行高)  
- **徽标**宽 14 caption medium: 冲突 `!` warning; 否则 `GitChangeKind.badge` — **A/M/D/R/C/T** 颜色见下  
- 选中:`selectedChangeKey = "\(section):\(path)"` → `selectedFill`  
- **单击**: 选中 + `openDiff`  
- **双击**: 编辑器打开非预览  
- **无障碍**: 「查看差异」「在编辑器中打开」

**徽标颜色**(`badgeColor`):

| kind | 颜色令牌 |
| --- | --- |
| added | `diffAdded` |
| deleted | `diffRemoved` |
| modified / typeChanged | `warning` |
| renamed / copied | `accent` |
| conflict `!` | `warning` |

**悬停操作**:

| section | 按钮 |
| --- | --- |
| staged | 打开编辑器; 取消暂存 |
| unstaged | 打开; 放弃更改(confirm); 暂存 |
| untracked | 删除文件(confirm); 暂存 |
| conflict | 「保留我的」「采用对方」plain accent; 标记已解决 `check` |

**右键菜单(完整)**:

1. 查看差异 (`file-diff`)  
2. 在编辑器中打开 (`file-text`)  
3. ——  
4. Git 历史 (`clock`) — **非 untracked**  
5. Git Blame (`git-fork`) — **非 untracked**  
6. ——  
7. 在 Finder 中显示  
8. 拷贝路径(相对仓库路径字符串)

### 5.4 提交区( recap )

- placeholder:`Message (⌘↩ to commit on "<分支>")`  
- AI:`scm.aiCommitMessage` + sparkles  
- 主按钮 ⌘↩; 下拉 Commit & Push / Amend / 暂存全部并提交  
- syncMode:「同步更改 ↓n ↑m」或「发布分支」

### 5.5 分支 / stash / 更多

见 05b;补充:**删除分支**仅在 ⋯ Menu 子菜单;**stash** 为 Menu「Stash」嵌套 pop/drop。

### 5.6 提交图谱 GitGraphSection

- CollapsibleHeader「提交图谱」; 右侧 `external-link`「在标签页打开完整历史」  
- 首次 **30** 条; 滚动加载 +30; 上限 **5000**  
- `laneWidth = max(laneCount) * 14 + 10`  
- 行: `CommitRow(compact: true)` 高 **26**; 点击展开/收起 `GraphCommitDetail`  
- 提交行右键: 拷贝提交哈希; 打开完整历史  
- 展开详情: 作者/日期/短 hash; 合并 tag; 文件列表; 点文件 → `openCommitDiff`  
- 文件行右键: 在编辑器中打开当前版本; 文件历史

### 6.1 GitBlameTabView

**顶栏** pad 14×6: 路径 small secondary +「在编辑器中打开」small 按钮。

**行** `BlameLineRow` 高 **18**:

| 参数 | 值 |

| 列 X | `x(column) = 10 + column * 14` |
| 行高 | 26 (`CommitRow.height`) |
| 节点半径 | 4pt 圆 (8×8) |

## 7. BrowserController 隔离与联动

### 7.1 数据隔离

- **每工作区路径**一个 `WKWebsiteDataStore`:  
  `SHA256(workspace.utf8).prefix(16)` → `UUID` → `WKWebsiteDataStore(forIdentifier:)`  
- **非**文件系统子目录;系统按 identifier 隔离 Cookie/存储  
- `BrowserController.ephemeral = true` → `.nonPersistent()`(演示/测试)  
- 同 workspace 多 browser 标签 **共享** 同一 dataStore

### 7.2 地址栏

`BrowserArguments.normalize`:

-  trim; 无换行  
- 无 `://` → 补 `https://`(localhost/127.0.0.1/.local → `http://`)  
- 拒绝 `javascript:`/`data:`/`file:` 等  
- 无法解析 → **静默不导航**(`go` guard nil)

特殊: `google.com.hk` → 改写 `google.com/ncr`(3s 节流)。

### 7.3 标签管理

- 内存 `tabs[id]`; 顺序 `order`; 每 workspace `active[id]`  
- 上限 **8**; 淘汰最久未用且**未在编辑区打开**的标签  
- `current(workspace)` 无打开标签则 `create` + `workbench.openBrowser`  
- Agent `browser_*`:`activate: false` 默认不抢焦点

### 7.4 界面联动(非单独「控制中」条)

- 用户与 Agent **同一** `WKWebView`  
- Agent 导航后地址栏 `onChange(model.urlString)` 同步  
- **选择元素**:`isPicking` + 顶栏 banner(见 05b); Esc 取消  
- 工具卡:会话时间线展示 browser 结果; **无**持久「Agent 正在控制浏览器」条(加载态见 `isLoading` 工具栏图标 x/rotate)

## 8. 检查点与 ChangesTabView

### 8.1 检查点机制

- 存储:`CheckpointStore` actor 内存; 工具完成时 `checkpoints.record(turn, path, old, new)`  
- 回退:`SessionModel.revert` / `revertAll` → 写盘; 冲突/无检查点更新 `FileChange.status`

### 8.2 用户可见入口

| 入口 | 行为 |
| --- | --- |
| 时间线 `.changes` | `ChangesSummaryView` 卡片(运行中隐藏) |
| 卡片「全部撤销」 | `model.revertAll(in: entry)` |
| 卡片「Review」 | IDE: `ideHost.openChanges()`; Agent: `openDiff` 首文件或 `openChanges` |
| 文件行点击 | IDE: 编辑器+行内审阅; Agent: `openDiff` |
| 文件行悬停 undo | `model.revert(change)` 单文件 |
| Diff 标签「撤销」 | `found.model.revert(found.change)` |
| Diff hunk 回调 | `revert(change, hunks: [hunk])` |
| IDE 编辑器审阅条 | 「全部还原」/ 块级「还原」 |
| 命令面板 | 「在标签中查看本轮改动」→ `openChanges` 标签 |
| `/rewind` 内置命令 | 提示用「本轮改动」卡片,非终端 rewind |

**无**独立「检查点」标签页。

### 8.3 ChangesTabView

- 数据: 指定或当前会话 **最后一条** 非空 `.changes` 条目 → `ChangesSummaryView`  
- 空状态:「暂无改动」/「Agent 修改文件后,这里会列出每个文件的差异。」  
- **无额外工具栏**; 全部按钮在 `ChangesSummaryView` / `FileChangeRow` 内(见 05b + 上表)

**FileChangeRow 悬停**:

- `arrow.up-forward-square`「在编辑器中打开」→ `viewerRequest`  
- `undo-2`「撤销修改」(pending/partiallyReverted)  
- 状态 tag: 已撤销 / 部分撤销 / 冲突 / 失败

## 10. 终端规格补全

### 10.1 交互终端

| 类别 | 来源 |
| --- | --- |
| 字体/字号 | `terminal.shell.fontFamily` / `terminal.shell.fontSize` 9–24,默认 12 |
| 光标 | `terminal.shell.cursorShape` block/bar/underline; `cursorBlink` |
| 回滚 | `terminal.shell.scrollback` 500–100000,默认 **5000**(创建时固定,改偏好不影响已开终端) |
| Option | `terminal.shell.optionAsMeta` 默认 true |
| Shell | `terminal.shell.path` 空=`$SHELL`; `loginShell` 默认 true → `-l` |
| 起始目录 | `terminal.shell.startDirectory` project/home |
| 配色 | `OMTerminalPalette` + `ThemeRuntime.didChange` |
| 复制 | 系统选区 + `TerminalController` 响应者链 ⌘C(选中有内容时) |
| 粘贴 | ⌘V 标准 |
| 清屏/分屏 | **无应用级快捷键**; 交给 shell/系统 |

### 10.2 多终端 UI

- **无**独立「终端列表」侧栏(K58 已移除); 每终端 = **一个标签** `TabKind.terminal(id)`  
- 切换: 命令「下一个/上一个终端」、标签栏点击、⌃Tab / ⇧⌃Tab(默认 next/previousTab)  
- `ProjectTerminals` 按项目登记 id+标题; Agent 与 IDE **共享**同一套 id(`IDEWorkspace+Editor`)  
- IDE 底部面板可显示 Agent 终端镜像(`showAgentTerminal`); Agent 窗口用 `AgentTerminalTabView` 只读

### 10.3 Agent 终端(工具)

- 输出缓冲:`terminal.outputLimitKB` 64–16384 KB,默认 1024  
- 沙箱:`terminal.sandbox.enabled` + `network` off/local/all  
- 字体(工具行):`terminal.fontSize` 默认 12
