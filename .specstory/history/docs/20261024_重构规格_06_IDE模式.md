## 1. 总览

### 1.1 产品定位

IDE 模式是 OhMyAgent 的**独立 AppKit 窗口**（`NSWindowController` + SwiftUI 外壳 `IDEShellView`），布局参照 Cursor / VS Code：活动栏 + 侧栏三视图 + 多组编辑器 + 底部面板 + 右侧 Agent 面板 + 状态栏。与全局唯一的 **Agent 工作台窗口**（SwiftUI `Window(id: "main")`）共享进程内状态：项目、会话、`FileDocumentStore` 文本缓冲、`ThemeRuntime`、`GitStore`、`TerminalStore`（按项目共享终端表）等。

### 1.2 模块分工

| 层级 | 路径 | 职责 |
|------|------|------|
| 数据（无视图） | `Sources/IDEKit/*` | 每窗模型、快照、`IDEMetrics`、`IDEResponsiveLayout`、`IDECommandRegistry`、`ProblemsStore`、`FusionFrame`、`IDEAutoSave`、文件导航栈 |
| 视图与编排 | `Sources/OhMyAgentApp/IDE/*` | 窗口控制器、外壳、侧栏、编辑区、面板、Agent 面板、命令面板、调试钩子 |
| 外部 IDE 启动 | `Sources/OhMyAgentApp/IDELauncher.swift` | 检测本机 Cursor/VS Code 等并用系统打开文件夹（**非** OhMyAgent IDE 窗口） |

### 1.3 技术栈要点

- **窗口**：AppKit `NSWindow`，`styleMask` 含 `.fullSizeContentView`，`WindowChrome.apply` 隐藏系统标题栏；`tabbingMode = .disallowed`。
- **热路径**：资源管理器 `NSTableView`（22pt 行高）；编辑器正文为 `OMEditorView`（原生 rope 引擎，宿主细节见文档 05）。
- **外壳**：SwiftUI；颜色/字号/图标遵守 `OMColors` / `OMFonts` / `Image.om`。
- **命令路由**：`WindowContext` 监听 `NSWindow.didBecomeKeyNotification`，键盘窗口为 IDE 时 `IDEWindowManager.route(_:)` 优先处理菜单快捷键。

### 1.4 侧栏视图枚举（持久化）

`IDESidebarView`（`ide-windows.json` 内 `sidebarView`）：

| rawValue | 活动栏文案 | 图标 (Lucide) |
|----------|------------|---------------|
| `explorer` | 资源管理器 | `folder` |
| `search` | 搜索 | `search` |
| `scm` | 源代码管理 | `git-branch` |

底部面板标签 `IDEPanelTab`：`terminal` | `problems` | `output`。

## 2. 窗口整体布局与度量

### 2.1 线框图（自上而下）

```
┌─ NSWindow (min 480×420, default 1280×820) ─────────────────────────────────────────┐
│ 标题栏 35pt (TitlebarMetrics.height == IDEMetrics.titleBarHeight)                  │
│ [panel-left] … [←][→][━━━━ 工作区名 / 未打开文件夹 ━━━━] … [panel-bottom][panel-right][settings][Agents Window ↗] │
├─ 1pt hairline ─────────────────────────────────────────────────────────────────────┤
│ ┌48pt┐ ┌─ 侧栏 180~520 (默认 260) ─┐ │1│ ┌──── 编辑区 min 320 宽 ────┐ │1│ ┌ Agent 280~900 (默认 380) ┐ │
│ │活动│ │  explorer / search / scm   │ │ │ │ 标签栏 32pt + 分屏编辑器    │ │ │ │ 会话标签 + ChatView       │ │
│ │栏  │ │  (+ OUTLINE / TIMELINE)    │ │ │ │  (+ 可选底部面板)           │ │ │ │                             │ │
│ └────┘ └────────────────────────────┘ │ │ └─────────────────────────────┘ │ │ └─────────────────────────────┘ │
│                                       │ │ ┌─ 底部面板 120~800 (默认 240) ─┐ │                                   │
│                                       │ │ │ terminal | problems | output  │ │                                   │
│                                       │ │ └───────────────────────────────┘ │                                   │
├─ 1pt hairline ─────────────────────────────────────────────────────────────────────┤
│ 状态栏 22pt (IDEMetrics.statusBarHeight)                                            │
└────────────────────────────────────────────────────────────────────────────────────┘
```

- 分隔条：`IDEResizer` + `OMSplitHandle`；侧栏右缘、Agent 左缘为**竖向**；面板上缘为**横向**；`zIndex(2)` 保证可拖过 AppKit 编辑器。
- **设置内嵌**：`model.settingsShown == true` 时，标题栏与状态栏之间整区替换为 `SettingsView`（与工作台共用设置页，`topInset: 0`）。

### 2.2 IDEMetrics 常量（源码 `IDEWindowSnapshot.swift`）

| 名称 | 值 | 说明 |
|------|-----|------|
| `activityBarWidth` | 48 | 活动栏固定宽 |
| `titleBarHeight` | 35 | 与 Agent `TitlebarMetrics.height` 一致 |
| `statusBarHeight` | 22 | 状态栏 |
| `windowMinWidth` | 480 | 内容区最小宽（再窄靠自适应收起） |
| `windowMinHeight` | 420 | |
| `windowDefaultWidth` | 1280 | 无存档外框时 |
| `windowDefaultHeight` | 820 | |
| `sidebarRange` | 180…520 | 用户拖拽钳制 |
| `sidebarDefault` | 260 | 双击分隔条恢复 |
| `panelRange` | 120…800 | |
| `panelDefault` | 240 | |
| `agentRange` | 280…900 | |
| `agentDefault` | 380 | |
| `editorMinWidth` | 320 | 拖分隔条与自适应计算 |
| `editorMinHeight` | 160 | 面板上限计算 |

**动态上限**（纯函数）：

- `sidebarMax(window:agentWidth:)` = clamp 到 `sidebarRange`，且 `window - activityBarWidth - agentWidth - editorMinWidth`
- `agentMax(window:sidebarWidth:)` 对称
- `panelMax(window:)` = `window - titleBarHeight - statusBarHeight - editorMinHeight`（`IDEShellView` 传入的 `window` 为工作区高度 + 标题栏 + 状态栏）

### 2.3 IDEResponsiveLayout 自适应（`IDEResponsiveLayout.resolve`）

**只影响实际显示，不改写** `sidebarVisible` / `agentPaneVisible` / 用户保存宽度；窗口拉宽后恢复原布局。

输入：`window`（活动栏左缘到窗口右缘的宽度）、`sidebarVisible`、`sidebarWidth`、`agentVisible`、`agentWidth`。

**收起顺序**（while `needed() > window`）：

1. 若侧栏本要显示 → 先 **隐藏侧栏**（`sidebarShown = false`）
2. 若仍不够且 Agent 面板开着 → **隐藏编辑区**（`editorShown = false`），只剩 **活动栏 + 撑满的 Agent 面板**
3. Agent 面板是否显示始终跟随用户 `agentVisible`（不在此逻辑里关掉）

`needed()` = `activityBarWidth` + (`editorShown ? editorMinWidth : 0`) + (`sidebarShown ? sidebarRange.lowerBound : 0`) + (`agentShown ? agentRange.lowerBound : 0`)

**⌥⌘E 最大化 Agent**：`agentPaneMaximized == true` 时，与 `!editorShown` 相同 UI——仅活动栏 + Agent 全宽（仍非融合专用逻辑）。

### 2.4 TitlebarMetrics（与 Agent 窗口共用）

| 常量 | 值 |
|------|-----|
| `height` | 35 |
| `trafficLightInset` | 88（IDE 标题栏左按钮组 `padding.leading`） |
| `buttonSize` | 26 |
| `buttonSpacing` | 2 |
| `modeSwitchWidth` | 124（「IDE」/「Agents Window」胶囊同宽） |

IDE 标题栏命令中心：`sideReserve = 224`（左右预留）、`centerMaxWidth = 560`。

## 3. 窗口生命周期与多窗口

### 3.1 注册表 IDEWindowRegistry

- 进程内**唯一**；`windows: [IDEWindowModel]` **MRU 顺序**（最近激活在前）。
- **同根复用**：`open(root:forceNew:)` 中 `IDEMetrics.normalizedRoot(root)` 匹配已有 `workspaceRoot` 则返回已有模型（`created: false`）；`root == nil` 空窗口**总是新建**。
- **⌥ 强制新开**：`forceNew: true` 跳过复用。
- **激活**：`activate(id)` 移到数组首位 + `markActivated()`。
- **关闭窗口**（非应用退出）：`remove(id)` 从数组移除并防抖落盘；**应用退出**不 `remove`，保留快照供恢复。

### 3.2 持久化 ide-windows.json

- 路径：`AppEnv.supportDirectory/ide-windows.json`（稳定版/开发版/演示隔离）。
- 格式：`IDEWindowsState`，`version = 1`；`windows: [IDEWindowSnapshot]` MRU 顺序。
- 写入：模型 `onChange` → **400ms 防抖** → `IDEWindowWriter` actor（generation 防旧快照覆盖）；`prepareForTermination()` → `saveNow()` 同步。
- 损坏：备份为 `.corrupt`，加载空状态；重复 UUID 只保留第一条。

**快照字段**（每窗）：`id`, `workspaceRoot`, `sidebarView`, `sidebarVisible`, `sidebarWidth`, `panelVisible`, `panelHeight`, `panelTab`, `agentPaneVisible`, `agentPaneWidth`, `frame`, `editor`（完整 `DockLayout`）, `lastActivated`。

**不持久化**（仅内存）：`panelMaximized`, `agentPaneMaximized`, `settingsShown`, `perfHUDVisible`, `terminalIDs`, `activeTerminalID`, `fileNav`, 大纲/时间线缓存等。

### 3.3 IDEWindowController

- 创建：`NSHostingView(rootView: IDEShellView(workspace:))`；`contentMinSize` = 480×420。
- 初始外框：存档 `IDEWindowFrame` 且与某屏 `visibleFrame` 相交则用；否则居中 default 尺寸，**cascadeIndex % 8 × 28pt** 错开。
- 系统标题：`"{文件夹名} — IDE"` 或 `"IDE — 未打开文件夹"`（Mission Control 用）。
- `windowShouldClose` → `workspace.confirmWindowClose()`（多文件脏保存对话框）。
- `windowWillClose`：`contentView = nil` 释放 SwiftUI 树 → `windowWillClose` 管理器（关终端、释放 Agent 槽位会话、registry.remove）。
- `windowDidResignKey` → `autoSaveOnFocusLoss()`（失焦保存模式）。

### 3.4 启动恢复

`IDEWindowManager.restoreWindows()`：

- 无快照 → 跳过。
- **融合模式**且 `UserDefaults general.fusionLastIDE == false`（上次停在 Agent）→ **不恢复 IDE 窗口**（避免与 Agent 叠在一起）。
- 否则按快照 **逆序** `show(..., activate: 仅 MRU 首个)`；融合模式下 `hideMainWindowWhenReady()` 最多 6s 内 `orderOut` Agent 主窗口。

### 3.5 入口汇总

| 操作 | 行为 |
|------|------|
| Agent 标题栏 `ModeSwitchButton(.ide)` / ⌃⌘I | `switchToIDE`：当前项目根，复用或新建 |
| ⌥ + 上述 | `forceNew: true` |
| 菜单「新建 IDE 窗口」⇧⌘N | `open(root: nil, forceNew: true)` 空窗 |
| 「在新 IDE 窗口中打开文件夹…」 | 系统目录选择器 → `open(root:)` |
| 空窗「打开文件夹…」 | `chooseFolder`：若该根已有窗则聚焦彼窗 |
| 项目树右键「在 IDE 中打开」 | 待确认（OhMyAgent IDE 入口在 `ProjectTreeView` 另有 `IDELauncher` 外链） |

### 3.6 WindowContext

- `kind`: `.agent` | `.ide(UUID)`
- IDE 判定：key window 或其 `parent`/`sheetParent` 链上能找到 `IDEWindowManager.model(for:)`
- 辅助窗口（面板、sheet）不改变 context

## 4. Agent 窗口 ↔ IDE 窗口切换与融合模式

### 4.1 非融合模式

- **Agent → IDE**：`open` 显示 IDE；无 `adoptFrame`。
- **IDE → Agent**：`AppActions.showMainWindow` 前置 Agent；若 IDE 当前有 `workspaceRoot` 则 `workbench.select(project:)` 或 `openProject`。
- 两侧按钮：`ModeSwitchButton` 宽 124pt；IDE 侧 `.omSecondary`，Agent 侧 `.omPrimary`（文案 **「IDE」** / **「Agents Window」**，图标 `external-link` 12pt）。
- 双击切换防抖：**0.6s** 内忽略重复点击。

### 4.2 融合模式 FusionMode

- **UserDefaults**：`ClientPrefs.Key.fusionMode` = `"general.fusionMode"`（bool，默认 false）。
- **UserDefaults**：`general.fusionLastIDE`（bool）：最近一次是否停在 IDE；退出时 `switchToIDE` 写 true，`switchToAgent` 写 false。
- 设置：**通用 → 融合模式 →「开启融合模式」** Toggle + Note 说明原地互切、共用会话、离开 IDE 自动保存等。

**切换动画**（`fusionSource` 需：融合开、窗口可见、非全屏）：

1. `adoptFusionFrame`：`FusionFrame.adopted` 沿用来源外框，最小尺寸不足时**顶边不动**放大（AppKit 左下原点）。
2. 目标窗 `beginFusionReveal()`：`alphaValue = 0`
3. `makeKeyAndOrderFront` 后 `finishFusionReveal`：sleep 40ms → 淡入 **0.14s**（减弱动态效果则 0）→ `source.orderOut`
4. IDE → Agent 前：`workspace.saveAll()` 保证磁盘与 Agent 一致

**项目同步**：融合下 IDE 成为 key window 时，若 `workspaceRoot` 在工作台项目中，则 `workbench.select(project: root)`。

### 4.3 文件/子 Agent 打开重定向

`AppEnvironment` 注册：

- `fileOpenRedirect`：若 `WindowContext.ideModel != nil`，则 `model.openFile(path,line,preview)` 并 return true
- `subagentOpenRedirect`：同理 `openSubagent`

用于 IDE Agent 面板内点击 `@文件`、子 Agent 标签等。

## 6. 活动栏与侧栏

### 6.1 活动栏 IDEActivityBar

- 宽 **48pt**，`OMColors.sidebar`，右 1pt hairline。
- 垂直 `padding.vertical = 8`，项间距 4。
- 三项 `IDESidebarView.allCases` + 底部 **设置**（`settings` 16pt，点设置同标题栏）。
- **ActivityItem**：36×36 点击区，圆角 `OMRadius.control`；选中 `selectedFill` + `.isSelected`；图标 16pt。

**交互**：`selectSidebar(view)` — 再次点击当前视图 → **收起侧栏**；否则切换视图并 **展开侧栏**。

### 6.2 侧栏容器 IDESidebarPane

- 背景 `OMColors.sidebar`。
- **explorer** 且有文件夹：不显示通用 `PaneHeader`（explorer 自带工具条）。
- 其他视图：`PaneHeader` 高 **32pt**，标题为视图 `title`，字号 `OMFonts.small`。
- 无文件夹：空状态 **「尚未打开文件夹」** + 说明 + 按钮 **「打开文件夹…」**。

### 6.3 资源管理器 IDEExplorerPane

**头部工具条**（高 28，hover 显示右侧四按钮）：

| 元素 | 文案/图标 | 行为 |
|------|-----------|------|
| 项目名 | 大写 `(root).lastPathComponent`，chevron | 点击切换 `@AppStorage("ide.explorerRootExpanded")` 默认 **true** |
| 新建文件 | `file-plus` | `create(..., isDirectory: false)` 目标目录见下 |
| 新建文件夹 | `folder-plus` | 新建文件夹 |
| 刷新 | `refresh-cw` | `ExplorerModel.shared.bump()` + `tree.refresh()` |
| 全部折叠 | `chevrons-down-up` | `tree.collapseAll()` |

**文件树 IDEExplorerView**（AppKit）：

- 行高 **22pt**，缩进 **12pt**，leading **8pt**；仅 `rootExpanded` 时显示。
- 单击/双击/拖放/键盘：由 `ExplorerTree` + 委托实现（与 Agent 文件树数据层共用 `ExplorerFlatten` 等）。
- **Git 装饰**：`GitStore.model(for: root).decorationIndex` 字母徽标。
- **activePath** 高亮当前编辑文件；`activeFilePath` 变化自动 `reveal`。
- **右键** `omContextMenu`（空白 vs 行）：

空白：**新建文件…** / **新建文件夹…**

文件/目录（多选支持）：

- **打开** / **在侧边打开**（⌥ 点击）→ `beside: true` 右侧分屏
- 新建文件/文件夹、**重命名…**（↩，仅单选）、**创建副本**、**移到废纸篓**（⌘⌫）
- **在 Finder 中显示**、**拷贝路径**、**拷贝相对路径**

**撤销**：本窗 `FileOpHistory`（新建/重命名/删除等），待确认菜单项「撤销」是否在 UI 暴露。

**OUTLINE IDEOutlineSection**：

- `@AppStorage("ide.outlineExpanded")` 默认 **true**
- 标题 **「大纲」**，头高 26；列表高 **200**；空：**「没有打开的文件」** / **「没有可显示的符号」**
- 数据：`workspace.outline`（LSP documentSymbol）；切换文件保留旧内容直到新数据就绪
- 行：图标 `symbol.kind.iconName`，缩进 depth×12，点击跳转行

**TIMELINE IDETimelineSection**：

- `@AppStorage("ide.timelineExpanded")` 默认 **false**
- 标题 **「时间线」**；列表高 **180**；空：**「没有提交历史」**
- `git log --follow` 最多 **50** 条；点击打开 **Git 历史** 标签 `openHistory(project:path:)`

### 6.4 搜索 IDESearchPane

- 模型：`IDESearchModel`（每窗独立），`task(id: root)` 绑定根目录。
- **切换替换**：chevron 按钮，占位 **「搜索」** / **「替换」**。
- 搜索框 toggles：**Aa** 区分大小写、**ab** 全词、**.*** 正则（22×20 胶囊）。
- **「要包含的文件(如 *.swift, Sources/**)」** 过滤行。
- 结果头：`"{totalHits} 个结果,{files.count} 个文件(已截断)"`；空：**「没有结果」** / 初始 **「在文件中搜索」**。
- 命中行点击：`openFile(..., preview: true)`；悬停可单条/整文件替换；通知栏可 **撤销** 替换。

侧栏切搜索时命令 `view.search` 会 `search.requestFocus()`（延迟 60ms 抢焦点）。

### 6.5 源代码管理 IDESCMPane

- 复用 `SCMContent(host: IDESCMHost(workspace:), model: GitStore...)`
- Diff/文件/历史等标签通过 `IDESCMHost` 打开到 **本 IDE 窗口** 的 `DockLayout`（非 Agent 右栏）。

## 7. 编辑区

### 7.1 结构 IDEEditorArea

- 空：`IDEEditorEmptyState`（图标 `code` 28pt）提示快捷键（侧栏/面板/Agent/⌥⌘E/切换/新建 IDE 窗），标题列宽 160、键位列 80。
- 有标签：`panelMaximized` 时编辑区隐藏；否则 `maximizedGroupID` 单组最大化或递归 `IDEEditorNodeView`。
- 背景 `OMColors.contentBackground`。

### 7.2 标签栏 IDETabBar（高 32，`IDETabMetrics.height`）

- 背景 `OMColors.sidebar`，底 hairline。
- **标签项**：文件 `OMFileIcon` 14；标题 `OMFonts.small`，预览 **斜体**；最大 label 宽 **180**；激活顶条 2pt（组聚焦 `accent`，否则 hairline）。
- **脏**：8pt 圆点；悬停/激活显示 **关闭** `x` 12；固定 **图钉** `pin`。
- 单击激活；**双击固定** `keepOpen`；**中键**关闭；**拖拽** `oma-tab:<uuid>`；拖入组/分屏区 `IDEGroupDropDelegate`（center/left/right/top/bottom 高亮 `accent` 12% 填充）。
- 空白区 **双击新建文件**（需 `root`）。
- 右侧：**向右拆分** `columns-2`；**更多** `ellipsis` → `OMContextMenuCenter`：**向右拆分** / **向下拆分** / **关闭已保存** / **关闭全部**。

右键菜单：**关闭**(⌘W) / **关闭其他** / **固定标签** / **拆分到右侧** / **在文件树中显示** / **在 Finder 中显示** / **拷贝路径**。

### 7.3 拆分与保活

- 组内分屏：`IDEEditorSplitView` + `OMSplitHandle`，比例 `DockLayout.normalizedRatios`。
- **splitDuplicate**：同文件副本进新分屏，**共享文档**；`splitGroup` 对当前 active 标签操作。
- **TabKeepAlive**：最近若干标签保持挂载，切换不销毁视图。

### 7.4 EditorSwapGate（切换不闪屏）

- 每窗 `EditorSwapGate.ready: Set<String>` 路径。
- **策略** `EditorSwapPolicy`：新文件路径可 hold（非二进制预览）、未 ready、旧槽位仍「可保留」（含预览原位替换）→ 继续显示 `shown` 标签；超时 **500ms** 强制切换。
- `IDEFileHost.markReady` 由编辑器首帧着色回调。
- 二进制预览 `FilePreviewKind.isBinary` 不等待。

### 7.5 标签类型（IDE 内）

| kind | 宿主 | 说明 |
|------|------|------|
| `.file` | `TabContentView` + `ideFileHost` | 主编辑路径 |
| `.diff` | 同上 | 标题后缀 ` ⇄` |
| `.changes` | `ChangesTabView` | Composer **Agent 改动审阅** |
| `.subagent` | `SubagentTabView` | 只读子 Agent 会话 |
| `.history` / `.blame` / `.commitDiff` 等 | `TabContentView` | Git 相关 |
| `.chat` / `.agentTerminal` | 空状态：**「该类型的标签在 IDE 窗口中暂不支持」** |

### 7.6 Agent 编辑器联动（宿主在 FileTabView，IDE 经 IDEFileHost）

- **⌘K**（keyCode 40+cmd，可编辑且 inline 可用）：`inlineEdit.begin()` 行内编辑，用 Agent 面板 `agentSession` 通道。
- **⌘L / ⌘⇧L**（keyCode 37）：`onReferenceSelection` → IDE 时 `addReferenceToChat`；空选区仅 `focusAgent()`。
- **审阅**：`inlineReview` / checkpoint 块级 Keep·Revert（调试动作 `review:` / `inlineAccept` / `inlineReject`）。
- **幽灵补全**：设置 `editor.ghostCompletion`，Tab 接受（见 §11）。
- 右键：**在对话中引用选区** 菜单写 **⌘L**（与设置页 Note「⌘⇧L」不一致，实际键盘两者均绑定 L 键）。

### 7.7 保存与关闭

- **⌘S** 当前；**⌥⌘S** 全部（`IDECommandRegistry` + 菜单）。
- **自动保存** `IDEAutoSaveMode`：关 / 延迟 **1s** / 失焦（见 §11）。
- 关标签：固定标签需 force；最后一处脏文件 **OMDialog** 三按钮 **保存 / 不保存 / 取消**。
- 关窗：`confirmWindowClose` 批量脏文件对话框 **全部保存 / 不保存 / 取消**。

### 9.1 IDEBottomPanel

## 15. 重构注意事项

1. **WindowContext 先于/workbench 单例**：任何「当前窗口」操作必须读 `WindowContext.shared.ideModel` 或 key window，不可假定 Agent `workbench` 布局。
2. **FileDocumentStore 跨窗共享**：脏标记需 `setDirty` 同步所有同路径标签；LSP `registerLSP` 按路径，**同文件多分屏关闭一栏** 可能误 unregister（K88 已知限制）。
3. **EditorSwapGate** 是 IDE 切换体验核心；预览标签原位替换必须算 `isShownKeepable`；超时 500ms、syntaxPending 兜底见开发进度 K85。
4. **融合模式** 全屏窗口不能 fusion；启动恢复与 `fusionLastIDE` 成对；IDE key 时同步 workbench 项目。
5. **终端生命周期**：非融合关 IDE 窗要 kill 项目终端；融合保留给 Agent。关窗必须 `releaseConversations` 防 Agent 进程泄漏。
6. **主题**：全部 `OMColors`；AppKit 树监听 `ThemeRuntime.didChange`（explorer `styleRevision`）。
7. **性能**：`IDEResponsiveLayout` 纯函数可单测；Perf 预算见 `DemoMetrics` `ide.*`；HUD 勿在 release 默认开启。
8. **持久化防抖**：rapid 拖拽分隔条只应触发模型 property 变更 + 400ms 写盘，勿每帧 sync。
9. **命令面板与 HubSearch 分离**：IDE 用 `IDEPaletteModel`，不是 Agent 的 `HubModel`（⌘K 仍开 Hub）。
10. **sanitize 与拆分**：恢复布局时去重标签会破坏「同文件两栏」存档，若需跨会话拆分要改 DockLayout 持久化策略。

### 17.3 ⌘L / ⌘⇧L 文案与真实行为

| 来源 | 原文 |
|------|------|
| 设置 → 编辑器 → Agent 联动 Note | **「在编辑器里选中代码,右键「在对话中引用选区」或按 ⌘⇧L,会把 @文件:行范围 加入当前项目的输入框。」** |
| 编辑器右键菜单 | **「在对话中引用选区」**，shortcut 展示 **⌘L**（且 `handle.hasSelection` 为真才出现） |
| `IDECommandRegistry` | `agent.referenceSelection`，shortcut **⌘L** |
| `OMEditorView+Keyboard` | keyCode **37**（L 键）+ **`[cmd]` 或 `[cmd, shift]`** 同一分支：调用 `onReferenceSelection`（**不区分**是否按住 Shift） |
| keyCode 40 + cmd+shift | **删除行**（`deleteLines`），**不是**引用 |

**运行时行为**（`TabContentView.referenceSelection` / IDE 经 `IDEFileHost.reference`）：

- **选区长度 > 0**：生成 `@文件:行范围` 追加到 Agent 面板 `session.draft`，并显示 Agent 面板。
- **选区长度 = 0**：仅 `focusAgent()` / 选中项目，**不**追加 token（注释写「空选区(⌘L):只切到并聚焦对话输入框」）。

**结论**：功能键是 **⌘L**（⇧ 不改变行为）；设置页 **⌘⇧L 为文档错误**（⇧⌘L 在编辑器内实际绑定删除行）。命令注册表与右键菜单以 **⌘L** 为准。

### 17.10 命令面板分模式细则

| 模式 | 进入方式 | 空输入 | 无结果 | 上限 | 排序 | 选中打开 |
|------|----------|--------|--------|------|------|----------|
| **⌘P 文件** | `openPalette("")` | 6 条模式入口 + 最近打开文件（首文件行尾 **最近打开**） | 索引未就绪：**正在建立文件索引…**；否则 **没有匹配项** | 模糊 **50**（`IDEQuickOpen.rank`）；>3000 文件异步排序 | 空：recent 优先；有 query：模糊分降序 | **固定打开** `preview: false`；**不支持** ⌥/⌘ 修饰 |
| **⇧⌘P 命令** | `">"` | 最近 8 条可用命令 + 其余按声明序 | **没有匹配项** | **50** | 空：recent 优先；有 query：模糊分 | 执行 `perform(id)` |
| **`:` 行** | `":"` / ⌃G | 单行占位 **输入行号以跳转** | — | 1 行 | — | 有行号 → `EditorRouter.goToLine`；**固定当前文件** |
| **`@` 符号** | 模式入口 **转到编辑器中的符号**（hint `@`，**非**输入 `@` 前缀） | 符号列表（无单独空态文案） | 过滤后空 → **没有匹配项** | 展示 **200**（`filteredCustom.prefix(200)`） | 符号树 flatten 顺序；输入后模糊分 | **固定** `openFile(path, line, preview: false)` |
| **引用** | ⇧F12 / 编辑器 | 首屏可能 **语言服务正在建立索引,稍后自动重试…** | 最终无结果 → 对话框 **没有找到引用** | 全部引用（无 200 截断） | LSP 返回顺序 | **固定** 打开文件行 |
| **分支/快速修复等** | 状态栏分支、⌘. | 自定义 placeholder | **没有匹配项** | 200（过滤） | 各 API 自定 | `actionID` 异步动作或 checkout |

**主题模式**：占位 **选择颜色主题(↑↓ 预览,↩ 应用,Esc 取消)**；↑↓ 实时改 `AppearanceModel.themeID`；Esc 还原。

### 17.11 IDE 窗口拖放

| 落点 | 接受类型 | 行为 |
|------|----------|------|
| **资源管理器** `NSTableView` | `NSURL` 文件/夹 | 工作区内 **move** / 外部 **copy** → `performDrop`（同名确认、脏文件拒绝移动） |
| **编辑器标签栏** `IDETabBar` | **`plainText`**（`oma-tab:uuid`） | 仅 **标签重排/跨组**；**不接受** Finder 文件 |
| **编辑器组内容区** | **`plainText`**（标签 ID） | 分屏/合并（center/left/right/top/bottom 高亮）；**不接受**外部文件 |
| **Agent 面板输入** | 经 `ChatView` → `ComposerView` | **`.fileURL`, `.image`** → `DropClassifier` 转 **`@路径` 提及** 插入草稿（与 Agent 窗口相同） |
| **终端** | — | **未**注册 IDE 专属文件拖入 |

Agent 工作台 **TabGroupView** 接受 `fileURL`+标签拖放；**IDE 未复用**该路径，故 **不能**把 Finder 文件拖到 IDE 编辑区/标签栏打开（仅资源管理器与 Agent 输入区）。
