## 2. 进入方式与窗口形态

### 2.1 触发入口（源码已实现）

| 入口 | 行为 |
| --- | --- |
| ⌘, | `AppActions.openSettings()` → `workbench.openSettings()` |
| 菜单栏 | `OhMyAgentApp`：`Button("设置…")` |
| 项目树底部 | `ProjectTreeView`：齿轮 + tooltip「设置 (⌘,)」 |
| IDE 标题栏 | `IDETitleBar`：`settings` 图标，label「设置 (⌘,)」 |
| IDE 活动栏 | `IDEActivityBar`：设置按钮 |
| 命令面板 | `PaletteCommand` id `settings`，title「设置…」，shortcut 显示 `⌘,` |
| ⌘K 搜索 | `HubSearch` 可跳转到任意 `SettingsPage` |
| 深链 | `SettingsRouter.initialPage()`：`OMA_SETTINGS_PAGE=<rawValue>`；旧 `OMA_SECTION=<ExtensionSection>` 映射到对应页 |
| 托盘菜单 | 「设置…」，快捷键 `,`（⌘ 修饰） |

### 2.2 关闭

- 侧栏 **「返回」**（图标 `arrow.left`，tooltip「返回工作台 (Esc)`）
- **Esc**：`SettingsView.onExitCommand` → `workbench.closeSettings()` 或 IDE 内嵌时 `onClose()`
- 融合模式 / IDE 内嵌：`SettingsView(topInset: 0, onClose: …)` 仅关设置层

### 2.3 与工作台关系

```
┌─ WorkbenchView ─────────────────────────────────────────────┐
│  mode == .settings ?                                        │
│    SettingsView(workbench, topInset, onClose)  : 正常三区   │
└─────────────────────────────────────────────────────────────┘
```

- **不是** SwiftUI `Settings { }` 独立窗口；注释写「设置窗口(⌘,)」指同一主窗口内的全屏设置 UI。

## 3. 整页布局与切页机制

### 3.1 ASCII 线框（Agent 主窗口，有标题栏）

```
┌──────────────────────────────────────────────────────────────┐
│ [红绿灯行] 整行 WindowDragArea (topInset = TitlebarMetrics)   │
├──────────────┬───────────────────────────────────────────────┤
│ SettingsSidebar│  OMColors.surface 内容区                    │
│ width =        │  ┌─ error banner (model.lastError) ─────┐  │
│ PanelMetrics   │  └──────────────────────────────────────┘  │
│ .clamp(        │  ZStack: 保活页 opacity 0/1               │
│  layout.       │  maxWidth: contentWidth (居中)            │
│  leftWidth)    │  maxWidth: ∞ 外层居中                      │
│ OMColors.sidebar│                                             │
│ (SidebarBackground)                                           │
└──────────────┴───────────────────────────────────────────────┘
```

- 左栏宽度：**与工作台项目栏相同**，`CGFloat(PanelMetrics.clamp(workbench.layout.leftWidth, side: .left))`，**不可**在设置内单独拖拽改宽。
- 右栏背景：`OMColors.surface`。
- 顶栏预留：`topInset` 默认 `TitlebarMetrics.height`；IDE 内嵌传 `0`。

### 3.2 切页时序（性能关键）

1. 用户点侧栏 → 只改 `SettingsRouter.shared.page`（侧栏 `@Bindable router` 立即重算 → **高亮先上屏**）。
2. `SettingsRouteFollower` 监听 `router.page` → `RunLoopAfterCommit.perform { show(next) }`（**下一帧**再改 `shownPage`）。
3. `show(_:)`：若 `next != shownPage`，先 `NSApp.keyWindow?.makeFirstResponder(nil)`，再 `keepAlive.visit(next)`，`shownPage = next`。
4. 父视图 **不在 body 里读** `router.page`，避免整页重布局。

### 3.3 错误条

- 来源：`ClaudeSettingsModel.lastError`（写 settings 失败等）。
- 样式：`Label(error, om: "xmark.octagon.fill")`，`OMFonts.small`，`OMColors.danger`，padding 10，背景 `danger.opacity(0.1)`。

### 3.4 生命周期 Task

- `onAppear`：`model.start()`，`center.start()`，解析 `Toolchain` 并 `center.setRunner(CLIRunner(...))`。
- `onDisappear`：`model.stop()`，`center.stop()`。
- 调试：`OMA_SETTINGS_SWEEP=<轮数>` 依次切页测首帧（`SettingsSweepProbe`）。

## 4. SettingsSidebar 侧栏

### 4.1 结构树

```
VStack
├─ [可选] Color.clear height=topInset + WindowDragArea
├─ HStack「返回」Label(arrow.left) height≈26, padding H14, bottom 4
├─ 搜索框 H26, padding H12, bottom 8
│    magnifyingglass 12pt + TextField「搜索设置」
└─ ScrollView → LazyVStack spacing 2
     ForEach filteredGroups
       ├─ 分组标题 OMFonts.small tertiaryText, padding top 12
       └─ SettingsSidebarRow × N
```

### 4.2 侧栏分组与顺序（`SettingsPage.groups`）

| 分组标题 | 页面顺序 | 页面 title（侧栏文案） | Lucide 图标名 `page.icon` |
| --- | --- | --- | --- |
| 客户端 | general → appearance → shortcuts | 通用 / 外观 / 快捷键 | gearshape / paintbrush / keyboard |
| Agent | agent → providers → modelMapping → prompts → network → permissions → trust → agentExtensions | Agent 与模型 / 模型提供商 / Claude Code 模型映射 / 提示词 / 网络 / 权限 / 项目信任 / Agent 注册表 | cpu / server.rack / arrow.triangle.swap / doc.text / network / lock.shield / shield-check / square.stack.3d.up |
| 工作台 | editor → terminal → browser → sourceControl → codeIntelligence | 编辑器 / 终端 / 浏览器 / 源代码管理 / 代码智能 | chevron.left.forwardslash.chevron.right / terminal / globe / git-branch / braces |
| 其他 | usage → privacy → advanced → diagnostics → about | 用量与成本 / 隐私与遥测 / 高级 / 诊断 / 关于 | chart.bar / hand.raised / wrench.and.screwdriver / stethoscope / info |

**不在侧栏列表但存在 `SettingsPage` case 的页面**（深链 / ⌘⇧E / Customize 内嵌）：mcp, skills, subagents, hooks, plugins, memory — 见 07b。

### 4.3 SettingsSidebarRow

- 最小高度 **30pt**，水平 padding 10，圆角 `OMRadius.control`。
- 选中：`OMColors.selectedFill`；悬停未选中：`OMColors.hoverFill`。
- 字体：`OMFonts.body`，前景 `OMColors.primaryText`。
- **不用**系统 `List` 选中色（避免窗口激活/失活变蓝）。

### 4.4 搜索

- 过滤：页 `title`、`group.title`、`page.keywords`（大小写不敏感）。
- 空 query → 完整 `groups`；有 query → 去掉空分组。

## 5. 右侧内容骨架

两套并存（迁移中）：

| 骨架 | 用途 | 关键样式 |
| --- | --- | --- |
| `SettingsForm` | 多数 Agent/网络/权限页 | `ScrollView` → 卡片化 `Section`；分组标题 `OMFonts.small` secondary；卡片 `OMColors.card` + `OMRadius.card` + 0.5pt hairline；行间距 `OMSpacing.sm+2`；行间 `Rectangle` hairline 0.5 |
| `SettingsScroll` + `SettingsCard` | 外观、编辑器、终端、SCM 等 | 外层 padding `OMSpacing.lg`；卡片标题在外；`SettingsRow` / `SettingsToggleRow` / `Note.footnote()` |

### 5.1 SettingsRow / SettingsToggleRow

- 左：标题 `OMFonts.body` + 可选说明 `OMFonts.small` secondary。
- 右：控件；开关 `Toggle` `.controlSize(.small)`。

### 5.1 SettingsNumericField

- 输入框宽默认 **90pt**，右对齐；可选单位 `OMFonts.small` secondary。

### 5.1 SettingsSliderRow + OMStepSlider

- 标题 + 当前值（右，`monospacedDigit`）在上，滑块占满宽。

### 5.1 Note

- `OMFonts.caption`，`OMColors.secondaryText`；`.footnote()` 在卡片内无顶部分隔线。

### 5.2 设置页宽度档位（`SettingsContentWidth`）

| 档位 rawValue | 显示名 | 最大宽度 (pt) |
| --- | --- | --- |
| compact | 紧凑 | 680 |
| standard | 标准 | 860（默认） |
| wide | 宽 | 1040 |
| full | 铺满 | ∞ |
| custom | 自定义 | `settings.widthCustom`，默认 900 |

- 自定义范围：**560…1600**，步长 **20**（`SessionOptions.swift`）。
- 滑块只展示 **presets**（不含 custom）；选档写入 `settings.width`。
- 窗口较窄时 SwiftUI 仍会收窄（`frame maxWidth` + 外层 infinity 居中）。

## 6. SettingsKeepAlive 保活

| 项 | 值 |
| --- | --- |
| 默认 limit | **6** 页（含当前） |
| 策略 | 最近访问的 **静态** 页保持挂载；ZStack 隐藏页 `opacity 0`、`allowsHitTesting false`、`accessibilityHidden` |
| 环境 | 隐藏页注入 `tabIsActive: false`（降低定时动画频率） |

**不参与保活**（每次进入重建）：`.providers`, `.modelMapping`, `.agentExtensions`, `.mcp`, `.skills`, `.subagents`, `.hooks`, `.plugins`, `.memory`, `.usage`, `.advanced`, `.diagnostics`

挂载顺序：`SettingsPage.allCases` 过滤保活集合，保证视图 identity 稳定。

## 7. Claude 配置 vs 客户端偏好

### 7.1 ScopeHeader（写 settings.json 的页）

- 文案「写入位置」+ 分段 `ConfigScope`：用户 / 项目 / 本地。
- 说明（原文）：
  - 用户：`~/.claude/settings.json,对所有项目生效`
  - 项目：`<工作区>/.claude/settings.json,可提交到版本库与团队共享`
  - 本地：`<工作区>/.claude/settings.local.json,仅本机,不入版本库`
- 无工作区警告：`当前没有工作区,无法写入此层;请先打开一个工作区。`

### 7.2 ClaudeSettingsModel 绑定

- `stringBinding`：空串删键。
- `boolBinding`：与 default 相同则删键。
- `envBinding`：维护 `env` 字典。

工作区：`SettingsContext.workspace` = 当前选中项目 URL；主目录项目视为 nil（与用户层相同）。

## 9. 设置页 · 外观 (`AppearancePage`)

**骨架**：`SettingsScroll` + 多 `SettingsCard`。

### 9.1 主题

- 预览：`ThemeMiniWorkbench` 高 **170pt**，圆角 `OMMetrics.cardRadius`，hairline 描边。
- 筛选框高 **28pt**，placeholder「快速筛选主题 (支持名称、深浅、风格…)」，图标 `search` / 清除 `circle-x`。
- 无筛选：按 `ThemeGroup`（不含 custom）分组网格，`GridItem adaptive minimum **170** maximum **240**`。
- 有筛选无结果：「未找到与「…」匹配的主题」。

## 12. 重构注意事项

1. **切页性能**：侧栏与内容解耦 + `RunLoopAfterCommit` 是刻意设计；重构勿在 `SettingsView.body` 直接绑定 `router.page`。
2. **左栏宽度**：必须跟 `workbench.layout.leftWidth`，否则 AGENTS.md 4.1 违反「设置页左栏与工作台一致」。
3. **保活与数据页**：提供商/扩展页不保活，避免 stale；静态页保活最多 6 个，注意内存。
4. **融合模式**独立 `FusionMode`，非普通 `@AppStorage` 单键。
5. **语言**写 `AppleLanguages`，不在 `ClientPrefs.resetAll` 前缀列表内（重置通用页不会清语言，除非用户改语言逻辑）。
