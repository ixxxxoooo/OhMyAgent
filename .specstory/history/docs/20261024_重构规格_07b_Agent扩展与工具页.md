## 1. Customize 页（扩展总入口）

### 1.1 入口

- 主侧栏「新对话 / **自动化**」下方的 **自定义** 预览标签（`WorkbenchModel.customizeTabID`）。
- 快捷键 **⇧⌘E**（`ShortcutAction.extensions`）→ 通常打开工具与扩展；深链仍可用 `SettingsPage.mcp` 等打开设置内页。
- **不在**设置侧栏 `groups` 列表中；与设置内 MCP 等页 **共用同一套** `MCPSettingsPage` 等视图。

### 1.2 布局

```
VStack
├─ topBar (maxWidth = chatWidth + 56, 居中)
│    ├─ ExtensionSearchField「搜索插件、技能、MCP…」
│    ├─ Button「浏览市场」omSecondary disabled
│    └─ CustomizeFilter chips 高 24
├─ Divider opacity 0.5
└─ content (同 maxWidth)
```

- 内容宽度 = **会话宽度** `ChatWidth.resolve` + **56pt**（子页自带 28pt 左右 padding，对齐时间线正文宽）。
- 筛选持久化：`workbench.customizeFilter`（rawValue，默认解析失败 → plugins）。

### 1.3 CustomizeFilter

| rawValue | 标题 | 图标 | 内嵌页面 |
| --- | --- | --- | --- |
| plugins | 插件 | puzzlepiece.extension | PluginsSettingsPage |
| mcp | MCP | brand.mcp | MCPSettingsPage + query |
| skills | 技能 | sparkles | SkillsSettingsPage kind .skill |
| commands | 命令 | terminal | SkillsSettingsPage kind .command |
| subagents | 子 Agent | person.2 | SkillsSettingsPage kind .agent |
| rules | 规则 | brain | MemorySettingsPage |
| hooks | Hooks | bolt.horizontal | HooksSettingsPage |

## 3. 模型提供商与映射

### 3.1 ModelProvidersPage

**布局**：

```
VStack
├─ topBar (padding lg, 高 ~42)
│    ScrollView 横向 chips 高 26 + [搜索宽140 当 providers>6]
│    Menu「添加」+ Button「导入」OpenCode
└─ ProviderDetailView (SettingsForm)
```

- 默认 `onAppear` 选中第一个 provider。
- Chip：品牌图标 14pt + 名 + 状态点（停=灰，缺 key=warning，OK=success）；草稿 chip 标签「未保存」。
- **不**写 ~/.claude/settings.json；数据 `providers.json` + 密钥文件（见 07c）。

**ProviderDetailView 分组**：

| Section | 主要字段 |
| --- | --- |
| 启用 | Toggle「启用此提供商」即时 `setEnabled` |
| 连接 | 名称；协议 Anthropic / OpenAI(经内置代理)；baseURL；SecretField API Key；测试连接；跳转映射 |
| 模型 | 默认 model ID；modelList 行；手动添加；获取列表 sheet |
| 高级 | 待读源码 ProviderDetailView `advancedSection` |
| 操作 | 保存 / 删除确认 |

密钥路径文案：`ProviderStorage.keysDisplayPath`，权限 0600。

### 3.2 ModelMappingPage

| 分组 | 内容 |
| --- | --- |
| 说明 | Note + 无提供商时 Button「去添加提供商」 |
| 使用自定义映射 | Toggle（仅 main 槽位已设时显示）→ `useMapping` |
| 槽位 | `ModelSlot.allCases` 每行 OMPickList 选模型；非 main 在 main 未设时 **disabled** |
| 辅助任务 | 会话标题生成 / 提示词优化 → `prompt.titleModel` / `prompt.optimizeModel` |
| 底部 | 状态 Label + 「清除全部映射」destructive |

槽位 picker：跟随默认 / 未设置(沿用 ~/.claude)；编码 `providerId\u{1F}model`。

| 槽位 | 标题 | 说明（原文） |
| --- | --- | --- |
| main | 默认 | 新会话的默认模型;未单独设置的槽位也使用它 |
| opus | Opus | 选择 Opus 时使用(复杂任务) |
| sonnet | Sonnet | 选择 Sonnet 时使用(日常编码) |
| haiku | Haiku | 选择 Haiku 时使用,Claude Code 的后台小任务也走它 |
| subagent | 子 Agent | 子 Agent 使用的模型 |

## 8. MCP / 技能 / 命令 / 子 Agent / Hooks / 插件 / 规则

### 8.1 MCPSettingsPage

- 副标题：「通过 Model Context Protocol…配置写入 ~/.claude.json 或项目的 .mcp.json。」
- 操作：**检测连接**（claude mcp list）、刷新、Menu **添加服务器**（表单 / 粘贴 JSON / Claude Desktop 导入）。
- 作用域分段过滤：全部 / 用户 / 项目 / 本地（带计数）。
- 行：启用、展开详情、批准项目级服务器、健康状态、编辑/删除。
- Sheet：`MCPEditorSheet`、`MCPJSONSheet`；删除 confirmationDialog。

**深链**：设置 `SettingsPage.mcp` 与 Customize 筛选 mcp **同一组件**（Customize 多传 `query`）。

### 8.2 SkillsSettingsPage (`MarkdownItemManagerView`)

- kind：`.skill` / `.command` / `.agent` 对应设置页 skills / commands / subagents。
- 管理 SKILL.md、斜杠命令、子 Agent 定义文件；含 `CommandCreateSheet`（命令创建）。
- 重构需读 `MarkdownItemManagerView.swift`、`CommandCreateSheet.swift` 全字段。

### 8.3 HooksSettingsPage / PluginsSettingsPage / MemorySettingsPage

- Hooks：`HooksManagerView` + settings.json `hooks` + 插件 hooks.json 只读。
- 插件：`PluginsManagerView`；副标题「安装、启停与更新 Claude Code 插件…需 claude 命令。」
- 规则/记忆：`MemoryManagerView`，CLAUDE.md 与 rules；标题「规则」。

## 13. 重构注意事项

1. **Customize vs Settings**：同一 MCP 视图两套入口，宽度规则不同（Customize 跟 chatWidth，Settings 跟 settingsWidth）。
2. **providers.json / agents.json** 与 Claude settings **分离**；映射页改 providers 会刷新活跃会话。
3. **MCP 配置** 在 `~/.claude.json` 与 `.mcp.json`，不是 settings.json（页头文案明确）。
4. **ExtensionPage** 操作区按钮强制 omSecondary，避免系统默认按钮破坏 24pt 规范。
5. **权限 bypass** 必须二次确认；与 ACP 会话内权限模式联动。
6. **Usage** 只读 Claude 侧数据，无账号 UI。
