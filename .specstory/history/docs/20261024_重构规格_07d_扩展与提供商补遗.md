## 1. MCP 管理 (`MCPSettingsPage` + Sheets)

### 1.1 列表行布局

| 区域 | 内容 |
| --- | --- |
| 左图标瓦片 | `brand.mcp`，色调随健康：connected=success / needsAuth=warning / failed=danger / 未知=accent |
| 标题 | `config.name` |
| 副标题 mono | stdio: `command + args` 空格拼接；否则 `url` |
| 徽章 | 作用域 `displayName`；传输 `transport.rawValue`；「待批准」warning；「被{scope}覆盖」warning |
| 展开详情 | 见 §1.3 |
| 右侧 | 健康文案 + 批准(待批准)或 OMSwitch 启用 + Menu(编辑/删除) |

**作用域过滤**（有服务器时）：分段「全部 N / 用户 / 工作区 / 本地」各带计数。

**空状态**：「还没有 MCP 服务器」或「这个范围内没有服务器」；引导点「添加服务器」或 Claude Desktop 导入。

### 1.2 行操作

| 操作 | 行为 |
| --- | --- |
| 点击行 | 展开/收起详情（`expandedID`） |
| 检测连接 | 页头；`claude mcp list`；进行中按钮文案「检测中…」+ Spinner，minWidth 84 |
| 刷新 | `center.reload()` |
| 添加服务器 Menu | 表单添加… / 粘贴 JSON 添加… / 从 Claude Desktop 导入 |
| 批准 | 仅 `needsApproval`；`MCPStore.approveProjectServer` |
| 启用开关 | `setEnabled`；成功 toast「已启用/已禁用」 |
| 编辑… | 打开 `MCPEditorSheet` |
| 删除… | confirmationDialog 标题「删除 MCP 服务器?」按钮「删除「{name}」」消息「将从{scope}配置中移除,此操作不可撤销。」 |

**Claude Desktop 导入失败**：`没有在 Claude Desktop 配置中找到 MCP 服务器`；成功「已导入 N 个服务器到用户作用域」。

### 1.3 展开详情字段

- SSE 警告：「SSE 传输已被 MCP 规范弃用,建议改用 HTTP。」
- 待批准：「这是项目 .mcp.json 中的服务器,尚未批准。批准后 Claude 才会启动它。」
- 覆盖：「同名服务器在{scope}作用域中优先生效,此条目被整体覆盖。」
- 健康：`Label(health.detail, waveform.path.ecg)`
- 未解析 env 变量列表警告（含 ANTHROPIC_API_KEY 说明）
- 键值：传输 displayName；stdio 命令；env 键值（敏感 mask）；HTTP 的 URL、请求头 mask
- 按钮：编辑… / 删除…

## 8. OpenCode 导入（两阶段 UI）

**Sheet** `OpenCodeImportSheet` 460×400：

1. **打开时**（`task`）：`OpenCodeImporter.scan()` 后台 → 列表候选（**不读密钥**）

## 11. `ProjectConfigHub` vs 设置 MCP

| 维度 | ProjectConfigHub | 设置页 `ConfigCenter` |
| --- | --- | --- |
| 生命周期 | 应用级，按工作区 URL 缓存 | 随 `SettingsView`/`CustomizePage` appear/disappear |
| 路径 | 同 `ClaudePaths(workspace:)` | `SettingsContext.workspace`（主目录→nil） |
| 用途 | 对话 `@` 补全、slash 命令、agent mentions；**不**写配置 | 完整 CRUD UI |
| MCP 健康 | 共享逻辑，Hub 内 center 也会 check | 设置页完整管理 |

**对话内 MCP 面板**（`MCPChatPanel`，宽 380，非设置页）：

- 入口：输入区工具栏 MCP 按钮 popover
- 空状态 +「添加服务器…」→ `openSettings(.mcp)`
- 行内：`/mcp reconnect|enable|disable` 发 Agent（运行中 disabled）
- 底栏：「会话内状态」`/mcp`；「管理…」→ 设置 MCP 页

数据同源 `center.snapshot.mcp` + `mcpHealth`，设置页改文件后 Hub reload 随 ConfigWatcher 刷新（经各自 center）。
