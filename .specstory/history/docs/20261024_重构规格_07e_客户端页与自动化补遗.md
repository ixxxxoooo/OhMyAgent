## 6. 自动化（表单 + 权限 + 模板）

### 6.1 `AutomationPermissionMode`

| raw | 界面 title | ACP mode 值 | 含义 |
| --- | --- | --- | --- |
| readOnly | 只读(不修改文件) | plan | 只读分析 |
| acceptEdits | 自动接受编辑 | acceptEdits | 自动接受编辑，其它授权拒绝 |

编辑器 Note：「无人值守时,需要额外授权的操作(如运行命令)会被自动拒绝。」

### 6.2 `AutomationEditor` 字段

| 字段 | placeholder/控件 | 校验 |
| --- | --- | --- |
| 名称 | 例如:每日变更摘要 | 空/ >80 字 |
| 项目 | omPicker 项目列表 | 必选路径 |
| 计划 | kind: **间隔/每天/每周/cron** | 见下 |
| 间隔 | 每隔 [N] 分钟(最少 5) | ≥5 |
| 每天/每周 | DatePicker 时分；weekly 星期 pill 2-7,1 | weekdays 非空 |
| cron | placeholder「分 时 日 月 周,如 0 9 * * 1-5」 | 5 段语法 |
| 权限 | OMCompactSegmented 两档 | — |
| 提示词 | TextEditor min 140 | 空/ >8000 |
| 保存/取消 | omPrimary/Secondary | center.add/update |

**默认草稿**：interval 60min；daily 9:00；weekly 工作日 9:00；cron `0 9 * * 1-5`。

### 6.3 内置模板（名称 / 摘要 / 计划 / 权限）

1. **每日变更摘要** — 每个工作日早上汇总过去 24 小时… — cron `0 9 * * 1-5` — readOnly  
2. **每周依赖检查** — 每周一检查依赖… — weekly 周一 10:00 — readOnly  
3. **待办扫描** — 每天傍晚整理 TODO/FIXME — daily 18:00 — readOnly  
4. **分支整理提醒** — 每周五列出分支… — weekly 周五 17:30 — readOnly  

prompt 全文见 `AutomationTemplates.swift` 21–36 行。

## 8. 用量页（`UsagePage`）布局与数据

### 8.1 概览（Grid adaptive min 150）

| 卡片 title | 图标 | 数据口径 |
| --- | --- | --- |
| 近 7 天消息 | messages-square | stats.recent(7).messages |
| 近 7 天会话 | layers | sessions |
| 近 7 天工具调用 | wrench | toolCalls |
| 累计 Token | coins | totalTokens 格式化 |
| 累计费用 | trending-up | totalCostUSD 或 — |
| 缓存命中率 | gauge | cacheHitRatio % 或 — |

加载中：「正在统计会话记录…」。来源 Note：transcripts（~/.claude/projects）或 stats-cache.json。

缓存：`AppEnv.supportDirectory/usage-index.json`。

### 8.2 当前会话

- `ContextUsageBody` 当 activeSession 有 usage
- 累计费用 LabeledContent；超 budget Label 警告
- **预算提醒** 数字 USD，prompt「0 表示关闭」→ `usage.budgetUSD` 默认 0
- Note：「预算提醒只在客户端侧判断…订阅通常不上报费用。」

### 8.3 活动趋势（有 daily 数据时）

- 分段指标：**消息 / 会话 / 工具调用**
- 分段范围：**7 / 14 / 30 天**
- 图表：**BarMark** 单色 accent gradient，高 160
- **ChartHoverTip**：`{date}\n{指标}:{值}`

### 8.4 每日 Token（按模型）

- **堆叠 BarMark** 按模型分色（最多 **5** 模型 legend）
- 高 190；Y 轴 Token 格式化
- Hover：日期 + 各模型 token 行

### 8.5 按模型累计

- 横向 **三系列 BarMark**：输入(accent)/输出(accent2)/缓存读取(success 0.55)
- 高 `count*34+56`；最多 **8** 模型
- Hover：模型名 + 三类 token
- 下列 LabeledContent 明细 + 费用
