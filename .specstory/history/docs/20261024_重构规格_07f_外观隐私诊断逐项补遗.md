### 6.3 cron 子集示例

| 类型 | 表达式 | 结果 |
| --- | --- | --- |
| 合法 | `0 9 * * 1-5` | 工作日 9:00 |
| 合法 | `*/15 * * * *` | 每 15 分钟 |
| 合法 | `0 0 1 * *` | 每月 1 日 0:00 |
| 合法 | `30 8 * * 1,3,5` | 一三五 8:30 |
| 非法 | `0 9 * *` | 仅 4 段 → 校验失败 |
| 非法 | `0 9 * * 1-5 extra` | 6 段 → 失败 |
| 非法 | `99 0 * * *` | 分字段 expand 超范围 → 失败 |
| 非法 | `0 9 * * 1-5/0` | step 0 → 失败 |
| 非法 | （空串 / 仅空格） | 失败 |

## 7. 更新：`UpdateChecker` / 安装校验 / UI 文案

### 7.1 appcast JSON

顶层 **`{ "stable": UpdateInfo, "preview": UpdateInfo?, … }`**。`UpdateInfo` 字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `version` | ✓ | 点分版本，与 CFBundleShortVersionString 比 |
| `build` | 可选 | 同 version 时比 CFBundleVersion |
| `url` | ✓ | dmg **https**（开发版可 localhost/file） |
| `sha256` | 正式版必填 | 小写 hex；**缺则拒绝安装**（dev 可省略） |
| `notes` | 可选 | `;` 或换行分条；WhatsNew/对话框 |
| `minimumSystemVersion` | 可选 | 低于则 `unsupportedSystem` |

**evaluate 失败文案**：发布源格式不正确 / 缺少 stable 通道 / 下载地址无效。  
**check 失败**：尚未配置更新源地址 / 更新源必须使用 https / 获取更新信息失败:{error}。  
**通道**：请求 channel 不存在时 **回退 stable**。更新仅当 version 更大或 build 更大。

**默认 feed**：`https://github.com/ixxxxoooo/OhMyAgent/releases/latest/download/appcast.json`（`update.feedURL` 空则用此）。

### 7.2 下载与 codesign（`UpdateInstaller.download`）

1. URL 须 `UpdateChecker.isAllowedSource`（https 或 dev 本机/file）。  
2. 下载 `update.dmg` → **sha256** 比对（有 expected 时）。  
3. 挂载取 `.app` → **`codesign --verify --deep --strict -R=identifier "com.ixxxxoooo.OhMyAgent"`** 失败 → **安装包签名无效**。  
4. 写入 `support/updates/ready.json`（`StagedUpdate`）。

**InstallError 用户可见**：下载地址无效 / 缺少 sha256 / sha256 不一致 / 无法打开安装包 / 包内无 app / 签名无效。

### 7.3 `UpdateWhatsNew`

- 键 **`update.whatsNew`**（JSON `{version, notes?}`）。  
- 退出安装前 `remember`；启动 `takePending` 当 `currentVersion >= recorded` 时弹一次并清除。  
- `bulletList` 最多 12 条（菜单检查用 50），超出加「…」。
