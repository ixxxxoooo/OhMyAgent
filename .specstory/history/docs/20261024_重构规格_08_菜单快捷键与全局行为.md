## 1. 总览

### 1.1 应用入口架构

```
OhMyAgentApp (@main)
├── init()           … 时区、字体平滑、滚轮、日志、Perf、演示沙盒、数据迁移、ThemeBridges
├── AppDelegate      … 激活策略、引导、托盘、IDE 恢复、更新检查
└── Scene
    └── Window(id: "main")  … Agent 工作台 WorkbenchView
        .defaultSize 1280×820 pt
        .windowStyle(.hiddenTitleBar)
        .commands { WorkbenchCommands() }

IDE 窗口 … AppKit NSWindow（非 SwiftUI WindowGroup），由 IDEWindowManager 管理
```

- **Agent 窗口**：SwiftUI `Window("OhMyAgent", id: "main")`，每个工作区逻辑上对应一个 Agent 子进程（见模块地图）。
- **IDE 窗口**：独立 `NSWindow`，与 Agent 窗口通过 `WindowContext` + `IDEWindowManager.route(_:)` 分流同一套菜单快捷键。
- **菜单栏**：仅 Agent 场景的 `WorkbenchCommands` 注册；IDE 窗口无独立 `CommandMenu`，依赖全局菜单 + 路由。

### 1.2 关键单例与职责

| 组件 | 职责 |
| --- | --- |
| `AppEnvironment.shared` | 唯一 `WorkbenchModel`、启动恢复项目、引擎预热 |
| `AppActions.shared` | 打开项目/会话/设置、保存、终端、主窗口前置、融合模式切换桥 |
| `WindowContext.shared` | 键盘窗口是 Agent 还是 IDE（菜单启用态与路由依据） |
| `IDEWindowManager.shared` | IDE 窗口 CRUD、⌃⌘I 切换、命令路由 |
| `ShortcutStore.shared` | 可自定义快捷键（UserDefaults `shortcut.*`） |
| `StatusItemController.shared` | NSStatusItem 托盘 |
| `AttentionCenter.shared` | 运行/待处理/未读 → 托盘点、Dock 角标 |
| `AppNotifier` | UNUserNotificationCenter，会话完成通知 |
| `LaunchTrace` | 启动阶段 perf 日志 |
| `AppEnv` | 稳定版/开发版目录名、`supportDirectory` / `logsDirectory` |

## 2. 原生菜单栏完整结构

菜单由 `WorkbenchCommands`（`OhMyAgentApp.swift`）注入 SwiftUI 标准 `Commands`。未在代码中替换的分组仍保留 **macOS 系统默认项**（随系统语言显示，如「撤销」「拷贝」「最小化」等）。下表只列 **应用自定义或替换** 的项；快捷键「可改」表示可在 **设置 → 快捷键** 修改（`ShortcutAction`）。

**路由列说明**：

- **Agent**：`WindowContext` 非 IDE 时，或 `IDEWindowManager.route` 返回 `false` 后执行 `WorkbenchModel` / `AppActions` 逻辑。
- **IDE**：当前键盘窗口为 IDE 且 `IDEWindowManager.route(...)` 返回 `true` 时，命令作用于该 IDE 的 `IDEWorkspace` / `IDEWindowModel`。
- **仅 IDE**：菜单项只调用 `IDEWindowManager.shared.route(...)`，Agent 窗口聚焦时通常无效果（route 返回 false，且无 fallback 的项则整体无操作）。

### 2.1 应用菜单（OhMyAgent）

| 菜单项（中文原文） | 快捷键 | 可改 | 启用条件 | 作用 | Agent | IDE |
| --- | --- | --- | --- | --- | --- | --- |
| 设置… | ⌘, | 否（系统） | 始终 | 打开设置 | `AppActions.openSettings()`；融合模式下可在 IDE 内嵌设置 | 同左；融合模式内嵌于 IDE |
| 切换颜色主题… | — | 否 | 始终 | 中央主题选择 | `HubModel.presentThemes` | 同左（Hub 挂 Agent 工作台） |

| `previousTab` | 上一个标签 | ⌃⇧⇥ | `shortcut.previousTab` |

| `goForward` | 前进 | ⌘] | `shortcut.goForward` |
| `switchWindowMode` | 切换 Agent / IDE 窗口 | ⌃⌘I | `shortcut.switchWindowMode` |
| `newIDEWindow` | 新建 IDE 窗口 | ⇧⌘N | `shortcut.newIDEWindow` |

**冲突规则**（`ShortcutStore`）：

1. **系统保留**（不可占用）：⌘Q、⌘H、⌘M、⌘,、⌘C、⌘V、⌘X、⌘A、⌘Z。
2. 与其他 `ShortcutAction` 冲突 → 设置失败，提示「与「xxx」冲突」。
3. 录制时 `ShortcutBinding(event:)` **必须含 ⌘、⌃ 或 ⌥ 之一**，否则忽略（避免吞输入）。
4. 恢复默认 = 删除对应 UserDefaults 键。

**导入/导出**：JSON 对象 `{ "actionRawValue": { "key", "modifiers" } }`；未知 action 跳过。

## 4. 窗口上下文与命令路由

### 4.1 WindowContext

```
键盘窗口 became key
    │
    ├─ 向上找 IDEWindowManager.model(for:)
    │       └─ 找到 → kind = .ide(UUID)
    │
    └─ window.canBecomeMain → kind = .agent
        （Panel、Sheet 不改变 kind）
```

- 菜单里 `disabled` / 文案可观察 `WindowContext.shared`（`@Observable`）。
- **融合模式**（`general.fusionMode`）：Agent ↔ IDE 同外框切换；`general.fusionLastIDE` 记录上次模式，影响启动是否恢复 IDE 窗口。

### 4.2 IDEWindowManager.Command 路由表

| Command | IDE 行为 |
| --- | --- |
| `toggleSidebar` | `model.toggleSidebar()` |
| `togglePanel` | `model.togglePanel()` |
| `toggleAgentPane` | `model.toggleAgentPane()` |
| `maximizeAgentPane` | `model.toggleAgentMaximized()` |
| `perfHUD` | `model.perfHUDVisible.toggle()` |
| `save` / `saveAll` | workspace 保存 |
| `closeTab` | 0 标签时关窗口 |
| `newTerminal` | `workspace.newTerminal()` |
| `quickOpen` | `openPalette("")` |
| `commandPalette` | `openPalette(">")` |
| `goToLine` | `openPalette(":")` |
| `showSearch` | `perform("view.search")` |
| `showSymbols` / `showReferences` / `renameSymbol` / `formatDocument` / `quickFix` | LSP 命令 |
| `foldCode` / `unfoldCode` | `perform("edit.fold/unfold")` |
| `reopenTab` / `nextTab` / `previousTab` | 标签导航 |
| `goBack` / `goForward` | `model.goBack/Forward()` |

| `applicationDidFinishLaunching` | `AppDelegate` | 读 `showDock` → `NSApp.setActivationPolicy(.regular/.accessory)`；legacy socket 清理；托盘默认迁移；`LaunchTrace.mark("应用代理开始")`；`AppNotifier.install`（非演示）；`AppEnvironment.bootstrap`；`AutomationService.start`；`StatusItemController.start`；`WindowContext.start`；`IDEWindowManager.restoreWindows` + `IDEDebugHooks`；`AppearanceModel.applyAll`；`LaunchTrace.mark("启动完成")`；8s 后 `UpdateModel.autoCheckIfNeeded`（非演示）；若无 `OMA_DRAFT`/`OMA_OPEN_SETTINGS` 则 `NSApp.activate()` |
| 首帧 | `DiagnosticsStore.markLaunch` | `OMA_PERF_OUT` 写首帧毫秒 |

**LaunchTrace** 每阶段写 `Log.perf`：`stage`、`sinceLaunchMs`、`deltaMs`。

**性能预算（文档目标，非硬编码）**：首帧 ≤300ms（release 热启动实测约 293–305ms）；启动完成日志合计约 1.3s（见 §11）。

### 5.2 退出行为

| 场景 | 行为 |
| --- | --- |
| ⌘Q / 托盘「退出 OhMyAgent」 | `applicationShouldTerminate`：有脏文件 → `OMDialog` 三选一（取消 / 不保存退出 / 全部保存并退出） |
| 关闭最后窗口 | `applicationShouldTerminateAfterLastWindowClosed`：**托盘开启时返回 false**（应用继续跑）；托盘关且 Dock 显示则退出 |
| Dock 图标点击无窗口 | `applicationShouldHandleReopen` → `AppActions.showMainWindow()` |
| `applicationWillTerminate` | IDE `prepareForTermination`；更新退出逻辑；`PerfSession.logSummary`；`workbench.shutdownAll`；LSP shutdown（最多等 1.5s）；`LogSystem.flush` |

### 5.3 多窗口规则

- **Agent**：SwiftUI 单场景 `main`；`openWindow(id: "main")` 可重建。
- **IDE**：多 `NSWindow`，注册表 `ide-windows.json`；同根目录默认复用；⌥ 强制新开。
- **融合模式**：切换时 adopt 外框 + 淡入 0.14s（减弱动态效果则 0）；IDE 关窗释放该窗 Agent 会话与终端。

### 5.4 重启应用

`AppActions.relaunch()`：仅 `.app` 包；后台 shell 等 PID 结束后 `open -n`；然后 `terminate`。

## 16. 重构注意事项

1. **菜单与 IDE 路由**：任何新增 ⌘B/⌘J/⌘W 类命令必须同时考虑 `WindowContext` + `IDEWindowManager.route`，否则 IDE 聚焦时行为错误。
2. **WorkbenchCommands 求值时机**：菜单 body 启动即执行；`disabled` 需绑定 `@Observable` 状态（如 `WindowContext`、`workbench`）。
3. **融合模式**：`showMainWindow` 与 `switchToAgent` 有重入保护；启动恢复 IDE 时可能 `orderOut` Agent 主窗口。
4. **托盘**：勿用 SwiftUI `MenuBarExtra`（曾 CPU 空转）；`syncVisibility` 防 UserDefaults 重入。
5. **演示模式顺序**：`DemoLaunch.activateIfRequested` 必须早于任何读 UserDefaults/Application Support 的代码。
6. **快捷键与发送键**：`.send` 与 `chat.sendKey` 两套逻辑；QA 需覆盖两种发送模式。
7. **退出**：托盘模式下关窗不退出；LSP shutdown 有 1.5s 上限，可能残留进程。
8. **性能敏感**：启动路径避免同步 IO；`RecentStore.record` 在 body 热路径有缓存；卡顿栈采样仅符号不含密钥。
9. **CI**：`restart.sh` **不**转发大部分 OMA_*；演示/截图需 `demo.sh` 或 `open --env`。
10. **Bundle 迁移**：`LegacyDefaultsMigration` 与 `oma.dev.defaultsSeeded` 只跑一次；跳过 NSStatusItem 键。
