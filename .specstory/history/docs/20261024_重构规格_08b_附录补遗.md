## 附录 A. 菜单栏：SwiftUI 默认项 + 自定义替换

应用仅注册 `WorkbenchCommands()`（`OhMyAgentApp.swift`），无 `@DocumentGroup`。菜单由 **SwiftUI 注入的系统 CommandGroup** 与自定义项合并而成。下表基于 macOS 27 + SwiftUI `Commands` 默认行为整理；**未在源码中显式声明的条目均为系统注入**，启用态遵循 AppKit 第一响应者链（标注「FR」）。

**替换关系（源码可核实）**：

| CommandGroup | 效果 |
| --- | --- |
| `replacing: .appSettings` | 移除系统默认「设置…」，改为自定义「设置…」「切换颜色主题…」 |
| `replacing: .saveItem` | 移除系统默认「保存 / 另存为 / 复制 / 还原」整组，改为自定义保存组 |
| `replacing: .sidebar` | 移除系统默认「显示/隐藏边栏」等，改为自定义视图组 |
| `after: .newItem` | 在系统「新建」相关项之后追加文件组自定义项 |
| `after: .textEditing` | 在编辑标准项之后追加查找/Hub/IDE 导航项 |
| `after: .appInfo` | 在「关于」区域后追加「检查更新…」 |
| `CommandMenu("标签")` | **新增**整栏「标签」菜单（非系统自带） |

**Dock / 菜单栏显示**：非 `Info.plist` 的 `LSUIElement`；由 `general.showDock` 决定 `NSApplication.ActivationPolicy`（`.regular` / `.accessory`），见 `AppDelegate.applicationDidFinishLaunching`。

## 附录 C. 快捷键：IDE ⌘1–9、浮层优先级、输入法

### C.1 ⌘1–⌘9 在 IDE 为键盘窗口时

| 项 | 行为 |
| --- | --- |
| 菜单绑定 | `WorkbenchCommands` → **始终** `workbench.selectTab(number:)`，**无** `IDEWindowManager.route` |
| 作用对象 | Agent 工作台 **`dock.focusedGroup`**（中栏/右栏停靠区的聚焦组），**不是** IDE 编辑器 `IDEWorkspace` 标签 |
| IDE 聚焦时典型效果 | 若用户未切回 Agent 窗口：操作的是**后台** `WorkbenchModel.dock` 的聚焦组；**不会**切换 IDE 编辑器内文件标签 |
| IDE 标签切换 | 应使用 **⌃⇥ / ⌃⇧⇥**（route 到 `workspace.cycleTab`）或 IDE 命令面板 `go.nextTab` / `go.previousTab` |
| 设计含义 | 与 VS Code「⌘1–9 切编辑器组」不同；重构若需 IDE 标签数字切换，须新增 route 或条件分支 |

### C.2 浮层内按键优先级

**原则**：模态 `NSApp.runModal` > key 子窗口 > 本地 `NSEvent` 监视器（**后注册的先收到**）> SwiftUI `.onKeyPress` > 菜单快捷键 > 第一响应者默认键位。

| 浮层 | 实现 | 按键 | 组字期间 |
| --- | --- | --- | --- |
| **Hub（⌘K）** | `HubKeyMonitor` 本地 `keyDown` | ↑↓ 移动、⌃N/⌃P、⇥/⇧⇥ 切 segment、↩ 执行、Esc 关闭 | `NSTextView.hasMarkedText()==true` 时 **resolve 返回 nil，事件放行给输入法** |
| **Hub 主题 segment** | 同上 + `handleThemeKey` | ↑↓ 预览主题、↩ 提交、Esc 回滚并关闭 | 同上 |
| **OMPickList / PickListContent** | SwiftUI `.onKeyPress` + 搜索框 `TextField` | ↑↓ 高亮、↩ 确认、Esc `onDismiss`；搜索框 ↩ `onSubmit`→confirm | **未**显式检测 markedText；组字时 ↑↓ 可能被 IME 消费 |
| **PickerPanel（OMPickList 容器）** | `NSPanel` 子窗口 `makeKey` | 键盘先进面板内 TextField | 面板失活/点外关闭 |
| **IDE 命令面板** | `IDEPaletteOverlay` `.onKeyPress` | ↑↓ 高亮（主题项预览）、Esc 关闭；↩ 在 `TextField.onSubmit` | 无 markedText 守卫（待实测 IME） |
| **IDE 主题选择器** | `IDEPaletteModel.themeKeys` = `HubKeyMonitor` | 与 Hub 相同逻辑 | 同 Hub |
| **OMDialog / OMModal** | `NSApp.runModal(for: panel)` | Esc → `cancelOperation` → `finish(-1)`；主按钮 `.defaultAction`；带输入框时 ↩ 校验后提交 | 系统 IME 在 TextField 内 |
| **快捷键录制** | `ShortcutsPage` 本地 monitor | 含 ⌘/⌃/⌥ 才记录；Esc 取消 | — |

**与菜单快捷键冲突**：Hub 打开时 monitor 若 `return nil`（未处理），⌘K/⌘P 等**可能继续传递**；handler 返回 true 则吞掉事件。

### C.3 输入框 / 会话区 IME

| 位置 | 规则 |
| --- | --- |
| `ComposerTextView` | `hasMarkedText()` 时 Return 不发送、Esc 不触发取消回调；占位符隐藏条件含 `!hasMarkedText()` |
| `ComposerMentionAttachment` | 组字中不处理 @ 提及 |
| Hub 搜索框 | 组字时方向键/回车/Esc **不**被 Hub 拦截 |
